# 与子平诸书的体系分界

> **为什么必须写这一份。**
> 金镖门自称承子平，但在最核心的两处（格局、旺衰）与书房派子平**正面相反**；同时它的中下册有六成篇幅是《滴天髓》逐章讲解，与已交付的「滴天髓」skill 大面积重叠。若不分界，用起来必然互相打架。

---

## 一、总表

| 议题 | 金镖门 | 子平真诠（沈孝瞻） | 滴天髓 | 三命通会 | 渊海子平 |
|---|---|---|---|---|---|
| 格局的作用 | **脚手架，只用来找用神** | 命理之骨干，必须先定格 | 不重定格，重气势 | 广列格局，兼收神煞 | 格局与神煞并重 |
| 格局数量 | 不论格名，取用只分两条路 | **只取八格**（正官、财、印、食神、七杀、伤官、阳刃、建禄月劫） | 无明确格数 | 数百格 | 数十格 |
| 月令地位 | 用神次序之一（官→财→月令→食伤） | **用神只在月令取** | 重月令但不绝对 | 重月令 | 重月令 |
| 旺衰 | **六档定性**，不看分值 | 不以旺衰为纲，以成败救应为纲 | 重衰旺但讲「中和」 | 讲旺衰 | 讲旺衰 |
| 相神 | 不用「相神」概念，用「喜神」 | 「相神」为核心（伤用甚于伤身，伤相甚于伤用） | 无此概念 | 无此概念 | 无此概念 |
| 神煞 | **基本不用** | 不用 | 不用 | 大量使用 | 大量使用 |
| 纳音 | **不用**（原文明确「胎元纳音、神煞口诀，多有不验」） | 不用 | 不用 | 用 | 用 |
| 断语风格 | 只给可证伪的十二项 | 论理，少断事 | 论理 | 汇编 | 汇编 |

## 二、最尖锐的一处对立：格局

### 金镖门的立场

原文（`K04_13`）：

> 无论是什么格局，它的本质都是找喜用神。找格局的最终目的——就是为了找出用神……**就不用去研究他是什么格，是什么局了，从它最终目的下手就行了**，就简化了，就直接了。

于是取用只剩一条分水岭：能不能承载财官。能，则 `官 → 财 → 月令 → 食伤`；不能，则 `印 → 比 → 根`。

### 《子平真诠》的立场

沈孝瞻的全部体系建立在「**八字用神，专求月令**」之上，且明言格局只取八格，其余皆为外格、不入正论。他认为必须先定格局，再论成败救应，再论相神，最后论行运——**格局是骨架，不是脚手架**。

### 冲突点

| 情形 | 金镖门会怎么断 | 子平真诠会怎么断 |
|---|---|---|
| 月令是正官，但官星无根无力，另有强财 | 官无力则弃，取财为用（「无用之神尽可伤」） | 仍是正官格，论其成败：官弱须财生、须印护，成败在此 |
| 月令是伤官，官星有力 | 身弱取印、身强取财，官星作忌处理即可 | 伤官格见官，须辨「伤官见官」之成败救应，不可径弃 |
| 格局名不清（如杂气） | 不纠结名目，直接判承载、取用 | 必须辨清杂气何者透干、何者为用 |

**使用建议**：若用户的问题偏「这个命做什么工作、哪年结婚」，走金镖门路径更快更实；若偏「这个命格局高低、贵在何处」，子平真诠的框架更严密。**不要把两套结论强行折中**，折中出来的往往是两套都错的结论。

## 三、第二处对立：旺衰

金镖门把旺衰切成六档（原文称七种），并明确「不明显的才需要辨」。判据只有一条硬标准：**日主近处（坐下）有强根，一般就不是身弱**。

子平真诠则根本不把旺衰当纲，它问的是「用神是否有力、相神是否得位、格局是否破」。滴天髓讲衰旺，但落点在「中和」与「顺逆之机」。

**冲突点**：同一个八字，金镖门可能判「不旺不弱，能承载财官」，子平真诠可能判「身弱用印，然印被财坏，格败」。两者并不矛盾——**它们回答的不是同一个问题**。前者回答「日主扛不扛得住财官」，后者回答「格局成不成」。

## 四、与「滴天髓 skill」的重叠与分工

### 重叠事实

05 中册 37 篇、06 下册 23 篇中，**大半是《滴天髓》逐章讲解**，篇名与《滴天髓》原文章节一一对应：

| 从格 / 顺局 / 化象 / 假化 / 知命 | — | `K06_13~K06_18` |

### 分工原则

| 问题类型 | 用哪个 skill |
|---|---|
| 《滴天髓》**原文是什么、任铁樵怎么注、某句怎么解** | 用「滴天髓」skill（那是原文校勘本，有底本依据） |
| 《滴天髓》**这句在实战里怎么用、金镖门怎么讲、配了哪些命例** | 用本 skill（这是讲课实录，有大量命例与现场修正） |
| 断具体事（婚期、职业、属相、牢狱年份） | 用本 skill |
| 论命理原理、格局成败的理论辨析 | 用「子平真诠」skill |

**关键提示**：本 skill 中的《滴天髓》讲解是**金镖门化的解读**，不是任铁樵注的原意。原文中反复出现「京南道人：」「徒张景发谨按：」「徒等归纳」等标记，说明这是师徒讲论而非注本。引用时须标明「金镖门讲法」。

## 五、与「三命通会」「渊海子平」的分界

这两书是**类书**，价值在「收录全」，可以把各家说法并列。金镖门对它们的态度是明确的批评，见 03 册序言：

> 术者又以三命为本源，论其神煞，编为口诀，以便记忆……审诸家书房立论，多取正官、正财、正印，而不知拱杀偏财亦能得力；盲派取印食禄三宝为美者，不知伤官劫财亦可出奇，偏执之见，未能圆彻。且**胎元纳音、神煞口诀，多有不验**。

也就是说：
- **神煞**：金镖门基本不用。三命通会的神煞条目在本 skill 中**不具备权威性**。
- **纳音**：金镖门明确判为「多有不验」。三命通会、渊海子平中的纳音断法**不要引入**。
- **胎元**：注意这里的微妙处——金镖门**批评的是「胎元纳音」，不是胎元本身**。胎元在 02 册中是核心技法（见 `J02_06`），但用法不是查纳音，而是**以日干定位胎元干支的十神、再还原为卦**。这是两套完全不同的胎元用法，不可混用。

## 六、与「穷通宝鉴」的关系

穷通宝鉴走的是「**按月令+日干**查喜用」的路线（如「甲木生于正月，用丙癸」），与本门「按承载与否取用」的路线并行而不冲突：

- 穷通宝鉴给的是**调候与月令喜忌的模板**；
- 金镖门给的是**承载判断与应期**。

实战中可以这样配合：先用穷通宝鉴定该日干在该月的**基本喜忌倾向**（尤其寒暖燥湿），再用金镖门判承载、定用神、抓病药、推应期。**但若两者结论冲突，以本门的承载判断为准**——因为本门明确说过「调候不能凌驾于承载之上」（见 `K05_11` 寒暖、`K05_35` 燥湿两篇中对「湿土来了不行」的现场修正）。

## 七、与「兰台妙选」「五行精纪」「神锋通考」的关系

这三部是**古法与杂占**一路：兰台妙选重格局名目与贵格，五行精纪重纳音与神煞，神锋通考是杂断汇编。

与本门的关系：
- **方法论上没有继承关系**，本门不用纳音、基本不用神煞、不论贵格名目。
- **可用作命例与断语的旁证**，尤其神锋通考中的实务断语。
- **不可反向引入**：不要用这三部的纳音、神煞结论去修正本门的判断。

## 八、一张「遇到分歧怎么办」的决策表

| 分歧场景 | 处理原则 |
|---|---|
| 本门与子平真诠在「格局是否必先定」上冲突 | 看问题类型。断事走本门；论格之成败走真诠。**不折中** |
| 本门与滴天髓注本在文义上冲突 | 文义以滴天髓 skill 的校勘本为准；实战用法以本 skill 为准，并注明「金镖门讲法」 |
| 本门与三命通会在神煞、纳音上冲突 | **本门优先**（本门明确判其不验）。神煞只作参考，不入结论 |
| 本门与穷通宝鉴在调候上冲突 | 承载判断优先；调候作为修正项，不单独成立结论 |
| 本门内部（01 与 11、或 04 与 11）说法不一 | 以 11《八字教程》为准（同源而更完整），01 作校勘参照；讲课笔记（04/05/06）与教材冲突时，**以讲课笔记为准**（时间更晚、有现场修正） |
| 原文本身自相矛盾（如「七种情况」只列六档） | 照实记录，不擅自补足。见 `07_校勘须知.md` |
