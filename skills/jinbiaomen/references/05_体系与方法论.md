# 金镖门盲派命理体系与方法论

> 本文件是本 skill 的「总纲」。它不替代原文，只做三件事：说清这套体系**怎么运转**、**从哪里下手**、**哪里会走偏**。具体断语一律回 `references/sec/` 查原文。

---

## 一、这套体系是什么

金镖门（京南道人一系，师承「老人参」盲师）自称远承子平、近取盲派，但其骨架与书房派子平有明确分歧。核心取向可以一句话概括：

> **不算「是什么格」，只算「用神是什么」；不讲「旺衰几分」，只讲「能不能承载」。**

三条硬立场（贯穿全部九种材料）：

1. **格局只是找用神的脚手架**，不作结论。见 `K04_13`。
2. **旺衰只分档，不分值**。六档（原文称七种）取代百分比打分。见 `K04_07`。
3. **吉凶落在「应期」与「六亲属相」两项硬功夫上**，不作模糊评价。见 `K04_06`。

## 二、十二个稳定得分点

这是本门对「什么叫算准了」的定义。十二项都是可以被证伪的硬结论，做不到就不算过门。见 `K04_06`。

| 组 | 得分点 | 具体要求 |
|---|---|---|
| 婚姻 | 哪年结婚 | 稳定得分，说了就得验 |
| 婚姻 | 哪年离婚 | 同上 |
| 婚姻 | 几次婚姻 | 同上 |
| 学历 | 学历层次 | 给出明确档位，不含糊 |
| 事业 | 定层次 | 当官／大老板／小老板／白领／工薪／打工／打零工／无业 |
| 事业 | 升与降、发与破 | 哪年提升、哪年降级；哪年发财、哪年破财，以及**因为什么** |
| 事业 | 具体取向 | 干什么行业、什么岗位 |
| 灾 | 牢狱 | 哪年进、哪年出 |
| 灾 | 血光 | 车祸／手术／其他，要分 |
| 灾 | 六亲之灾 | 克父、克母、克妻、克子 |
| 硬功 | 断应期 | 准确到年 |
| 硬功 | 六亲属相 | 父母、配偶、子女的属相 |

> 注意：**没有「性格分析」「命好不好」这类项目**。本门认为那是断不出来的东西，说了等于没说。

## 三、断命八步次第

```
第一步  定用神（不看格局名，直接找用神）
第二步  辨承载（日主能否承载财官 → 决定取用方向）
第三步  定喜忌（帮用神即喜神，害用神即忌神）
第四步  看顺逆（吉神顺用、凶神逆用；有用之神不可伤）
第五步  抓病药（男犯比劫、女犯伤官、官杀混杂、枭夺食……找病，等药）
第六步  过三关（工作关 → 婚姻关 → 父母关）
第七步  定应期（大运定乾坤，流年不违大运）
第八步  取象补细节（胎元、借盘、八卦、串宫压运）
```

八步的原文依据分散在各篇，逐条索引见 `01_主题索引.csv`。

## 四、第一步：定用神——「格局的最终目的」

原文（`K04_13`）：

> 找格局的最终目的——就是为了找出用神……格局的最终目的知道了，就可以从这个最终目的去下手，**就不用去研究他是什么格，是什么局了**，从它最终目的下手就行了。

取用只有两条路，分水岭是**日主能不能承载财官**：

**（甲）身强可承载财官**，用神优先序：

> 官 → 财 → 月令提纲 → 食伤

有官取官（官是用神则财不是）；无官有财取财；官财皆无取月令；最后取食伤。

**（乙）身弱不可承载财官**，用神只找帮身：

> 印 → 比 → 根；月令是印比者，可直接以月令为用神

**喜神的定义极简**：「帮用神就叫喜神。」由此派生四种常见配置：

| 用神 | 受谁害 | 喜神 |
|---|---|---|
| 财 | 被比劫克 | 官杀（护财） |
| 财 | 自身弱（无破） | 食伤（生财）、财运、财见根之运 |
| 官 | 被食伤克 | 印（护官、枭神夺食） |
| 印 | 被财坏 | 比劫（护印制财）；印衰则官杀为喜神（生印） |

## 五、第二步：辨承载——旺衰六档

原文列了七行却只给出六档（`K04_07`）：

```text
旺极端
太旺
旺
不旺不弱，能承载财官   ← 关键档
太弱
弱极端
```

「不旺不弱」是本门最常用的一档，也是最容易误判的一档。判据只有一条：

> **日主近处（坐下）有强根，一般就不是身弱。**

两个原文命例把这条讲透了：

- `壬 壬 戊 乙 / 申 子 午 卯`：水极旺，子午冲，但坐下有午，「足以承载旺财官」，只算偏弱。
- `壬 壬 己 辛 / 申 子 巳 未`：看似身弱，实际自坐禄旺又贴未土，**是身旺**。

但注意断婚期时的例外：**财官过重、明显比日主旺的，大运取帮身，流年也要取帮身**——即使事业上可以直接取财官为用。这是「同一命局，不同项目取用不同」的典型。

另附两条实战补充：

- **转换规则**：「太衰似印」「极端化气」——太弱可借印之象、弱极则入化气。
- **刑冲穿破根**：`辛` 坐 `丑`，把丑刑了不是开库，是**坏了辛金的库根**；`甲` 见 `未` 被刑同理。见 `K04_07`、`K04_10`。

## 六、第三步：顺用逆用与「有用之神不可伤」

原文（`K04_14`）：

> 官是尊贵的，印、财、食神，这都是吉利的；伤官、七杀、阳刃，这都是凶猛的。
> **吉神要温柔对待，或者生或者化泄；凶神要制裁它克它。**

但紧接着是全门最重要的一句限定：

> **有用之神不可伤，无用之神尽可伤。**

含义：正官本不可被伤官克，但如果这个正官**没力量、不能主事**，那就可以随便克、随便践踏，留着也是摆设。原文举 `甲 甲 己 辛 / 申 申 巳 酉` 为例，此官无用，辛可径克。

同一逻辑延伸：没用的财尽可劫，没用的印尽可坏。所谓「伤官伤尽」，不过是「无用的官」这一角。

## 七、第四步：抓病药——本门的「病」清单

本门断命是**找病 → 等药**。核心的病与药：

| 病 | 适用 | 药（解法） | 原文 |
|---|---|---|---|
| 男犯比劫（夺妻） | 男命婚姻 | 官杀制比劫；比劫得用配杀 | `K04_06` |
| 女犯伤官（克夫） | 女命婚姻 | 印制伤；财化伤 | `K04_06` |
| 日主不立／配偶星不立 | 婚姻 | 印、比劫、见根（三者哪个先来取哪个） | `K04_06` |
| 官杀混杂 | 事业、贵气 | 身弱须去混杂；身旺且官弱反而喜混杂（助官） | `K04_14` |
| 枭神夺食 | 全局 | 比劫化枭、财破枭 | `J11_01` |
| 财来坏印 | 学业、名声 | 官杀（首）、比劫（次） | `J01_01` |
| 印太重（水大木漂、木多火塞、土多金埋、火旺土焦） | 全局 | 财制印（「君赖臣生」反局） | `K06_07` |

**病不解，事不成。** 原文举女命 `癸 癸 辛 己 / 亥 亥 亥 丑`：女犯伤官，若印星一直不来，则断为独身，来了才结婚（应期在丑运戊子、己丑年）。

## 八、第五步：过三关

「过三关」是本门的招牌结构，在 02《精进》与 11《八字教程》中各有完整演示。

1. **工作关**——见 `J02_05`、`J11_03`
   三步曲：**找格局 → 检查格局是否成立 → 取象**。
   不能直接取象，理由原文说得很直白：火克金可能是设计院画图（国有），也可能是电工，也可能是电子厂——**格局不定，取象必错**。
   工作只分三种：吃皇粮的（国家单位）、私人单位打工、自己开买卖。

2. **婚姻关**——见 `K04_06`、`J02_03`、`J11_04`、`M08_05`
   职业命师断婚姻只有五件事：何年结婚、是否离婚／何年离婚、是否出轨／何年出轨、是否克夫克妻、几次婚姻。**「除此以外，皆为没有说服力的断语，非本门风格。」**
   操作依「婚姻五大法则」，见 `02_婚姻五大法则表.csv`。

3. **父母关**——见 `J11_06`、`K06_22`、`M08_09`
   父母关是六亲重中之重。技法序列：胎元 → 六合 → 暗合 → 六冲 → 六穿 → 三合 → 三会 → 三刑 → 六亲定位 → 八卦精准取象 → 借盘法 → 六亲属相。

## 九、第六步：应期——「大运定乾坤」

本门断应期的铁律：

> **大运定乾坤，流年是不能和大运相违背的。**

具体到操作：
- 大运已经「表了意思」（如：帮身），流年只要符合这个意思即可（印、比、根皆可）。
- 大运若明确「来了印」，流年就**只能**选印，不可选比劫。
- 断婚期通常报两个年号（一年订婚、一年领证婚礼）。

配套技法：大运倒象、流年倒象、原因倒象（`M08_06`）；伏吟主「重」（`M08_14`）；串宫压运十二星循环管年（`M08_11`）。

## 十、第七步：取象——三层取象

本门的「象」，从粗到细三层：

1. **干支类象**（基础层）：十天干类象、十二地支类象，见 `J11_01`、`J01_01`。
2. **胎元八卦象**（先天层）：胎元干支还原为卦，再以「与某卦组合」派生。见 `J02_07`、`J02_08~16`。
   例：胎元 `戊寅`，戊藏于辰，辰在巽宫 → 胎元干为巽卦 → 巽为「利市三倍」之财，故断此造先天所带之财很大。
3. **串宫压运象**（流年层）：十二星（太岁、青龙、丧门、六合、官符、小耗、大耗、朱雀、白虎、贵神、吊客、病符）× 十二宫，逐年循环。见 `M08_11`、`J11_05`。

## 十一、十二道门速览

`08 十二道门绝技` 是本门最浓缩的一册，每道门都是一首口诀加若干命例。完整表见 `04_十二道门口诀表.csv`。三道最关键的门：

- **第一道·秘传十排歌**（总纲）：
  > 先看天干做何事，再查地支有何意；升天入地加伏吟，刑冲合穿为动门；分清动静和体用，看命断事细如神。
  操作：日干在做什么？只有两种——**生**（生食伤，看食伤做什么）与**合**（阳干合财、阴干合官）。天干既不生也不合，才看日支做什么。

- **第四道·鸳鸯门**（婚姻专章）：宫（夫妻宫）与星（夫妻星）并看，「宫星相配和谐美，宫坏星伤徒伤情」。

- **第六道·牢灾**：
  > 劫财伤官莫犯官，犯官定永吃牢饭；劫财伤官见官符，吃上牢饭不自由。

## 十二、五处限界（必须承认的）

1. **同居不算结婚。** 原文反复强调：只有领证或办婚礼才算婚姻。现代命例若按同居作婚期，必错。
2. **无「反吟」「小运」**。全书检索零命中（见 `01_主题索引.csv`），本门不用此二项，不要凭空补入。
3. **十二道门原文只列十四道**（首道至第十四道），坊间传「十二道」为概称，且「郑公绝技命例」一节在 08 册中缺失（`M08` 已注明）。
4. **01 与 11 两册高度重叠**。01《基础》与 11《八字教程》共用同一份目录、同一套章节，正文为同源不同版本；引用时优先用 11（OCR 质量更好、章内更完整），01 作校勘参照。
5. **八卦只有七卦**。02 册「八卦取象」缺巽卦（OCR 过程中该字被严重误识，无法还原），引用八卦象时**不可自造巽卦条目**。

## 十三、生成与核查建议

拿到一个八字，建议按下面顺序做，避免跳步：

1. 排盘，标出日干、日支（元神）、月令。
2. 判旺衰落在六档哪一档，写一句「能不能承载财官」。
3. 按承载与否取用神，写出用神、喜神、忌神各一。
4. 列病：男看比劫、女看伤官；再看官杀混杂、枭夺食、财坏印、印过重。
5. 过三关：先工作（格局→成立→取象），再婚姻（五大法则），再父母（胎元→借盘→属相）。
6. 定应期：找大运给了什么「意思」，再在该意思下选流年。
7. 取象补细节，但**取象只作补充，不作结论**。
8. 输出时只给十二个得分点范围内的结论；超出范围的猜测要么删掉，要么明确标为推测。
