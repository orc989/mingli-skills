# 纳音五行体系：《五行精纪》的论命骨架

> 一句话：**《五行精纪》不讲「日干为主」，它讲「纳音为主、年为主、日为本」。**
> 拿子平的十神、格局、用神直接套这本书，几乎每一句都会读歪。

---

## 一、先辨体系：唐五代—北宋的「三命」与南宋以后的「子平」

命理史上有一条大分水岭：

| | 唐—北宋「三命术」（本书所属） | 南宋—明清「子平术」 |
|---|---|---|
| 论命主体 | **纳音五行**（六十甲子各有纳音） | **日干**（日元） |
| 年柱地位 | **年为主**（本命） | 年柱为祖上／背景 |
| 日柱地位 | 为本（己身） | 主导 |
| 胎月 | **参与论命，与年月日时并称五位** | 基本废弃 |
| 十神 | 无「正官／七杀／食神／伤官」之名（有官、鬼、财、印、食实而不同名） | 十神体系完备 |
| 神煞 | 极密（本书 64 小节专列凶神） | 减少、降为辅助 |
| 中和 | **不主中和**，主「气数归位」与「扶抑太过不及」 | 主中和、格局成败 |

**因此本书的读法应当是**：
1. 先看四柱（或五柱）纳音，判其生旺死绝；
2. 再看干神、支神的关系（合、冲、刑、害、空亡）；
3. 再看禄、马、贵神、印、食、三奇等福神与劫、亡、咸池、金杀等凶神；
4. 最后以岁运补其不足（「虚一待用」）。

## 二、「纳音为体」：三条关节

### 1. 六十甲子逐柱立论，不逐干立论

卷一整卷（《论六甲纳音法》）把六十个干支逐柱配一段评语，句式为「**某柱 + 四字取象 + 宜忌 + 前人评语**」：

> **甲子从革之金**，其气散，得戊申土、癸巳水相之，则吉。戊申乃金临官之地，土者更旺于子，必能生成，癸巳系金，生于巳，水旺于子，纳音各有所归，又为朝元禄，忌丁卯丁酉戊午之火。
> 阎东叟云：甲子金为进神，禀沉潜灵中之德，四时皆吉，入贵格，承旺气，则术业精微，主魁夺之荣。

注意三点：
- 「甲子」不是「甲木坐子水」，而是「甲子」这一整柱＝**海中金**；
- 忌的「丁卯丁酉戊午之火」是**纳音火**，不是日干火；
- 评语来源是**阎东叟**、《五行要论》、《玉霄宝鉴》等，不是子平诸书。

### 2. 同一纳音，因「成器／未成器」而吉凶相反

《玉霄宝鉴》的分法在本书被反复引用：

> 甲子乙丑**未成器金**，见火则成，多见则吉。
> 庚辰辛巳**未成器金**，宜见火，盖辛巳是自生，巳为火，得之者，光辉日新。
> 壬申癸酉，**金旺之位，不可复旺**，旺则伤物；不可见火，见火则自伤。

同一「金」，未成器要火炼，已成器忌火伤。**这是纳音法的第一道判据，跳过它就会得出完全相反的结论。**

### 3. 「盛大／小弱」可随他柱而变

卷二末（《广录》）有一段极重要的方法论：

> 右件六十甲子，**盛大者，忌变为小弱；小弱者欲变为盛大**……且年属木，假令是庚寅辛卯，则木之盛大可知，若日月时胎不见他木，则以松柏论；万一月日时胎上见杨柳木或石榴木，则**当舍大就小**，不以松柏论也。

即：**纳音取象不是固定的，要看他柱有无同类而改判。** 庚寅辛卯（松柏木＝盛大）遇壬午癸未（杨柳木＝小弱），就要「舍大就小」。这一条是本书与一般纳音口诀书（只背「甲子乙丑海中金」）的分水岭。

## 三、主本论与三主三限

卷十《论年月日时胎》引《李虚中书》与《阎东叟书》：

> **年与月管初主，月与日管中主，日与时管末主**，其法与星象历家分三主同。（李虚中书）
> **常以生月为初限，管二十五年，生日为中限，管二十五年，生时为末限，管五十年**，后彻终年。（定三限）
> **遁月从年，则以年为主；遁时从日，则以日为本。主胜于本，多出资荫；本胜于主，当自卓立；主本两胜，则富贵双全。**（阎东叟书）

三个要点：

1. **「主」＝年，「本」＝日。** 这与子平以日为主正相反。断「谁出力」——靠祖荫还是自立——看主本胜负。
2. **三限有确定年限**：初限 25 年、中限 25 年、末限 50 年。这是宋人以「时」为百年的算法，与子平以月令分旺衰完全不同。
3. **胎月是第五柱。** 《鬼谷遗文》：「主本係和，未生贫贱之人；时月乖违，岂见久荣之者。」胎月参与「係和」的判断。

## 四、五行判法：不是「扶抑」，而是「四贵四忌 + 太过不及」

卷八《论五行二》：

> 夫五行之性，大概以**胎、生、旺、库为四贵，死、绝、病、败为四忌，余为四平**。然有生而不生，旺而不旺者，此为凶乃先吉也；有死而不死，绝而不绝者，此为吉乃先凶也。
> 如水见戊申土，此生而不生也；水见庚子土，此旺而不旺也……如水见癸卯金，此死而不死也；水见辛巳金，此绝而不绝也。

以及：

> 五行之用，多则太过，少则不及，其气其数，有余不足，皆能致凶，**抑扬归中，然后为福**。功成者贵于退藏也，将来者贵于荣振也。

请注意「抑扬归中」这四个字——本书**也讲中**，但与《滴天髓》的「中和」是两回事：
- 《滴天髓》的中和，讲的是**日主与财官食伤之间的强弱平衡**；
- 本书的中和，讲的是**纳音五行自身气数的盈虚进退**（功成者退藏、将来者荣振）。

两者名字相近，落点完全不同。

## 五、吉凶神的用法：「扶身／克身」与「轻重校量」

这是本书凶神部分最要紧的一条通则，卷廿七引《珞琭子》：

> **须要明其神杀轻重，校量身克杀而尚轻，杀克身而尤重。**
> 莹和尚注云：吉凶神杀，百有馀坐，或得于日时，或逢于岁运，但以**杀克身而重，身克杀而轻**，更要随器审详，临机消息。

同一条神煞，吉凶可以相反，取决于**谁克谁**。例：

| 神煞 | 身克杀 | 杀克身 |
|---|---|---|
| 劫杀 | 君子得之，气刚志勇，宜为右职，多谋略 | 小人得之，放僻邪侈，梁上君子 |
| 亡神 | 附禄元化为武曲星，「反讶韩信彭越谩雄」 | 被人伤害或伤害人 |
| 三刑 | 身能制杀，当掌刑罚之任 | 多受戮辱，或非命而终 |
| 金杀 | 夹贵兮，有兵有权 | 男刑伤兵刃，女产厄 |
| 六害 | 贵自贵，害自害 | 终不显，遭贬剥 |

**所以本书的神煞不能「见即断凶」**——这一条几乎被后世的神煞派丢掉了。

## 六、贵格的判法：「气数归一」而非「格局成败」

卷廿二《论贵局下》开篇即立总纲：

> **一切福神相还格**：凡禄马、阴官贵、六合、华盖、金舆、文星、贵人、印绶、禄库、食神、奇德之类，皆谓之一福神，递互相还，便是贵格。若无死绝冲破、空亡，有五行旺气，福神……（下略）

所谓「相还」，是指诸福神**互相回环照应**（甲位之福落到乙位、乙位之福回到甲位），不是单点有力。同卷又有：

- **致一凝神**：「敛散抑扬，归于一者，所以为致一之命，乃问世贤辅、出群异人也」；
- **虚中精实**：「年时上下如天地覆载……虽美恶相杂，憎爱相半，无不并包而兼容之」。

判贵的标准是**气是否归一、是否周流不断**，而不是子平的「格局是否成、用神是否有力」。这是本书与后世格局派最大的方法论差异。

## 七、岁运：「虚一待用」

卷卅四《论岁运》第一条即：

> **虚一待用**：发于沉滞之中，有非常之庆；起于贫贱之间，有不次之用，**当在岁运相遇也**。谓金木水火而无土，或乙辛丁而无癸，或甲丙庚而无壬，或辰戌丑而無未……至于六合、四库、三合，交互见贵、见禄之类，**待其岁运，补其不足，则气数备**。（阎东叟书）

命局缺一位，不必即为缺陷，要看岁运能否补上。这与子平「用神受伤则终身受累」的思路也不同：本书认为**缺者为「虚」，逢运补足则为「待用」**，反而可能大发。

## 八、操作流程（可直接照做）

1. **排五柱**：年、月、日、时、胎（胎元＝受胎之月）。
2. **标纳音**：五柱各标纳音五行，查 `02_纳音六十甲子表.csv` 得「取象语／所喜」。
3. **定主本**：年为主、日为本，判主本胜负（谁旺、谁得位）。
4. **判四贵四忌**：各柱纳音在十二长生中的位置，标出胎生旺库／死绝病败。
5. **辨成器与否**：查《玉霄宝鉴》之「未成器金见火则成」「已成器金见火则伤」一类判据。
6. **看合冲刑害空**：干合、支合、三合、六冲、三刑、六害、空亡（以生日旬中空亡为主）。
7. **列福神与凶神**：禄、马、贵神、印、食、三奇、华盖、劫、亡、咸池、金杀……查 `03_神煞起例表.csv`。
8. **校轻重**：逐神问一句「身克杀还是杀克身」。
9. **看贵格**：诸福神是否「相还」、气是否「归一」。
10. **推到岁运**：缺者是否「虚一待用」，旺者是否「功成退藏」。

## 九、常见误读（逐条纠）

| 误读 | 实情 |
|---|---|
| 「甲子」＝甲木坐子水，子水是甲的印 | 本书「甲子」＝海中金，「从革之金，其气散」，忌纳音火 |
| 以日干为日主，看十神 | 本书以**年为主、日为本**，十神名目未立 |
| 「财」＝我克者（日干所克） | 本书「财」以**纳音**为身：禄财、命财、身财三等，各以墓为库 |
| 「官」＝克我者（日干被克） | 本书分「官」「鬼」，且明言「**五行克纳音者为真官**」——干头之官只是浅层 |
| 神煞见即凶 | 「身克杀而轻，杀克身而重」；劫杀、亡神、三刑、金杀皆可反用为权 |
| 华盖必孤 | 「华盖为庇荫之清神……惟与夹贵正印并，则为福清贵」 |
| 空亡一律作废 | 「若月冲日时，时冲年，名曰仇杀」之外，「遇冲空亡，主祸中生福」 |
| 中和即贵 | 本书主「抑扬归中」＋「功成退藏」，且以「气数归一」为贵格标准 |
| 缺一五行即贫 | 「虚一待用」——待岁运补之，反有非常之庆 |

## 十、本书与《三命通会》的关系

《三命通会》（明·万民英）大量沿用本书条目，尤其：
- 六十甲子纳音取象、逐柱评语；
- 神煞起例与断语（天乙、禄、马、华盖、劫杀、亡神、咸池、金杀等）；
- 释日时贵格／凶格一类日时配格表；
- 「论疾病」「论形貌性情」等分门别类的写法。

**但《三命通会》是把三命术与子平术「混编」的书。** 它一面抄本书的纳音条目，一面又以日干十神立论，导致同一神煞在两套体系里的用法并存。读《三命通会》时若见自相矛盾，多半就是这两套体系拼接的痕迹。
