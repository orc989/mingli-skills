# 兰台妙选

## 这是什么

明·西窗老人撰，三卷，现存最完整的**以纳音、地支取象为核心的明代禄命赋文**。全书 220 个格目，其中 109 个含具体干支组合、可实操判断。

它的地位很特殊：被《星平会海》《古今图书集成》收录，但被任铁樵在《滴天髓阐微》里点名骂作「尤属不经，不待辩而知其荒唐也」。**用它的前提是搞清楚它和子平法是两个体系**，不是子平法的补充。

## 判格三步（最关键的操作）

兰台妙选的格比子平格局更机械，但也更容易判错，因为**限制条件极多**。

**第一步：定主体**
年柱（首选）或日柱的纳音是什么。例：甲子乙丑＝海中金，取象「蚌蛤之珠」。

**第二步：定客位**
时支（首选）或日支是什么。例：己未＝天上火，取象「月宫」。

**第三步：逐条核对限制条件——这步最容易漏**

| 格 | 限制条件（不可省略） |
|---|---|
| 蚌珠照月 | 己未生人得甲子乙丑时「亦可引用」——可以反用 |
| 攀龙附凤 | 「辰酉见庚辰，或庚辰见乙酉则非」——乙庚合、辰酉合之外夹了紫暗大煞 |
| 昆山片玉 | 「二金三金非」——过则破格 |
| 凤凰恋禄 | 须三字同干一字异，且年月日时皆藏寅辰 |
| 月照寒潭 | 「须有申酉方可言贵」——无申酉则不成 |
| 龙居沧海 | 「春夏秋间得此格为伏藏无用，惟冬生妙」 |

**季节性条件不是修饰语，是成立的必要条件。** 「惟冬生妙」「更要秋生方为贵」「春夏生显，秋冬虚贵」「日生者非」——这些都不能省。

## 五条纪律

**纪律 1：不与其他体系混断**

兰台格成只说明「此命合某取象格」，不等于「命贵」。一命往往同时中数个吉格与凶格，必须**先列全部格再综合**，不能只挑吉的说。

**纪律 2：格成不等于命贵**

赋文自己的话：「虽仗根基之稳，未饶格局之真」「有禄马之往来反居贫贱，坐凶煞之交互却主光荣」。取象与实体是两回事。

**纪律 3：年柱优先于日柱**

这是禄命法系统的书，以年命为主。日柱用法是后世掺入，两说冲突时按年柱。

**纪律 4：时支权重最高**

绝大多数格以「某年生人得某时」成立，时柱是归宿、是落点。

**纪律 5：与子平/滴天髓并列而不融合**

| | 滴天髓（任注） | 兰台妙选 |
|---|---|---|
| 核心 | 五行生克、气势、用神 | 纳音取象、干支组合 |
| 断法 | 定用神 → 推六亲 | 定纳音 → 配时支 → 核条件 |
| 彼此态度 | 斥其「荒唐」 | — |

两边结论冲突时，如实说明「子平看为 X，兰台格看为 Y」，指出是体系差异，**不做加权平均**。

## 已知缺陷

- **格名不是原书定名**：原文多数格无固定名，`gezi_格目总表.csv` 的格名取赋文首句，仅供检索
- **东里本删过内容**：校者自述「有三段释文为《古今图书集成》所无，今皆删去」，重要异文须回查西窗老人本
- **疑误保留原样**：原文含「（疑此处缺一『酉』字）」这类校勘注，引用时须一并说明
- **220 个格目 ≠ 220 个格**：含大量总论与过渡句，真正可判的约 109 个
- **了无本段落全粘连**：PDF 为扫描竖排，pdftotext 抽取后赋文与释文混成一片，并夹有页边残字，**只能查释义不能引原文**
