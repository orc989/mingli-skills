# 金镖门盲派命理

## 这是什么

金镖门（京南道人一系，师承「老人参」盲师）的完整体系库。本 skill 收录 **9 份原典、1,037 页、157 篇、76.7 万字** 原文，是实战断命工具，不是玄学漫谈。

核心立场一句话：

> **不算「是什么格」，只算「用神是什么」；不讲「旺衰几分」，只讲「能不能承载」。**

与书房派子平分歧明确，详见 `references/05b_与子平诸书的体系分界.md`。

## 三条硬纪律

1. **不以格名论命。** 格局只是找用神的脚手架。原文：「就不用去研究他是什么格，是什么局了，从它最终目的下手就行了。」
2. **不用神煞、不用纳音。** 原文明确判其「多有不验」。全库检索「反吟」「小运」零命中，本门不用。
3. **不给模糊评语。** 只给十二个可证伪的得分点（见下）。超出范围的话要么删掉，要么标明是推测。

## 断命八步

```
第一步  定用神（不看格局名，直接找用神）
第二步  辨承载（能否承载财官 → 决定取用方向）
第三步  定喜忌（帮用神即喜神）
第四步  看顺逆（吉神顺用、凶神逆用；有用之神不可伤）
第五步  抓病药（男犯比劫、女犯伤官、官杀混杂、枭夺食……）
第六步  过三关（工作关 → 婚姻关 → 父母关）
第七步  定应期（大运定乾坤，流年不违大运）
第八步  取象补细节（胎元、借盘、八卦、串宫压运）
```

### 第一步：定用神

分水岭是**日主能不能承载财官**。

- **能承载**（身强）：`官 → 财 → 月令提纲 → 食伤`
- **不能承载**（身弱）：`印 → 比 → 根`；月令是印比者可直接以月令为用神

原文：「找格局的最终目的——就是为了找出用神。」详见 `sec/K04_13`。

### 第二步：辨承载（旺衰六档）

```text
旺极端 / 太旺 / 旺 / 不旺不弱（能承载财官）/ 太弱 / 弱极端
```

**唯一硬判据**：「日主近处有强根，一般就不是身弱。」

注意：「不旺不弱」是最常用也最易误判的一档。但断婚期时例外——**财官过重者，大运流年都要取帮身**，即使事业上可直接取财官为用。详见 `sec/K04_07`、`references/03_旺衰六档表.csv`。

### 第三步：定喜忌

> **帮用神就叫喜神。**

| 用神 | 受谁害 | 喜神 |
|---|---|---|
| 财 | 被比劫克 | 官杀 |
| 财 | 自身弱 | 食伤、财运、财见根 |
| 官 | 被食伤克 | 印 |
| 印 | 被财坏 | 比劫；印衰则官杀为喜神 |

### 第四步：顺用逆用

> 官是尊贵的，印、财、食神，这都是吉利的；伤官、七杀、阳刃，这都是凶猛的。
> **吉神要温柔对待，或者生或者化泄；凶神要制裁它克它。**

但真正的准绳是下一句：

> **有用之神不可伤，无用之神尽可伤。**

官不能用伤官克——**除非这个官没力量、不能主事**，那就可以随便克。所谓「伤官伤尽」，不过是「无用的官」这一角。详见 `sec/K04_14`。

### 第五步：抓病药

| 病 | 适用 | 药 |
|---|---|---|
| 男犯比劫（夺妻） | 男命婚姻 | 官杀制比劫 |
| 女犯伤官（克夫） | 女命婚姻 | 印制伤、财化伤 |
| 日主不立／配偶星不立 | 婚姻 | 印、比劫、见根（哪个先来取哪个） |
| 官杀混杂 | 贵气 | 身弱须去杂；身旺官弱反喜混杂 |
| 枭神夺食 | 全局 | 比劫化枭、财破枭 |
| 财来坏印 | 学业名声 | 官杀（首）、比劫（次） |
| 印太重（水大木漂等四类） | 全局 | 财制印（君赖臣生·反局） |

**病不解，事不成。** 女命 `癸 癸 辛 己 / 亥 亥 亥 丑`：女犯伤官，若印星一直不来，断为独身；来了才结婚。

### 第六步：过三关

1. **工作关**：`找格局 → 检查格局是否成立 → 取象`。**不能直接取象**——火克金可能是设计院画图（国有）、电工、电子厂，格局不定取象必错。工作只分三种：吃皇粮的、私人打工、自己开买卖。
2. **婚姻关**：职业命师只断五件事——何年结婚、是否离婚／何年、是否出轨／何年、是否克夫克妻、几次婚姻。「除此以外，皆为没有说服力的断语，非本门风格。」
3. **父母关**：`胎元 → 六合 → 暗合 → 六冲 → 六穿 → 三合 → 三会 → 三刑 → 六亲定位 → 八卦取象 → 借盘法 → 六亲属相`。

### 第七步：定应期

> **大运定乾坤，流年是不能和大运相违背的。**

大运已「表了意思」（帮身），流年符合这个意思即可（印、比、根皆可）；大运若明确「来了印」，流年就**只能**选印。断婚期通常报两个年号（一年订婚、一年领证婚礼）。

### 第八步：取象

三层：**干支类象** → **胎元八卦象** → **串宫压运象**。取象只作补充，不作结论。

## 婚姻五大法则（最常用）

详见 `references/02_婚姻五大法则表.csv` 与 `sec/K04_06`。

1. **定位夫妻星**——家里的财官，即**坐下或时上**的财官。不分男女；男以财优先，女以官杀优先。再加阴阳：群阴独阳、群阳独阴时取异性。日时没有再去年月找。特殊情况下比劫、印、食伤亦可为夫妻星。
2. **不立，非印即比根**——日主或配偶星立不住时，结婚只在「印来 / 比劫来 / 见根」三种年运，哪个先来取哪个。
3. **男犯比劫、女犯伤官必解**——病不解决，夫妻星到位也结不成；一辈子不解则断为独身。
4. **大运的语言提示**——大运定乾坤，流年不违大运。
5. **干支拦截**——夫妻星到位但被合冲穿墓伏吟拦截，须看过不过得去。

> 注意：**同居不算结婚。** 原文反复强调，只有领证或办婚礼才算。

**必背三首**：

> **十排歌**（第一道·总纲）
> 先看天干做何事，再查地支有何意；
> 升天入地加伏吟，刑冲合穿为动门；
> 分清动静和体用，看命断事细如神。

操作：日干在做什么？只有两种——**生**（生食伤，再看食伤做什么）与**合**（阳干合财、阴干合官）。天干既不生也不合，才看日支。

> 劫财伤官见官符，吃上牢饭不自由。

> 生辰八字看婚姻，鸳鸯门中寻宫星；
> 宫星相配和谐美，宫坏星伤徒伤情；
> 财是命中情缘线，男女财星不可断。

## 六亲定位：胎元与借盘

详见 `references/06_六亲定位与三关表.csv`、`sec/J02_07`、`sec/J02_08`。

**九步**：宫位 → 本元 → 六亲星 → 扶神/制神排序 → 扶神互战与通关 → 借盘法 → 胎元法 → 八卦取象 → 空亡校正。

两个关键定义：

- **胎元** = 月干前一位为胎元干、月支前三位为胎元支。用法**不是查纳音**，而是以日干定位胎元干支（及支中藏干）为十神，再还原为卦。原文：「先天一气是本元」「胎元定一人所带是福禄还是恶业」。
- **借盘** = 原局无该六亲星时借用。「要借和日干同性的六亲，就找和日干同性的干；要借异性的，就找异性的干。」先看月干是否与日干同性。

**扶神/制神排序**：生为第一、比为第二；克为第一、泄为第二、耗为第三。日支能「通关」则化解，不能通关则成「互战」。

## 使用与输出规范

1. **先判承载，再取用。** 跳过旺衰直接取用是最大错误来源。
2. **只输出十二个得分点范围内的结论。** 超出范围的要么删除，要么明确标注「推测」。
3. **引用原文必须注明篇号**（如 `K04_06`），四柱干支加来源。
4. **干支存疑要标注。** 四册 OCR 的命例干支可信度低，引用前核一遍（见 `07_校勘须知.md`）。
5. **遇分歧先怀疑 OCR，不怀疑理论。** 例如「氮印」「桌印」「抽印」正字都是「枭印」。
6. **不要把本门与子平真诠折中。** 两套回答的不是同一个问题：本门答「日主扛不扛得住、哪年应事」，真诠答「格局成不成、贵在何处」。
7. **本门《滴天髓》讲解是「金镖门化的解读」**，不是任铁樵注原意。引用时标明「金镖门讲法」；要查文义请用「滴天髓」skill 的校勘本。
