# 刚柔

2021.3.27 刚柔

  春木、夏火、秋金、冬水、季土，得时当令，原局无克制之神，其势雄壮，其性
刚健，不泄则不清，不清则不秀，不秀则为顽物！
  这个春木，夏火，秋金，冬水和季土，都是得时当令的，那日主得时当令的，自
然就强，就刚建。日主旺，肯定就得用克或是用泄，如果原局没有克制日主的；或克
制日主的五行，没根没气，没有力量的，实际克制日主的就是官杀。
  没有克制的，就得需要找泄，用泄的方法来达到五行平衡，就是用食伤，因为日
主得时当令，身旺就刚建。但是不管用什么手段，用克也好，还是用泄也好，它都是
为了让五行保持平衡。
  这个“刚”，也就是通根月时的日主，它身旺，很旺的那种。要么就用以暴制暴，
用“克”的方式，用官杀；要么就是释放它的能量，用“泄”的方式。
  还有一种是日主刚健，就是很旺的时候，而对方财官一方，或食伤一方太柔弱，
太衰弱无力，无根无气，那么就只能“从”旺的一方了，因为对方的力量太弱小了；
日主旺极，而财官或食伤无根无气的，它就弱小，这时就得考虑“从”。
  比如日主是庚金，全局都是金，然后天干透一个丙火，这个丙火无根无气，那丙
火就是柔弱的，日主是刚建的。无根的丙火就制不了旺金日主，反倒激怒庚金了，因
为庚金很旺，这时丙火就成病神了，太柔弱的就不能为用，反倒为病了。
  春金、夏水、秋木、冬火、仲土，失时无气，原局无生助之神；其势柔软，其性
至弱，不劫则不辟，不辟则不化，不化则为朽物！
  这个是春金，夏水，秋木，冬火，还有仲土，日主是失时无气的，就是不通根月
令；这种情况下，日主肯定是弱的，如果命里再没有帮扶的十神，它就属于弱不受生
了，不如就“顺从”了。
  就是越弱越好，就是“从”的意思，但前提是原命局没有帮扶的时候，因为本身
就不占月令了，地支再无根无气，无生无助的。
  泄者，有生生之妙；克者，有成就之功；引者，有和悦之情；从者，有变化之妙！
  上面都是介绍什么叫“刚柔”，那下面就具体看看如何取用
  “刚柔”是怎么取用神的
  “刚柔”，一般都是围绕着四种情况，始终围绕着这个“泄”“克”，“引”，
“从”，这四个字。

               辛丑年弟子班中册

      第一个是：“泄”
      就是刚才说的，没有克的时候，就要用泄，也就是“泄秀”的意思。因为日主得
时当令，刚健，这时就得考虑用泄的方式。
      但是这个“泄”，不光是指日主刚健的时候用泄，扩展一下，这个泄，不光是用
食伤泄秀的；还有食伤旺的时候，也可以用财泄秀，这个财也是泄食伤的，这也是泄
的一种方式，要不为啥总说食伤生财呢，就是这个意思
      还有官煞旺，用印的，这印也是泄官杀的；主要是看命局的意向。还有命局给的
是什么条件？这里说的“泄”，只是说身旺用食伤泄秀，咱们只是扩展一下思维，这
一定要记住了，它是有区分的，但是得知道。
      第二个是：“克”
      比如身旺用官煞的；财旺用比劫的；食伤旺用印的；实际这都是“克”。但是这
里说的“克”，主要说的是身旺的时候，用“克”的方式，没有泄就可以找克。
      第三个是：“引”
      “引”，一般都是官煞旺
      X 庚 甲 X
      X 申 子 X
      比如这个命例，官杀庚金得时当令，肯定是旺，而日主柔弱，这时就得用子水印
星，来引通庚申的肃杀之气；这就是“引”的意思，这个“引”，有“和悦”之情。
      第四个是：“从”
      “从”，无非就是什么从格，什么从旺，从势，从强这些。
      最后总结一下无非就是两条
      第一条：就是日主得时当令，身旺刚建的
      这时取用神，就得考虑用“克”或者用“泄”的方式。
      如果日主是旺极的那种，“克”或者“泄”都休囚了，也就是没有力量了，克和
泄都不能取用了，这时就得考虑“从”了。
      第二条：是日主失时休囚的
      这时肯定就是身弱了，取用神，就得考虑印比帮身或者生身；如果没有印比的时
候，用食神制杀的时候，日主必须得有根有气，日主它不能太弱。
      如果日主弱极，没根没气，没有印比帮身的，或者印比也是无根无气，就得考虑
“从”。大体总结基本上就是这两条。

                   辛丑年弟子班中册

年干透了一个千水泄秀，但壬水坐戌土上了，还被戊土克了一下，也就是枭神夺食了。

能为用了。好在时干又透了一个丙火，丙火有根有气，所以就不用王水了，只能用丙

  命主甲寅运克去戊土，又生丙火用神，这步运他发财了。这个命例就是用火克的，

  这两个命例非常典型，都是身旺刚建，究竟是用克还是用泄？
  这两个命例就很能对比出来。
