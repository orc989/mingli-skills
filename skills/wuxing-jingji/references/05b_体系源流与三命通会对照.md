# 体系源流与《三命通会》对照

## 一、本书的坐标

| 项 | 内容 |
|---|---|
| 书名 | 《五行精纪》 |
| 卷数 | 三十四卷 |
| 撰者 | 宋·廖中 |
| 序跋 | 岳珂跋（南宋绍定元年戊子，1228） |
| 体系 | 三命术／纳音五行一系（非子平） |
| 性质 | **宋人纳音命理的集大成总集**，辑录而非自撰 |
| 体量 | 正文约 18.3 万字（本 skill 切分后统计） |
| 结构 | 卷一—二：六十甲子纳音；卷三—六：干神、支神；卷七—九：五行；卷十—十二：年月日时胎、日时贵格、十二月节气；卷十三—廿二：吉神与贵局；卷廿三—廿七：凶神凶杀；卷廿八—卅二：杂例、六亲、形貌、疾病、寿夭；卷卅三—卅四：大运、小运、岁运 |

### 为什么说它是「总集」

三十四卷里，廖中本人几乎不发言，通篇是「某书云」「某氏云」。据本 skill 统计，可辨的引用来源近四十家（见 `04_引用书目.csv`）。其中征引最密的几家：

| 来源 | 次数（约） | 性质 |
|---|---|---|
| 广信集 | 65 | 佚 |
| 壶中子 | 45 | 佚 |
| 烛神经 | 45 | 佚 |
| 神白经 | 42 | 佚 |
| 王氏注／莹和尚注 | 41／42 | **传世**（《珞琭子三命消息赋》两注） |
| 沉芝源髓 | 36 | 佚 |
| 五行要论 | 35 | 佚 |
| 广录 | 31 | 佚 |
| 金书命诀 | 28 | 佚 |
| 三命提要 | 25 | 佚 |
| 鬼谷要诀／遗文／命格 | 31 | 佚（托名） |
| 三命钤 | 21 | 佚 |
| 阎东叟书 | 19 | 佚 |
| 珞琭子 | 19 | 赋文传世 |
| 天元变化书 | 17 | 佚 |

**这意味着**：想读通本书，靠的不是「理解廖中的思想」（他基本没有自己的主张），而是**辨认每一段话属于哪一家、哪一系**。同一件事，`广信集` 与 `烛神经` 说法不同是常事，本书往往并列而不裁断。

## 二、本书在命理史上的位置

```
唐 李虚中（三命术，以年为本）
        │
        ├── 五代—北宋：《珞琭子消息赋》王/莹二注、阎东叟、林开、李九万、壶中子、沉芝源髓……
        │            （纳音＋神煞＋禄马的密术系统）
        ▼
南宋 廖中《五行精纪》（1228 岳珂跋）── 辑录以上诸家，成 34 卷总集
        │
        ▼
明 万民英《三命通会》── 大量沿用本书条目，同时混入子平术
        │
        ▼
明清 子平术成为主流，本书几近失传（《四库》未收）
```

与另一条线的关系：

```
北宋 徐子平（以日干为主）
     └─ 南宋 徐大升《渊海子平》
          └─ 明 万民英《三命通会》（两系混编）
               └─ 清 《子平真诠》《滴天髓》
```

**两条线在《三命通会》处交汇，而《五行精纪》是左线（纳音线）在宋代的终点。**

## 三、与《三命通会》的逐项对照

| 项目 | 《五行精纪》（宋，纳音系） | 《三命通会》（明，混编） | 注意 |
|---|---|---|---|
| 论命主体 | 纳音 | 日干为主，纳音为辅 | 会通卷首即言「日干为主」，但其纳音章节整段抄本书 |
| 年柱 | 为主（本命） | 为祖上、少年 | 断「资荫／自立」须用本书主本法 |
| 胎元 | 第五柱，参与係和 | 有「胎元」一节，实际少用 | 会通「论胎元」多采本书 |
| 十神 | 未立「十神」之名，只有官、鬼、财、印、食 | 十神齐备 | 会通把本书的「官／鬼」并入十神，导致同名异义 |
| 官 | **克纳音者为真官**，干头克我者为浅 | 克日干者为正官／七杀 | 这是两书最容易读混的一处 |
| 财 | 禄财／命财／身财三等，各以墓为库 | 我克者为财（日干） | 同上 |
| 六十甲子 | 逐柱取象＋逐柱评语（卷一、卷二） | 「论纳音取象」整段沿用 | 会通的纳音章几乎可直接回溯本书 |
| 神煞 | 分十三—廿七卷共十五卷专论，密度极高 | 有「神煞」诸卷，条目大半同源 | 会通删减了本书的「轻重校量」原则，只留条目 |
| 吉格 | 贵局重「福神相还」「气数归一」 | 重「格局成败」 | 会通把本书的贵局拆散成格 |
| 日时配格 | 卷十「释日时贵格」、卷十一「释日时凶中凶格」——逐日逐时列表 | 会通「日时」诸卷沿用此类表 | 这类表是宋人实务记录，非理论 |
| 女命 | 卷廿九专列「释女命例」，与男命并列 | 会通「女命」卷 | 两书都重「夫子两星」，但取法不同 |
| 小儿 | 卷廿八「释小儿例」，专论关煞 | 会通「小儿」篇 | 关煞名目高度重合 |
| 疾病 | 卷卅一「论疾病」：五行相克成疾、相生生疾、诸杀主疾 | 会通「论疾病」 | 会通此篇基本是本书的节本 |
| 形貌性情 | 卷卅「论形貌性情」：五行形性＋十干合性情 | 会通「论性情」「论形貌」 | 同上 |
| 运 | 大运、小运、二运、岁运，另立「虚一待用」 | 大运、小运、流年 | 会通无「虚一待用」之说 |

### 三处最易混淆的「同名异义」

1. **「官」**
   - 本书：`季主云：旺处逢鬼鬼化官，衰处官官化鬼。`（卷十七，广信集引）——官鬼以**纳音受克**为准，且可随旺衰互换。
   - 会通：正官／七杀以**日干**为准，官鬼不可互换。
2. **「财」**
   - 本书：`禄命身三等财库者，取我克者为财……甲子金，甲为禄属木，木克土，故土为禄财`（卷十九）——「我」是**纳音之我**。
   - 会通：我克者为财，而「我」是**日干**。
3. **「身」**
   - 本书：身＝**纳音**（`金为身，金克木，故木为身财`）。
   - 会通：身＝**日主**。

> 只记一句：**本书里凡是「我」「身」「命」，先问一句是纳音还是日干。** 全书九成的误读都出在这里。

## 四、与其他典籍的关系

| 典籍 | 关系 |
|---|---|
| 《珞琭子三命消息赋》（王／莹二注） | 本书卷十七、廿五、廿七、卅二、卅三大量引其赋句并附注，是本书与传世文献唯一能直接对校的接口 |
| 《李虚中命书》 | 本书卷十「三主论」、卷十七「生成官」标为「李虚中书」；但今本《李虚中命书》为宋人辑本，二者孰先孰后难定 |
| 《玉照定真经》 | 同为宋人纳音系，可比对但本书未直接引 |
| 《渊海子平》 | 体系相反（日干为主），不可互证 |
| 《滴天髓》 | 「中和」二字同名异实：本书的「中」是气数盈虚之中，非日主强弱之中 |
| 《神峰通考》 | 明确的辟谬之书，其「病药说」与本书「四贵四忌＋抑扬归中」在方法上对立 |

## 五、版本与文字

- 本书《四库全书》未收，通行本主要来自明清抄本与《续修四库全书》系统。

  3. 底本编者夹入的校记（「（ps：……）」形式）。
- 详见 `06_校勘须知.md`。
