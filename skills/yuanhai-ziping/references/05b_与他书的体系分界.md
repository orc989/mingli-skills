# 渊海子平与他书的体系分界

> **本篇是使用本 skill 的第一道闸门。** 子平术与纳音系（三命术）分属两个体系，工具、坐标、推论链全不同。混用是今日命理实践中最常见的系统性错误。本篇给出可操作的辨识标志与取舍准则。
>
> 与本书对照的其它著作，见本 skill 库中的 `sanming-tonghui`（三命通会）、`wuxing-jingji`（五行精纪）、`lantai`（兰台妙选）、`ditiansui`（滴天髓）、`qiongtong-baojian`（穷通宝鉴）、`qianli-minggao`（千里命稿）、`mingli-tanyuan`（命理探源）、`shenfeng-tongkao`（神锋通考）。

---

## 一、一句话分界

**子平：以日干为主的十神体系。**
**三命：以年柱为主的纳音体系。**

《论日为主》（第5篇）已经把这条界线画得很清楚：

> 予尝观唐书所载，有李虚中者，取人所生年月日时干支生剋，论命之贵贱寿夭之说，已详之矣！**至于宋时，方有子平之说；取日干为主**……

而《详解定真论》（第49篇）更进一步，直接否定纳音取法：

> 【理愚歌】云：『五行真假少人知，知时须是洩天机』是也。**俗以甲子作海中金**，即娄景之前，未知金在海中之论。……**或以年为主者，则可知万亿富贵相同者**；以甲子年生，便可为本命忌日之戒。

两句话，两个否定：**否定了纳音取象（甲子海中金），否定了年柱为主（同一年生者富贵相同）。**

## 二、硬指标：这个词在本书中出现几次

判断一段论断是否属于子平体系，最快的办法是数关键词。

| 关键词 | 本书（85篇·5.5万字）出现次数 | 属何体系 | 判定 |
|---|---|---|---|
| **纳音** | **0 次** | 三命术核心 | **本书完全不用** |
| **命宫** | **0 次** | 三命术／星宗 | **本书完全不用** |
| **胎月** | **0 次** | 三命术（以胎月为第五柱） | **本书完全不用** |
| 胎元 | 3 次（仅「五行绝处即是胎元」一义） | 借用名目，非纳音义 | 可作参考，不作主轴 |
| 阳刃 | 81 次（35 篇） | 子平神煞（日干本位） | 本书核心神煞 |
| 羊刃 | **0 次** | 后世写法 | 本书一律作「阳刃」 |
| 神煞 | 4 次 | 两系共用，但态度不同 | **本书只作「轻重较量」** |

> 【按】「纳音 0 次」是本 skill 最重要的单一事实。若见到以纳音论子平命局的解法，那是**后人的混合体**，不是本书的用法。同样，「命宫」「胎月」在本书中完全缺席，任何以命宫／胎月起论的推断，都不应以本书为据。

## 三、坐标对照表

| 维度 | 渊海子平（子平术） | 三命通会／五行精纪／兰台妙选（纳音三命术） |
|---|---|---|
| **命主** | 日干（日主／日元） | 年柱（本命） |
| **四柱角色** | 年根·月苗·日花·时果；日为身，日支为妻 | 主本论：**主为年、本为日**；三限 25/25/50 |
| **第五柱** | 无 | 胎月（胎元） |
| **五行载体** | 干支本气（甲乙木、子亥水） | **纳音**（甲子海中金、丙寅炉中火） |
| **核心工具** | 十神（比劫食伤财官印） | 纳音五行 + 神煞 + 禄命身三命 |
| **月令地位** | **提纲，定格局之唯一根据** | 参看之一 |
| **取格** | 只取六格：官印财杀食伤 | 可至数十格，另加纳音格 |
| **神煞地位** | 辅助，只校轻重 | **主体之一**，起例动辄数十百条 |
| **贵贱判据** | 身与财官相称、格局成败 | 纳音清浊、禄马贵神、煞之轻重 |
| **典型断语** | 「财多身弱，正为富屋贫人」 | 「甲子从革之金，忌丁卯丁酉戊午之火」 |

## 四、三命术的核心概念，在本书中如何对应

若要跨体系参照，须先弄清概念如何转换，不可直接搬用。

| 三命术概念 | 在本书中的对应物 | 转换说明 |
|---|---|---|
| 纳音五行 | **干支本气五行** | 甲子在三命为海中金，在子平为甲木坐子水（印）。二者结论常相反 |
| 禄命身三命 | **日主与财官** | 三命的「禄」近于财官，「命」近于日主，「身」近于纳音 |
| 胎月（第五柱） | **无对应** | 本书不取胎月，切勿补入 |
| 命宫 | **无对应** | 本书不取命宫 |
| 主本（年主日本） | **年根日花** | 名近而实异：三命以年为主轴，子平以日为主轴 |
| 纳音相生剋为真官真财 | **十神生剋** | 「五行剋纳音者为真官」是纳音逻辑，子平只论「剋日干者为官」 |
| 神煞轻重 | **神煞轻重较量** | 这一点两系方法**相通**：都说「杀克身而重，身克杀而轻」，须校轻重 |

> 【按】最后一行值得注意：**两系在「神煞须校轻重」上方法相通**，这是可以合法借鉴的一处。但「校轻重」的标准不同——三命看煞与纳音的关系，子平看煞与格局成败的关系。

## 五、与各书的具体冲突点

### 与《三命通会》

| 议题 | 渊海子平 | 三命通会 | 取舍 |
|---|---|---|---|
| 命主 | 日干 | 年为主、日为本（二说并存） | **不可混**。用子平即用日干 |
| 纳音 | 明确否定 | 大量使用，专列纳音诸篇 | **不可混**。本书立场鲜明 |
| 神煞 | 6 篇，且皆日柱本位 | 数十百条，专卷 | 子平只取「关涉格局」的数条 |
| 格局数量 | 只六格，余者斥为「妄立」 | 极多，分门别类 | 子平严守六格 |
| 女命 | 身弱为贵，夫星一位 | 亦有女命专论，口径部分重合 | 可参，但以本书为底 |

### 与《五行精纪》

《五行精纪》是**纯粹的纳音辑录体**，其四条核心结论（纳音为体、主本论、神煞校轻重、辑录多源）在本书中只有第三条部分相通。凡遇「纳音为体」「三限 25/25/50」「胎月为第五柱」，一律判为三命术，不得用于子平命局。

### 与《兰台妙选》

《兰台妙选》专论**纳音格局**（如「学堂词馆」「玉井奥诀」一类），全书以年柱纳音为骨。与本书体系不相容，**不可交叉引用**。

### 与《滴天髓》

《滴天髓》与本书同属日主体系，且有明显承接：皆重「日主强弱」与「用神」。但《滴天髓》更重**五行气势流通**，本书更重**月令格局与十神配合**。二者可互补，冲突不大。唯《滴天髓》少谈神煞，本书尚存神煞余波，此处须留意。

### 与《穷通宝鉴》

《穷通宝鉴》以**十干配十二月令**论调候用神，与本书「月令定格局」取径相近而重心不同：一重调候（寒暖燥湿），一重格局（官印财杀食伤）。**可并行，不可替代。**

> 【按】本书卷一《论天干地支暗藏总诀》（第2篇）按月分日列当令之神，与《穷通宝鉴》的月令分日用事方法**同源**，这是两书可以互校的地方。见 `05_体系与方法论.md` 第四节第二步。

### 与《千里命稿》《命理探源》

二者皆为近现代整理之作，体系上已属日主一路，与本书承接。差异在体例与用语现代化。可作入门阶梯，但**断语分寸须以本书原文为准**。

### 与《神锋通考》

《神锋通考》偏神煞与刑冲，与本书「神煞退居辅位」的立场不同。引用时须标明属神煞专书，不可据以推翻本书的格局判断。

## 六、混用的四种典型错误

### 错误一：用纳音断子平局

如见甲子日，断「海中金，怕火」，再寻丙寅炉中火为害。
**错在哪**：甲子在本书是甲木坐子水，子中癸水为正印。火（丙丁）对甲木是食伤，非「剋金之火」。
**正解**：先看月令归格，再论丙丁（食伤）在格中是喜是忌。

### 错误二：用年柱定格局

如见年柱庚申，便断「年上七杀格」。
**错在哪**：《宝法第二》（第58篇）：「皆以月令为用，**不可以年取格**。」
**正解**：年柱只论祖业盛衰与少年运（《论月令》第6篇），格局必从月令取。

### 错误三：补入命宫、胎月

**错在哪**：本书「命宫」0 次、「胎月」0 次。补入即改变体系。
**正解**：若确需用命宫，须明确声明「此为三命／星宗取法，非渊海子平本法」。

### 错误四：以神煞定命

如见魁罡即断大贵或大凶，不看月令格局。
**错在哪**：《四言独步》：「神煞相绊，**轻重较量**，先观月令，论格推详。」神煞在格局之后。
**正解**：《论魁罡》自己就说「运行身旺，发福百端；**一见财官，祸患立至**」——魁罡的吉凶取决于格局与运，不取决于日柱本身。

## 七、可合法借鉴的三处

分界不是隔绝。以下三处两系方法相通，可以参用：

1. **「神煞须校轻重」**——两系共识。子平的表述在《四言独步》与《喜忌篇》：「神煞相绊，轻重较量」。
2. **「五行有救则凶反为吉」**——《论太岁吉凶》：「五行有救，其年反必招财。」这与三命术的「有制则煞化为权」同理。
3. **月令分日用事**——本书第2篇与《穷通宝鉴》同源，可互校节气深浅。

## 八、使用本 skill 时的三步判体系

遇到任何一条命理判断，先过三问：

1. **命主是谁？** 日干 → 子平；年柱或纳音 → 三命。若混杂，先拆开。
2. **工具是什么？** 十神、月令格局 → 本书可用；纳音、命宫、胎月、三限 → 非本书。
3. **神煞在第几位？** 在格局之后校轻重 → 本书；在格局之前定命 → 三命。

三问有一问答错，就应回到本 skill 的 `05_体系与方法论.md` 重走一遍八步次第。
