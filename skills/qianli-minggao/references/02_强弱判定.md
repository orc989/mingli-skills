# 强弱判定（第一步）

> 出处：`vol_qiangruo.md`（强弱篇，PDF 021—023）；`vol_tiangan.md`（天干篇「气」「势」两项）；`vol_dizhi.md`（地支篇）；`vol_renyuan.md`（人元篇）。

## 1. 三个层次：得令、得地、得势

韦千里把「强」拆成三个独立来源，这一拆法比《子平真诠》的「得令得地得势」更细，因为他对每一项都给了**「最强／中强／次强」的分档**。

### 1.1 得令（月令）

「当令即月令旺相」。查 `vol_tiangan.md` 每干「势」项：

| 干在四季 | 势 | 说明 |
|---|---|---|
| 木旺于春 | 最旺 | 相于冬（次旺）、休于夏（衰）、囚于四立前各十八天（次衰）、死于秋（最衰） |
| 火旺于夏 | 最旺 | 相于春、休于四季月、囚于秋、死于冬 |
| 金旺于秋 | 最旺 | 相于四季月、休于冬、囚于春、死于夏 |
| 水旺于冬 | 最旺 | 相于秋、休于春、囚于夏、死于四季月 |
| 土旺于四立前各十八天 | 最旺 | 相于夏、休于秋、囚于冬、死于春 |

> **注意土的「旺」不在四季末月，而在四立前十八天。** 这与多数命书的「土旺四季」说法不同，是本书的一个特点（`vol_tiangan.md` 引《神枢经》《历例》为据）。四季末月（辰戌丑未）对土只是「相」。

### 1.2 得地（日支与其余三支）

查 `vol_tiangan.md` 每干「气」项，即十二宫。示例（甲木）：

```
长生在亥，沐浴在子，冠带在丑，临官在寅，帝旺在卯  ← 以上为气之盛
衰于辰，病于巳，死于午，墓于未，绝于申，胎于酉，养于戌  ← 以上为气之衰
```

判读规则：
- **临官、帝旺**＝得地（最实）
- **长生、冠带**＝得气（尚可用）
- **衰、病、死、墓、绝**＝失气
- **胎、养**＝无力但不算绝

> **日支最亲、月支次之、年时又次**。这是通行排序，本书在强弱篇未明说，但在评断举例中处处按此权重（例三「长生于亥，胎于酉，得禄于寅，地支有气，尚非至弱」——三支各给了一个不同权重）。

### 1.3 得势（干支同类与印）

即帮扶的**数量与质量**。注意「质量」有两层：
1. 该字自身是否有根；
2. 该字是否被合会被改变性质。

**关键判例（评断篇例四）**：甲生辰月，见三土二金，财杀太旺。辰土本是财（耗身），但因会子辰成水局，**辰土之财化为印**，反而生身，「故专弱为强」。→ **同一个字，位置与会合不同，身份可以变。**

**关键判例（评断篇例一）**：丙生子月，未戌己土虽能制水，但「本身先泄丙火之气」，所以不算扶助。→ **能制忌神的字，若同时泄日主，则不计为扶。**

## 2. 强弱的九档

原书把强、弱各分三档，共六档；加上「至强＝外格从旺」与「至弱＝从格」，实际是九档。

### 2.1 身强三档（`vol_qiangruo.md` PDF 021—022）

| 档 | 条件 | 原文举例 |
|---|---|---|
| **最强** | 既当令，又多帮扶 | 甲寅 丁卯 甲子 甲子：「甲木旺于春月，又卯为帝旺，故当令；四柱又有四木两水帮扶」 |
| **中强（甲式）** | 仅多帮扶而失令 | 甲寅 癸酉 乙亥 丙子：乙木死于秋酉月、又为绝地，故失令；然四柱三水座（+）木帮扶 |
| **中强（乙式）** | 仅得令而少帮扶 | 甲寅 丙子 壬寅 丙午：壬水旺于冬、子月帝旺故得令；然四柱全无金水帮扶 |
| **次强** | 既不当令，又少帮扶，但年日时支得气 | 辛亥 丁酉 甲寅 丁卯：甲木死于秋故失令，天干全无水木帮扶，仅亥年长生、寅日临官、卯时帝旺「皆得气」 |

> **注意中强有两种**——多帮扶失令、得令少帮扶，二者**同级**。这意味着韦千里认为「月令」与「帮扶数量」权重相当，不是「得令绝对优先」。

### 2.2 身弱三档（PDF 022—023）

| 档 | 条件 | 原文举例 |
|---|---|---|
| **最弱** | 既失令，又多克泄 | 戊申 庚申 甲午 庚午：甲木死于秋故失令，四柱又有丙火之泄、四金之克 |
| **中弱（甲式）** | 仅多克泄，而当令 | 丙辰 庚寅 甲午 庚午：三火之泄、两金之克，然甲木旺于春，颇当令 |
| **中弱（乙式）** | 仅失令，而少克泄 | 甲寅 丙子 丁卯 己巳：丁火死于冬、失令；然四柱不复见水克与土泄，且有四木两火帮扶 |
| **次弱** | 既不失令，又少克泄，但年日时支无气 | 辛巳 辛丑 壬寅 癸卯：壬水旺于冬当令，天干两金一水帮扶；仅巳年壬绝、寅日壬病、卯时壬死、丑月壬衰，四支失气 |

### 2.3 至强与至弱：从格的门槛

- **至强无抑** → 从旺格／从强格（见 `03_格局与用神.md`）。原文辨义：「**从旺者，本身之旺也**（印绶不过为其宾耳）；**从强者，身与印平均，而神皆旺也**」（PDF 045）。
- **至弱无扶** → 从财／从官／从杀／从儿格。判例即许世英造（PDF 081）：四柱纯金、乙木凋零，人皆以从杀推；韦断**不从**，理由是「年头癸水进气，泄金生木，乙有根原」→ **只要有一点生机，就不作从格**。

> **从格纪律**：从格的门槛是「绝无生扶之机」，不是「看起来弱」。凡有一字可为根、一气可为援，即按身弱用印比论。原书三处判例（许世英、宣统、郑君）都遵循此律。

## 3. 身强身弱的喜忌（判第五步「喜忌」的基准）

`vol_qiangruo.md` 给了两个对称的三＋四结构：

### 身强喜抑，抑之四因

| 因 | 定义 | 例 |
|---|---|---|
| 受克 | 克我 | 甲木见金克 |
| 被泄 | 我生 | 甲木见火泄 |
| 被分 | 我克 | 甲木见土分 |
| 气衰 | 地支走衰病死墓绝 | 甲木见辰巳午未申酉戌 |

### 身强忌扶，扶之三因

| 因 | 定义 | 例 |
|---|---|---|
| 受生 | 生我 | 甲木见水 |
| 得授 | 同我 | 甲木见木 |
| 气盛 | 地支走长生临官帝旺 | 甲木见亥子丑寅卯 |

### 身弱喜扶、忌抑

把上两组的「喜／忌」对调即可。原文明确：「身弱忌抑，抑之构成，见前论身强之喜忌。」

> **实操提示**：这两组是**评估「任何一字对日主的作用方向」的坐标系**。论喜忌时不必重新推理，只需判断该字落在哪一格。

## 4. 人元（支藏天干）的权重

`vol_renyuan.md`（PDF 017—018）给了三档，这是判「得地」精细度所必需：

| 档 | 内容 | 说明 |
|---|---|---|
| **最重** | 月支内之人元属月之本气者 | 如申月之庚，庚与申皆属金 |
| **次重** | 月支内所暗藏之人元 | 如申月暗藏之戊壬，虽非本气 |
| **稍轻** | 年日时支内所藏之人元 | 与月支相较则力减轻 |

同篇另列「人元之利」两条（补干支之不逮、增干支之力量）与「人元之害」两条（助干支为虐、破坏干支之精采），各附命例。后两条尤其值得注意：**支藏之字并不总是帮忙的**——它也可能把格局的「精采」冲掉。

例（PDF 018）：乙未 戊寅 戊辰 庚申。戊土甚重，本应泄秀于庚申二金；但寅中所藏丙火克去时干庚金，时支申中庚金又冲去寅中丙火，**「精采尽为破坏」**。→ 这是「人元之害」的标准案例。

## 5. 快速判定流程（可直接执行）

```
1. 日干是什么？查 vol_tiangan.md 该干条目，抄下：
   - 气：长生在哪、临官在哪、帝旺在哪
   - 势：在四季分别属旺/相/休/囚/死
   - 生：谁生我；克：谁克我；合：与谁合；化：在何月可化

2. 日主生月 → 定「得令 / 失令」，并记下是旺相休囚死中哪一档

3. 看日支 → 是临官帝旺（得地）／长生冠带（得气）／衰病死墓绝（失气）

4. 统计帮扶（比劫＋印）与克泄（食伤＋财＋官杀）
   注意：逐字检查
   - 该字有根吗？
   - 该字被合会被改变性质吗？（辰会子辰成水则财化印）
   - 该字是否「制忌神的同时泄日主」？（未戌土制水但泄火 → 不计扶）

5. 三档归位：
   当令＋多扶 → 最强
   当令少扶 / 失令多扶 → 中强
   失令少扶 + 年日时支得气 → 次强
   反之为弱，同构三档

6. 边界检查：
   有抑否？无抑 → 考虑从旺/从强（须至强）
   有扶否？无扶且无一线生机 → 考虑从财官杀儿（门槛极严）
   凡有一字可为根 → 不作从格
```

## 6. 三个易错点（实测）

| 易错 | 正确 | 依据 |
|---|---|---|
| 见满盘比劫即断身强 | 看有无抑、有无根。满盘比劫而日主无根于月令且气衰，仍按弱论，或入从旺 | 身强之构成须「当令」或「多帮扶＋有气」 |
| 见土即断能制水 | 未戌土制水同时泄火，对火日主不算扶 | 评断篇例一 |
| 见财即断耗身 | 财会印局（辰会子辰）则化为印，反生身 | 评断篇例四 |
