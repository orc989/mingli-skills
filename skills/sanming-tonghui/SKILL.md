# 三命通会（明·万民英）技能

## 一、三条硬纪律

**① 卷次必须先对上，再答。**

本书十二卷，各卷体裁完全不同，混用即错：

| 卷 | 体裁 | 答什么 |
|---|---|---|
| 卷一 | 五行本源、纳音 | 「五行为什么这样生克」「某甲子纳音是什么、取象为何」 |
| 卷二 | 干支体性、刑冲合害、大运小运太岁 | 「甲木是什么性情」「三刑怎么起」「大运怎么排」 |
| 卷三 | 神煞 | 「天乙贵人怎么查」「驿马怎么用」 |
| 卷四 | 十干坐支、十二月支配日干、五行时地分野 | 「甲木坐十二支各如何」「寅月甲日如何」 |
| 卷五 | 正官、偏官（官煞） | 「正官格成破」「七煞怎么制」 |
| 卷六 | 财、印、食、伤、刃、禄、杂格 | 「伤官伤尽」「杂气财官」「壬骑龙背」 |
| 卷七 | 女命、小儿、六亲、疾病、性情 | 「女命怎么看」「六亲怎么论」 |
| 卷八、卷九 | 六十日 × 十二时的时断 | 「甲日甲时生人如何」——这是断语库，不是理论 |
| 卷十 | 看命口诀、巫咸撮要、玉井奥诀 | 总纲性质的取用口诀 |
| 卷十一 | 气象篇 | 以「气象」论命的长篇总论 |
| 卷十二 | 十七篇赋论 | 元理赋、真宝赋、四言独步等，多为骈文断语 |

**② 本书是「汇集体」，不是「一家言」，遇到前后不一致时不许强行调和。**

万民英自述其书为「合诸家之说而折衷之」，因此书内并存：

- 徐子平的正宗四柱法（卷五、卷六以财官印食为主）
- 早期禄命法残余（卷三神煞、卷一纳音的禄命色彩）
- 唐宋赋论的断语式判断（卷十二）
- 五星、六壬的痕迹（卷二「十干分配天文」、卷七「定妇人孕生男女」）

同一命造，神煞断法与格局断法结论可以相反。**正确做法是标明「这是哪一卷、哪一法的说法」，而不是说「三命通会认为……」**。详见 `references/03_体系与内在张力.md`。

**③ 时断（卷八、卷九）是断语不是判例，不许反推成理论。**

卷八、卷九共 119 篇（丁日缺己卯时一篇，两种底本同缺），每篇格式固定：
> 先一句七言口诀（「六甲日生甲子时，败中印绶官生至……」）→ 再释「天干关系」→ 再列「忌某月」→ 再举命例。

这 119 篇的断语**彼此之间经常矛盾**（甲日某时主贵，乙日对应时而主贱），因为它们按「日干+时支」机械编排，来源不一。**引用时必须指明「六甲日甲子时断云」，不能提炼成通则。**

## 二、五步检索流程

### 第 1 步：判断问题落在哪一卷

用 `references/00_卷篇总目.csv`（301 行，含卷次、篇名、字数、文件名）。

关键词 → 卷的对照，见 `references/01_主题索引.csv`（178 条，含「术语 → 卷/篇 → 一句话释义」）。

### 第 2 步：读原篇

所有原文在 `references/sec/` 下，文件名格式 `NNN_卷X_篇名.md`。**直接读整篇，不要只读片段**——本书论证常先立后破，只读前半会得到相反结论。

### 第 3 步：查该术语的「起例」有没有独立表

- 神煞起例 → `references/02_神煞起例表.csv`（约 60 个神煞，含起法、所主、喜忌、出处篇名）
- 十神 → `references/04_十神与六格.md`
- 时断 → `references/05_时断速查.csv`（119 行，日干+时支 → 口诀首句、格局关键词、原文首句）

### 第 4 步：核对是否有内部异说

凡涉及以下题目，先看 `references/03_体系与内在张力.md` 的「分歧清单」：
格局数目（四格/六格/十八格）、伤官用财还是用印、阳刃是否可用、杂气是否必冲、女命以夫为主还是以自身为主、纳音是否可信。

### 第 5 步：出处写全

引用格式统一为：**卷次 · 篇名 · 「原文摘句」**。例：

> 卷五《论正官》：「正官者，乃甲见辛、乙见庚之例。阴阳配合，相制有用，成其道也。」

## 三、本书最不可替代的五个部分

1. **六十甲子性质吉凶（卷一，2.1 万字）**
   逐条列六十甲子的取象、所喜、所忌、所属神煞（「甲子金，为宝物，喜金木旺地。进神喜，福星，平头，悬针，破字」）。这是历代纳音取象最完整的汇编。

2. **十二月支配日干（卷四，4,105 字）**
   以「子月甲乙日…亥月壬癸日」120 组，逐组给「得何者为印/官/财、喜见什么、忌什么」。与《穷通宝鉴》的 120 组调候用神**互为对照**——一个是格局视角，一个是调候视角。

3. **时断 119 篇（卷八、卷九）**
   唯一系统处理「时柱」的古典文本。四柱法通常重月令轻时柱，本书给时柱独立地位。

4. **赋论十七篇（卷十二）**
   《元理赋》《真宝赋》《四言独步》等，是明清命书的共同源头，后世《滴天髓》《子平真诠》大量袭用其句。

5. **看命口诀（卷十，1.19 万字）**
   以「先看月支有无财官」开篇，是子平法最紧凑的操作纲要。

## 四、常见误用（务必避开）

| 误用 | 纠正 |
|---|---|
| 拿卷三的神煞断语直接断吉凶 | 神煞在本书中**只作参断**，卷三《总论诸神煞》明言须与格局合看；单见一煞不断凶 |
| 把 119 篇时断当「公式」输入生日 | 时断的断语前提是「只论日干与时支」，不看年月，与完整四柱论断不可等同 |
| 用卷十二赋文的骈句当判据 | 赋文多夸张（「位至三公」「贵不可言」），须以卷五、卷六的格局条件校验 |
| 认为「三命通会 = 子平法」 | 本书并存禄命法、五星法痕迹；纯粹子平法要看卷五、卷六 |
| 把《穷通宝鉴》的调候用神说成三命通会的观点 | 两者体系不同；本书论用神重格局成败，不重寒暖燥湿 |

## 六、已知局限

1. **两份「注评」是同一文件的重复上传**（MD5 相同：`7a2fa617…`，592 页扫描件，无文字层）。若需引用其评注，须先 OCR，本技能未收录其正文。另有一本潘东光《特殊格局注解》（113 页，横排双栏低清扫描），OCR 实测仅 6/113 页可读，已放弃，只在其书目信息中保留章节目录。
2. **底本卷八、卷九各缺 10 篇首时**（甲日甲子时、乙日丙子时……），已从《三命通会》-万民英.pdf 补足；**「六丁日己卯时断」两种底本同缺**，本书时断实为 119 篇而非 120 篇。补入篇的正文质量略低于 txt 版。
3. **卷二「论坐命官」当为「论坐命宫」**，底本作「官」，系形近之误，已在 `06_版本与校勘.md` 记录，正文未改。
4. 本书**不提供**现代命理流派的引申（如盲派、新派旺衰法），只提供万民英原文及其内部体系。
