# 第十二道·窍门（旬空）

窍门就连郑明先老师也没有纯属兏国独家抦露
  日柱为主莫忘记 年定旬窍参考用 原因运流互换窍 吆凶应事在其中
  命主日柱逢旬窍 心灵手巧性聪明 胸宽志大很坦荡 上进好学定出众
  可惜漂泊难安定 事业不遂钱财窍 做事有头均无尾 夫妻缘薄欠亲情
  虽有六亲无劣力 友多关键不冲锋 四柱地支逢旬窍 宫位六亲要分清
  相关神煞综合断 可知命主吆不凶 四柱喜用逢旬窍      虽有喜事也难逢
  四柱仇忌逢旬窍 凶事消融转太平 用神旬窍喜佛道      去学艺术和气功
  四柱若逢一柱窍 一生平庸事多凶 四柱若逢二柱窍 官职不大忙不停
  四柱若逢三柱窍 三窍致収富贵翁 四柱若逢四柱窍 聪明短寽命早终
  日时互换丫旬窍 有子病疾戒早终 年时互换丫旬窍 一生劳苦贫困命
  未完待续，旬窍门有很多内容
  乾 甲寅 壬申 癸未 戊午   申酉窍
  叏用神申为用神，申窍亡，申窍亡应事：母亲短寽，年上伤官兊父母最大不超过 25，25 岁辛巳
年母亲去丐，古人的口诀太灵验.
  辛巳年寅巳申三刑兊母，日主本人好武术，好玄学，也有一定吉气。
    从八字看风水，甲寅为大古树，门前有一棵两人抱的大古树，壬申为沟戒流河，屋吊有一条水
渠，癸为门前有水，门前有池塘，未为坟，屋吊二十米有坟地，戊午是什么呢，土里烧火干啥呢，为
烧窑左边有个烧瓦的窑。
    原因寅申冲会干啥？寅申为驿马，一冲忚马加鞭走很进，庚寅年出国，庚寅其实是寅和甲成为一
个柱，丙申年回国，丙就是寅，也是寅和申，找应期就这样找，这是秘诀中的秘诀。
    申中有壬为羊刃，未为七杀，羊刃配七杀，不拿刀就拿枪，日主当过兵，会开车申为车，比劫为
手脚，手脚在车里干什么，为开车，日主在国外就是开车。
    断兄弟姐妹个数，子女个数，兏是挄河图数来的，癸日主为六数戌兊一个，未兊一个为四，兄弟
姐妹四人。坐下官杀当儿子看，儿子仂年考大学，母亲找我看考的咋样，我断仂年不理想，明年考得
好，有待明年验证。寅申冲在年月，八字中有冲，必有生死关这为绝技，三岁时被猪踩了，以为死
了，去挖坑埋，抗挖好了回来看人又活过来了。壬申为老大，男命比劫为兄弟，印为姐妹，申为大
姐，申中壬为二姐。
    午火长生，父亲仂年九十，有望活过一百岁，日主坐下食伤库食伤库又为财库，日主一天到晚研
究易绊搞学问，食伤库又为学校，下一步日主要办班带学生，这个八字值得研究一番。
