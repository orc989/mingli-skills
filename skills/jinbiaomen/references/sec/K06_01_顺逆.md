# 顺逆

顺 逆

  顺逆不齐也，不可逆者，其气势而已矣
  八字中有顺的关系，还有逆的关系。
  顺一般说的是专旺格，或者两气成象的意思，也就是日主得时当令，形成专旺的
气势了，或者两种五行旺势的，取用神就得找配合他专旺气势的五行，这就叫顺，这
种都是不可逆的，就是你要顺着旺的五行找取用神，不能找破坏你旺神气势的五行，
如果有破坏的五行，那么就是逆。那么这个逆就是忌神。所以你八字里有某种五行过
于旺象的取用神就得找顺着旺势的那个五行为用神。
  那么这种顺，有顺着以日主为中心点的顺，比如八字里印比旺的，这就是专旺了,
还有一种是以整体八字为中心点的，比如全局除了日主外，全是财官，这就是从了财
官，取用神要顺着财官的气势找取用神。
  比如我们说的比劫旺，食伤泄秀，身旺印旺，印生身的，比如你日主得时当令，
全局旺势，八字里全是印比的，这是取用神就得顺着来，就得找印比为用，这就是顺
的意思。
  还有我们说的日主当令得势的，也就是身旺用官杀的，那么官杀不管有力无力他
都是逆的意思，官杀无力要去掉，顺着日主的旺势取用神，这就是顺局出现逆的五行，
这个五行就是病神，还有一种是官杀有力的可以克制日主身旺的，那么这种日主虽然
有旺势，但是官杀有力就不能顺着日主的旺势了，虽然官杀也是逆的意思，官杀有力
量就不能顺着日主的旺势找取用神了，就是正常的身旺用官杀了。
  如果你官杀旺的，日主弱了，这时就得用印化这个官杀，因为官杀是逆的，你要
用印把官杀变成为你所用的。如果官杀旺，没有印，形成从官杀克了，这时你就得顺
着官杀的气势，取用神就得考虑顺着财官的气势。
