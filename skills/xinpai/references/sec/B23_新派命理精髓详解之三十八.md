# 新派命理精髓详解之三十八



    癸卯 己未 己卯 辛未(申酉)

    身弱用己土。时干辛金为用神，月干己土为正官，为用神，旺时可为当官。本命为
当官不久的命，在己上受制时会丢官。
    乙卯大运，癸未流年。乙木大运为正官天干凶的大运，癸水流年为在本运中第一个
同性制己土正官的流年，所以这一年官丢了。
    什么时候当官，正官吉的大运当官，丁巳大运同性生月干己土，又同性制年干癸水
，这步运为正官吉运，所以这步运为当官的运。
    丁巳大运制年干癸水，社会环境吉，导致了正官很吉。同时时干辛金弱、导致了日
干己土很弱，正官也就不吉了，时干辛金为名声、文凭，断因为文凭不够高，当时领导
不太满意。尽管我的文凭达不到他们的要求，但正官社会环境吉，单位一把手力排众议
，提拔了我。实际情况是我是中专文凭，单位要高文凭的人才，但是我却通过了。
    丁巳大运，乙丑流年。丁火大运生己土，本运正官吉．乙木流年制癸水，正官的社
会环境吉，开始工作。
    丁巳大运，丁卯流年。丁火流年帮丁火大运，生己土制癸水，正官最吉，这一年破
格提拔了，本运中一直深得一把手的重用，在重要部门工作。
    测一个为官者的工作时，考虑哪些内容?权力大小、受重用与否的情况等。
    巳火大运生未土，权力小。巳火制卯木。我的权力被同事竟争，好多事情我说了不
算。丁火制年干癸水，一直很受重用，尤其一把手对我很信任。丁火克时干辛金，大家
的质疑一直不断。制年干癸水，发偏财多。正官导致偏财吉，利用职务之便发了财，搞
了外遇。
    部下变为情人的情况有二:
    1、男领导：正官导致偏财吉时，为部下成为情人。
    2、女领导：正官导致偏官吉时，为部下成为情人。
    丙辰大运，丙火稍有力，生己土，己土较旺，工作还算顺利。比上一个运差了，领
导对我没有过去那么好了。
    丙辰大运，癸酉流年换了个工作岗位，癸水在流年出现，为我被动过去。就是在我
没有思想准备的情况下，被安排过去了。
    丙辰大运，辛巳流年，辛金为实神，在先天风水中弱，出现的流年以弱断，日干己
土减力，月干己土弱，正官天干凶，癸水旺，你的工作重心有所转移，专门做钉子户的
工作，这一年的工作很不好干。
    丙辰大运，壬午流年，壬水制丙火，己土弱，工作不十分顺利，午火生辰土，辰土
旺，制未，我权力仍然很大。但是年干癸水不弱，已经不太受领导信任了。
    进入乙卯大运，乙木克己土，正官天干凶，该在本运中的丢掉正官。
    乙卯大运，癸未流年。月干己土最弱，正官没有了。时干辛金弱，干偏业了，自己
做事，癸水在先天风水中弱，挣钱了。
    乙卯大运，自己做事一直不顺利。乙卯大运中制辛金做偏业，癸水弱，偏业都发财
。乙木大运制己土，正官凶，正财凶，所以本运中正业都干的不理想。偶尔干个新的行
当，干得却好。
    乙木大运制年干癸水，正官的社会环境吉，无人管，无人约束，过得很爽。卯木克
未土，正官的内环境吉，而天干却凶，目标定的很大，但做的却很困难。空有抱负却难
以实现。
    乙卯大运，己丑流年，企业家的正官社会环境吉，就代表手续齐全，手续合法。己
土流年在先天风水中是弱的．己土在流年出现时，以弱断，所以今年正官最为不吉。今
年事业到了最低谷。
    乙木大运制时干辛金，偏官凶，己土弱的流年时干辛金弱，今年偏官最凶了，所以
今年改行了。己土制癸水，偏财最吉，一干就发财。
    有句断语叫做"大运决定六亲的年龄段，流年决定长相"，年龄段并不是真正地体现
出六亲的实际年龄，而是外貌所反映出来的岁数大小，长相也是六亲与命主本人相比较
长相如何，并不是指一个人长相完竟如何。
    丑土流年制卯木大运，时支未土旺．偏官的内环境还好，有一定业务．所以可以干
，但是业务量不会很大。
    看一个人的技术高低，看日干对正官的作用，日干对正官起好作用时，为技术提高
，日干对正官起坏作用时，技术不好，或出现技术性问题。
    婚姻：看己土，为用神靠近日干为吉，但是己土在先天风水中弱，与爱人的关系不
十分好。辛金为用神，不十分旺，曾经闹过离婚，但是离不了。
    定亲的时机：己土旺时定亲。
    丁巳大运，己巳流年。己土在流年最旺，女方追我。辛金为偏官，辛金最弱时，结
婚。
    丁巳大运，庚午流年，庚金在先天风水中弱，制不住丁火，丁火有力克辛金，偏官
凶，结婚、己土旺，天气很好。
    从女人的命中看何年生孩子，日干凶时生孩子。
    辛未年、壬申年都是生孩子的流年，辛金在先天风水中弱，丁火克辛金时，时干辛
金弱．己土就弱，妻天干凶，生孩子。壬水流年有力制丁火大运，月干己弱，也是生孩
子的流年。实际生在壬申年。
    丁巳大运，壬申流年。辛未为男孩，己未为女孩，申金制大运巳火，大运巳火有力
，巳火生时支未，不生男，生月支未，不生女。
    巳火有力制日支卯木，卯木弱，时支未土旺，不生男，月支未土旺，不生女。
    巳火有力制年支卯木，年支卯太弱，不克月支未土，未土旺，不生女。
    最终断生男。
    父亲为年上癸卯，为忌神。离日干远，感情很好。身体看癸水与卯木，卯木旺，地
支吉。天干中月干己土与日干己土都不十分旺，还有时干辛金弱，己土更弱，所以父亲
应凶在天干。辛金、己土弱时父亲应凶。乙卯大运中，父亲的身体就不好，在本运这就
有病。乙木在先天中弱，不严重。逢辛金减力时，会身体不好，乙卯为凶。壬午、乙酉
．为乙木有力制时干辛金有力，癸水旺，父亲身体不太好．但都无大障碍。
    丙辰大运中，丙火较有力制时干辛金，乙亥流年时，乙木制时干辛金．父亲病了一
场
    己未为母亲，为用神。未为母亲的内环境，在先天风水中弱，又有卯木制、地支较
吉。天干癸水同性制、时干辛金使己土增加的力量小，所以天干为凶。母亲在天干凶时
，应凶。都在制辛金的时候，也是在进入乙卯大运后，身体素质明显下降。
    如何测病，我们以本命局母亲的身体状况说明：
    一、天干，天干己土这个字，在大运流年的作用下、凶时，母亲会得病。十个天干
中．有四个是使己土增力的字，如果这四个字在先天风水中有力．在这四个字所代表的
身体部位健康。如果这四个字在先天风水中弱，在这四个字所代表的身体部位有病。
    二、月支未土，为母亲的内环境，未土弱时，母亲的身体好。在十二个地支中，有
四个地支是使未增力的，如果这四个地支在先天风水中旺，在四个地支所代表的身份部
位有病。如果这四个地支在先天风水中弱，在这四个地支所代表的身体部位健康。
    三、天干中制己土的字有六个，如果这六个天干在先天风水中弱，在这六个天干所
代表的身体邵位健康。如果这六个天干在先天风水中旺，在这六个天干所代表的身体部
位有病。
    四、制未土的字有八个，如果这八个地支在先天风水中旺，在这八个地支所代表的
身体部位健康。如果这八个地支在先天风水中弱，在这八个地支所代表的身体部位有病
。
    具体的生病部位在先天风水中最旺或最弱的那个字代表的身体部位。如：本命局中
时干辛金先天风水中弱，辛金弱，就导致己土弱，不利母亲，母亲在辛金这个字代表的
身体部位容易生病。
