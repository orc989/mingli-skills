# 疾病断诀

十三疾病断诀

要想四柱断疾病，分清宫位干落宫

甲在年上头有病，落在月上手臂疼

乙在年上神经病，脖颈也会时常疼

落在月上肝胆病，落在时上关节炎

落在日上没法定，丙在年上坏眼睛

落在月上肩膀病，落在日上阑尾炎

丁在年上脑神经，月上心脏血液病

戊在年干鼻窦炎，落在月上胸膈肌

落在日上胃不好，落在时上小腿疼

己在年上皮肤病，己在月上脾胃病

己在日上腹部疼，己在时上肌肉病

庚在年上骨牙齿，月上胸骨与经络

日上脐轮与大肠，时上尾骨下肢骨

辛在年上呼吸道，月干肺部和淋巴

时干定位大腿部，壬在年上舌耳朵

日干三焦与水道，癸在年上脑供血

月上便为心包络，日上肾上有问题

时上可把足上说，以上只是信息象

何时得病得端详，命中此干坏作用

便可把它来断定，支上也是同此理

天干也是地支象.
