# 神峰通考（命理正宗）

## 三条硬纪律

**第一条：先判体系，再动手。**
《神峰通考》讲"病药"，《滴天髓》讲"中和"，《子平真诠》讲"格局成败"。三套判据对同一命局会给出**相反结论**。用户没有指定体系时，先问一句"按哪一路看"，或在回答中明确标注"以《神峰》病药法论"。**绝不可混用**。详见 `references/04_体系源流与内在张力.md` 第八节的分歧表。

**第二条：引用必须标明"这是张神峰的主张"还是"这是张神峰反对的"。**
本书是一部**辟谬之书**（原名《通考辟谬命理正宗》）。日贵、日德、魁罡、趋艮、趋乾、六乙鼠贵、六阴朝阳、刑合、合禄、润下、从革等格，卷二虽逐一列出并附命例，但卷一《总论子平谬说类》已斥为"谬说无疑"。**只引卷二不引卷一，等于把作者反对的东西说成他的主张。** 凡引用这些格，必须同时交代立场。

**第三条：干支必须先校正再引用。**
OCR 文本层的干支讹误是系统性的——"巳"一律被识别为"已"（辛已→辛巳 79 次）、"酉"被识别为"西"、"辰"被识别为"展"、"戊"被识别为"成"。引用四柱前先过一遍 `references/05_校勘须知.md` 的讹字表。**凡涉及具体命例、起例、口诀，回查原页图像。**

## 一句话认识这本书

> 「有病方为贵，无伤不是奇，格中如去病，财禄两相随。」

这四句是全书纲领，张神峰说它"为命书千万卷之括要"。

它的意思是：**八字要有病，才是贵格。** 没有伤、没有病、四平八稳的命，是"无病无药，不富不贵之人"。

这与现代人习惯的"越中和越好"正相反。张神峰在《病药说类》里把自己的弯路写得很清楚：

> 「先前未说病药之说，屡以中和而究人之造化，十无一二有验……后始得悟病药之旨，再以财官中和参看，则尝失八九而七。」

一句话：**他是先用中和法验不过一成，才转出病药法的。**

## 五步检索流程

### 第 1 步：定位概念

用户问的若是**方法论**（病药、四病、四药、动静、盖头、六亲、辟谬），走 `references/01_主题索引.csv` 前 19 条与第 1—12 条，再读对应的 `references/sec/` 篇目。

用户问的若是**具体格局**（正官、偏官、印绶、阳刃、建禄、井栏叉、飞天禄马、壬骑龙背……），直接在 `00_篇目与页码.csv` 里按篇名找。

用户问的若是**神煞**（贵人、华盖、驿马、空亡、咸池、元辰、劫煞、红艳……），查 `references/02_神煞起例表.csv`，该表 39 项均给出起例、主事与原文位置。

用户问的若是**起例、排盘、遁月遁时、大运小运**，查 `01_主题索引.csv` 第 70—75 条，并注意 `05_校勘须知.md` 第五节的两张表格补录（天干五阳通变、日上遁时）——这两处 OCR 全废，只能用人工补录版。

### 第 2 步：核对立场

找到篇目后，先判断它属于哪一类：

| 类 | 篇目特征 | 引用时的处理 |
|---|---|---|
| **正说** | 五星正说、病药说、四病、四药、动静、盖头、六亲 | 可直接作张神峰主张引用 |
| **谬说** | 五星谬说、总论子平谬说 | 这是他的辩驳，可作主张引用 |
| **先立后破** | 卷二日德、日贵、魁罡、趋艮、趋乾、六乙鼠贵、六阴朝阳、刑合、合禄、润下、从革 | 必须说明"张神峰列为谬说" |
| **存正** | 勾陈得位、玄武当权、曲直、稼穑 | 他明确认可，可作主张引用 |
| **赋论** | 卷四各赋、《四言独步》《五言独步》《喜忌篇》《继善篇》 | 多为引前人之作，非其独创 |

### 第 3 步：读原文，辨真伪

打开对应的 `references/sec/NNN_篇名.txt`，注意三件事：

1. **篇首常带前篇余文**（机械切分所致），首句不一定是本篇。
2. **每篇含"【白话讲解】"**——那是 2006 年注译者的解说，**不是原文**，引用时须区分。
3. **干支要校正**（见第五条硬纪律）。

### 第 4 步：落到判据

病药法的完整操作流程只有六步，出自《病药说类》末段：

1. 先看**日干**。
2. 次看**月令**——月令支中属什么，就把那个字拈出来。
3. 把**同类之字聚在一处**看（月令是火，就去看年、月、时上还有没有火）。
4. 判**这一堆字是病还是非病**。
5. **地支所藏先不要看**——看了就"串混杂不明"。
6. **从重者论**——哪一路最重，从那一路下手。

这六步与"扶抑"最大的不同在第 3 步与第 5 步：**要先聚、先不看藏干**。现代教学多要求先看藏干，张神峰明确反对。

### 第 5 步：给结论时交代剂量

病药说的结论不是"吉/凶"二元，而是四档：

| 情形 | 结论 |
|---|---|
| 病重而得药 | 大富大贵之人 |
| 病轻而得药 | 略富略贵之人 |
| 无病而无药 | 不富不贵之人 |
| 有病而无药 | （原文未明说，按体系推为凶） |

另有剂量调节：「或本身病重而药少，或本身病轻而药重，又当以取其中和。」——**"中和"在本书里是剂量标准，不是判断标准。**

## 核心体系速览

### 四病（`03_四病四药速查.csv`）

| 病 | 一句话 | 判据 | 治则 |
|---|---|---|---|
| **雕** | 纯粹未琢 | 官无伤、财无比劫、印无财、食伤无印，纯然无杂 | 须有雕琢锻炼之功 |
| **枯** | 有根而力未透 | 有根但气未透，如官星有根未透、财星有根未旺 | 贵有根之枯；行官旺、财旺之乡 |
| **旺** | 太过 | 官／财／印／日干太旺 | 官旺行伤官运、财旺行比劫运、印旺行财运、身旺行官杀运 |
| **弱** | 不及，尤忌无根 | 官／财／日主太弱 | 官弱行官旺乡、财弱行财旺地、身弱行身旺地 |

### 四药（同上）

| 药 | 一句话 | 手法 |
|---|---|---|
| **损** | 损其有余 | 当权得位者不再资助，反制之（木有余以金制之） |
| **益** | 益其不及 | 本气已衰，补之（木不及行水运滋根） |
| **生** | 取其生气 | 六阳生处真为生（甲生亥）；六阴死处反为生（乙死亥） |
| **长** | 气炽则须克 | 木长寅卯辰宜金运、火长巳巳午未宜水运 |

### 三个"说"（技术底座，不可分读）

- **动静说**：天干为动，地支为静；**动只攻动，静只攻静**。运上天干攻不到原局地支所藏。→ 看运时干运、支运须分别计。
- **盖头说**：天干四字是"头"，地支是"肚腹四肢"，支中所藏是"五脏六腑"。害物藏在支中不算凶，**透到天干才算凶**。
- **六亲说**：年祖宗、月父母兄弟、日支夫妻、时子女，以喜忌定吉凶。

## 与《滴天髓》的四处硬分歧

| 议题 | 《神峰通考》 | 《滴天髓》 |
|---|---|---|
| 主轴 | **病药**第一，中和只作剂量 | **中和**为贵 |
| 阴阳生死 | **阳生阴死、阳死阴生**（甲生亥、乙生午为弱） | 阴阳**同生同死** |
| 纯粹无杂 | 是"**雕**"病，未琢之玉无用 | 清纯为贵 |
| 外格 | **大量辟谬**（日贵、日德、魁罡、趋艮、趋乾斥为谬说） | 少论外格 |

前两条会直接改变判读结果。**用户若未指定体系，必须在回答里说明依据哪一路。**

## 常见误用

| 误用 | 错在哪 |
|---|---|
| 把"病药"当"扶抑" | 扶抑只看强弱；病药要看"哪个字在害哪个字"，而"雕""枯"两病与强弱无关 |
| 见"纯粹无杂"就断贵 | 张神峰说这是"雕"病，未琢之玉 |
| 见"弱"就扶 | 弱分有根无根；无根之弱不可救（但绝处藏干算有根） |
| 用《滴天髓》阴阳同生同死法套本书 | 本书严守阳生阴死 |
| 把卷二列出的外格当作者主张 | 须同时交代卷一辟谬立场 |
| 看运时把一柱大运当整体 | 违反动静说，须干支分计 |
| 一上手就翻藏干 | 违反"从重者论"，须先聚月令属字再看 |
