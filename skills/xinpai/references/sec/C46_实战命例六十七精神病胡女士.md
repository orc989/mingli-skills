# 实战命例六十七精神病胡女士

1972年11月13日4时阴历壬子年十月初八日寅时
坤造：壬子辛亥戊申甲寅
[pic]
一日干戊土生在亥水月弱51%.全局没有一个字使日干增力.从弱.月干辛金为用神.年干壬
水为忌神.时干甲木为用神
1.2000年进甲寅大运2004年甲申流年.天干地支都吉。
1.从表面来看不会有病。
2.通过出现的六亲看没有出现的六亲。
3.运年作用.时干甲木旺丙火偏印凶.偏印是忌神容易得精神病。
偏印凶就指传统文化.佛.道.神.仙.妖.精.鬼.灵不帮助
4.运年作用.时干甲木旺丙火偏印旺.对日干没起好作用.容易得精神病。
5..运年作用.时干甲木旺庚金食神凶。
食神吉考虑问题全面.细致.逻辑思维强.记忆力好.不偏激.语言得体.行为得当。
1日干是忌神.容易得精神病
2.偏印对日干没起好作用.容易得精神病
3.食神凶容易得精神病
4.食神对日干没有起好作用容易得精神病
5.偏印是忌神容易得精神病。
