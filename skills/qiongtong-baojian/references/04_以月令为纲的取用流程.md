# 以月令为纲的取用流程

> 穷通宝鉴的方法只有一个：**先定月令，再定日干，然后查这一格的气候病灶，最后取药**。
> 全书 120 格 = 12 月 × 10 日干，每一格就是一张「病历 + 药方」。

---

## 一、五步流程

### 第 1 步：排除「不成格」的情况（先看能不能论）

穷通宝鉴在正题之前，会先挡掉几种特殊结构。这些结构**不适用月令取用法**，
必须先识别，否则后面全错。

| 结构 | 出处 | 处理 |
|---|---|---|
| **从财、从杀、从化** | 正二月甲木「素无取从财、从杀、从化之理」（因月令禄旺）；但三月、五月、六月甲木另论 | 月令禄旺者不论从；月令衰绝而全局一边倒者方可论从 |
| **专旺格（炎上、曲直、稼穑、从革、润下）** | 四月丙火「若金水俱无而见甲木，则成炎上格」；六月戊土「八个字中土得其七……不作稼穑格论」 | 五行的气势**纯而不杂**才成专旺；杂一位即破格 |
| **化气格** | 五月甲木「化气必须见辰，方为真化」；三月壬水「丁壬相合，月垣逢辰，有化木之可能」 | 化气须月令有化神之根（辰），否则「虽不争妒，亦属虚名」 |
| **阳刃驾煞** | 二月甲木「庚金得所者，名阳刃架煞，可许异途小贵，若武职便显」 | 刃格宜武不宜文，须财资煞，见癸水则困了财杀 |

> **一句判据**：月令是日干的**临官、帝旺**之地（甲在寅卯、丙在巳午、庚在申酉、壬在亥子），
> 则「自无从化之理」，一律按**身旺用克泄**论；月令是日干的**死绝**之地，
> 才考虑从格、专旺。

### 第 2 步：定月令所属「气候段」

不是按农历月份，而是按**节气**。底本给出的分界点：

| 月建 | 分界 | 界线前 | 界线后 |
|---|---|---|---|
| 寅（正月） | 雨水 | 初春，余寒未退，丙癸并用，以丙为主 | 仲春，木乘旺气，先庚次丁 |
| 卯（二月） | 清明 | 同正月雨水后 | — |
| 辰（三月） | 谷雨（底本作「鼓雨」） | 与二月同看 | 土旺用事，阳壮木渴，非藉水滋扶不可 |
| 巳（四月） | — | 丙火司权，木气已退 | — |
| 午（五月） | 夏至 | 夏至前阳盛，先癸次丙 | 夏至后阴生，三伏生寒，丙癸俱尊 |
| 未（六月） | 大暑 | 大暑前同五月 | 大暑后金水进气，三伏生寒 |
| 申（七月） | 立秋→白露 | 秋初，暑气未尽 | 白露后金气纯 |
| 酉（八月） | 秋分 | — | 金气极旺 |
| 戌（九月） | 霜降 | 霜降前同八月 | 霜降后土旺用事 |
| 亥（十月） | — | 小阳春，阳气略出 | — |
| 子（十一月） | 冬至 | 冬至前阴盛 | 冬至后「弱中生旺」「一阳来复」 |
| 丑（十二月） | — | 上半月癸辛主事 | 下半月己土主事 |

> **注**：底本用「鼓雨」代「谷雨」，是抄本旧写，非错字。

### 第 3 步：判这一格的「病灶」

病灶只有四类，穷通宝鉴每一格都在诊断其中一两类：

| 病灶 | 典型表述 | 用药方向 |
|---|---|---|
| **寒** | 「初春尚有余寒」「严寒冰冻」「天气寒冻，木性极寒」 | 丙火（不是丁火——丁为灯烛，不能解冻） |
| **燥**（旱） | 「木性虚焦」「火炎土燥」「阳壮木渴」 | 癸水（雨露）优先，壬水（江河）次之；水须有金为源 |
| **湿** | 「二月因湿乙伤丁」「湿泥寒冻」「水泛木浮」 | 戊土制水、甲木疏土、丙火暖土 |
| **塞/埋/浊** | 「木多火塞」「土厚埋金」「己土浊壬」 | 庚劈甲、甲疏土、壬洗金 |

**四类病灶的用药优先级**：

```
寒 → 丙（唯一解）
燥 → 癸 ≻ 壬（须庚辛为源）
湿 → 戊 ≻ 甲 ≻ 丙
塞 → 庚 ≻ 甲 ≻ 壬
```

### 第 4 步：查该格的用神（见 `01_调候用神总表.csv`）

表里三列「首选 / 次选 / 再选」是**主次关系**，不是并列关系：

- **首选**：缺此则格不成。如三月甲木无庚，则「钝斧无钢，无有学问」。
- **次选**：配合用。如三月甲木之壬，专为「泄庚润木」，防庚金燥烈伤木。
- **再选**：救应或变局。如四月甲木「又须有庚透」，是因癸丁并用时须庚调和。

「所忌」一列同样是硬约束，例如：

- 三冬己土忌癸（愈寒愈冻）
- 五月戊土忌癸（力微不足破火）
- 十一月辛金忌癸（冻金而困丙火）
- 二月壬水忌甲、丁（甲破戊、丁克辛）

### 第 5 步：落到「有根无根」「透干藏支」

用神查到之后，还要判**力量**。底本判力量的三个标准：

1. **透干 vs 藏支**：「癸藏丙透，名寒木向阳」——藏支者力薄，透干者显。
2. **有根**：「壬透不见丁化，加以庚辛亦透，壬水有根，科甲无疑」
   ——用神须有生它的神，否则「无源之水易涸」（四月乙木）。
3. **不相碍**：「丙癸并透，名为不晴不雨」「丙癸透干，不可相并，须中有间隔」
   ——两味药不能相互克伐，中间要有通关之神。

判完这三条，才是「上格 / 中格 / 下格 / 常人」。

## 二、从「格」到「运」：底本的岁运观

穷通宝鉴讲运的比重不大，但立场很明确，且与明清其他书不同：

> 凡中等格局，皆须运岁相扶，否则不能大发也。（二月甲木）

> 上等者不必运助，自然富贵；次等者，原局有缺，非运助不发。（三月甲木）

三句话概括：

1. **上格不赖运**——原局配合完美者，行运只要不冲用神，皆可发。
2. **中格全赖运**——「运程配合得宜，必然富贵」，运不扶则「有名无实」。
3. **忌运看用神**——「困用神」是唯一的凶法：
   - 用庚者忌南方（火克金）、忌丁火制庚
   - 用丁者忌癸水伤丁
   - 用癸者忌戊己土克、忌支成火局

> 底本不讲「大运吉凶等第」，也不讲「流年断事」，只在命例的按语里偶一提及。
> 拿它去断流年细节，是超出底本范围的用法。

## 三、命例的使用方式：只作「证例」，不作「范例」

底本 1029 条命例（见 `02_mingli_suoyin.csv`）的编排逻辑是：

```
四柱 → （生时）→ 命主名 → 断语一句
```

断语几乎都是「**用X得X**」的形式，例如：

> 庚寅，戊寅，甲子，丙寅，光绪十六年正月二十三日寅时。
> 陈济棠命：生於雨水前七日，丙透癸藏，大富大贵之命，妻宫癸水，内助尤得力也。

这句话的作用是**验证前面的口诀**：「正月甲木，初春尚有余寒，得丙癸透，富贵双全，
癸藏丙透，名寒木向阳」——陈济棠造正是「丙透癸藏」，故断为大富贵。

**所以命例的正确读法**：

1. 先看这一格的口诀，自己判断这个八字缺什么、有什么。
2. 再看断语，比对判断是否一致。
3. **不一致时**，多数是断语给出了口诀之外的补充条件（如「生於雨水前七日」——节气位置）。

**错误读法**：把 1029 条命例当作统计样本，归纳「用庚的多贵、用丁的多富」。
底本的命例是**名家命造**（陈济棠、萧耀南、萨镇冰、岳武穆、清世祖、张謇、赵恒惕……），
本身经过筛选，不存在统计代表性。而且大量命例带**事后附会**的按语
（如「行辛亥运，辛酉年，冲合阳刃，坐囹圄亡身」——岳武穆造，是已知结局后的追述）。

## 四、本流程的已知边界

| 边界 | 说明 |
|---|---|
| **不论格局成败** | 穷通宝鉴只讲调候用神，不讲「伤官配印」「食神生财」这类格局名目的成败条件。需与《子平真诠》《千里命稿》配合 |
| **不论六亲细节** | 每格末尾的「用X者，Y妻Z子」只给出六亲的**取象方向**，不断具体吉凶 |
| **不论女命** | 全书除个别命例外，通篇按男命论 |
| **不定寿夭** | 除命例按语外，正文无生死断法 |
| **用神可能互斥** | 120 格中有 20 余格的首选与次选属于相克关系（如丙壬、丁癸），底本的解法是「不相碍」与「有间隔」，实际操作中歧义极大，须结合全局 |
