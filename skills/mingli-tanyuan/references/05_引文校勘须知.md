# 引文校勘须知（OCR 缺陷清单）

> 本技能的全部正文来自一份 **241 页、无文字层的扫描 PDF**，经 `tesseract -l chi_sim --psm 6` 识别。
> 识别质量「可读但不可引」：能读懂大意，**不能据此引用原文**。
> 本文件列出实测到的系统性错误，供引用前逐类排查。

| 项目 | 实况 |

| 文件 | `袁树珊 - 命理探源.pdf`，22 MB，241 页，523×752 pt |
| 生成 | PTScrip5 Distiller，2007 年（Acrobat 扫描输出） |

## 三、结构性缺损（不只是错字，是缺内容）

### 3.1 每两页之间可能脱文
原扫描件为**双面对折装订**。绝大多数「PDF 第 N 页」与「PDF 第 N+1 页」之间**不是连续**的：第 N 页末行与第 N+1 页首行往往接不上，中间有 1—3 行脱失。

**已在 `vol_*.md` 每页开头统一插入标记**：
```
←〔PDF 第NNN页末行与第NNN+1页首行之间疑有脱文，OCR 不可读，请核原书〕
```

已知**连续**（无明显脱文）的分界点，可不带此标记：
- PDF 010（卷一开篇）、087（卷四开篇）、128（卷五开篇）、162（卷六开篇）、184（卷七开篇）、225（卷八开篇）

### 3.2 标题行大面积损坏
以下小节**标题行 OCR 不可读**，在 `00_mulu_章节索引.csv` 中已标 `※`：

| 位置 | 状况 |
|---|---|
| 卷四·4（PDF 093） | 标题行完全丢失，只能从「徐大升说」起判；疑为「论五行生克」类 |
| 卷六·9（PDF 173） | 位于形象论与八格论之间，标题丢失；疑为「方局论」 |
| 卷八·2（PDF 227） | 按「星家十要」体例应为第二要，疑为「常变」 |
| 卷七·9 癸水四则（PDF 220） | OCR 作「九、作水一则」，但按十个天干配九节推断应为「癸水四则」；**「四则」与实际收例数不符，待核** |

### 3.3 表格与命盘全废
- 十二宫定局表（PDF 062—063）、纳音六十甲子表（PDF 016—017）、大运排盘表（PDF 045—046、055—059、186—224）在 OCR 后仅余零散干支，**无法复原**。
- **卷七命例的八字四柱基本不可读**。`01_润德堂命例索引.csv` 只记录了「为谁推命 + 起止页 + 批语大意」，**没有记录四柱**。若要使用具体命例，必须打开原 PDF 对应页人工录入。
- 卷三神煞的干支表（天德、月德、天乙等）同样损坏，本技能未收录这些表；如需查表请回 PDF 070—086。

### 3.4 引号与书名号错乱
`《》` 与 `「」` 在 OCR 中经常互换或丢失，古文引述边界不清。引文时须自己重新划定引用范围。

## 六、若要提升质量，建议的下一步

1. **换 OCR 引擎**：`--psm 4`（单列可变行高）或 PaddleOCR / 行楷专用模型，对竖排民国铅字效果通常优于 `--psm 6`。
2. **提高分辨率**：200 dpi → 300 dpi，形近字错误率可显著下降（代价是耗时约 2.2 倍）。
3. **装订线检测**：先切掉左右各 5% 的装订边与页眉页脚，再做 OCR，可消除大部分页码噪声。
4. **用通行本对校**：本 PDF 是近代译本，可与《命理探源》民国排印本（如台湾武陵、大陆九州出版社本）对校标题与页码。
