# 新派命理精髓详解之二十九





    丁亥 乙巳 丙申 丁酉(辰巳)
    [pic]
    丙火生于巳火月，但巳火月令空亡，决定日干旺衰的50%以年支定，丙火日干生于亥
水年，弱于年支，日干弱。乙木生日干丙火，身弱用乙木。时干丁火反断为忌神。
    年干丁火泄月干乙木用神，对日干起了坏作用，年干丁火为忌神。
    月干乙木为正官，为用神，靠近日干，可断本命为官命．在乙木旺的大运上当官。

    癸卯大运，癸水同性制年干丁火，同性生月干乙木，都会使月干乙木旺起来，所以
在癸卯大运中可提升。
    癸卯大运，戊申流流。癸卯大运异性制流年戊土，戊仍然有力量与局中的字发生作
用，制日干丙火，丙火减力对月干乙木正官起好作用，正官吉，这一年提升。
    日干丙火在先天风水中弱，泄月干乙木力小，本命属于日干对正官起好作用的命，
此命为技术性干部。在丙火弱的流年上当官时，必定是当技术干部。由此可断，本命在
戊申流年时，成了技术科长。答：是技术科长。
    时干丁火为偏财，为忌神，在丁火旺的时候会破财，在制去丁火时会发偏财。本命
的组合还有一个十分显著的特点：为官不长。象这种为官不长的命．在正官凶时，必定
会被撤职。
    辛丑大运，辛金制月干乙木．本运中就会因自己犯事而下来。辛金大运同时制时干
丁火，丁火弱时会发偏财。丁火弱了，日干丙火会旺，日干丙火有力泄月干乙木正官，
可断为因为在这个技术科长的位置上贪污了钱，被顶头上司发现被告发，而遭撤职。
    此命有趣的事还有很多，辛金大运制乙木，辛金大运制时干丁火，辛金大运还制年
干丁火。制月干乙木时正官凶，断官不当了。制时干丁火，断发偏财了。制年干丁火，
断本运中本命很受单位一把手的赏识．是一把手的红人。
    无论你的人际关系如何，只要是正官凶时，都不会逃掉官灾的命运。
    丁火在先天风水中旺，只要是丁火旺时，就会破偏财，丁火在流年出现时，定会有
大的破财之事。直断2007年的丁火流年，刚买了新楼房，并且是买得四楼。答：是。
