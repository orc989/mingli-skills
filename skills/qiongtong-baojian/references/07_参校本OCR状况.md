### 梁湘润本为何不可用

该书为**黑底白字的影印石刻体**，且为双页合扫，单字高度不足 20 px。
测试过三种方案均失败：

1. 直接 OCR（`--psm 6`）：输出为随机汉字串，与原文完全不对应。
2. 2 倍 / 3 倍放大 + 反色 + autocontrast：仍是随机串。
3. 左右半页分别 OCR：同上。

**结论**：本技能**不提供梁湘润评注的内容**，只保留其书目位置与在版本链中的角色
（见 `05_版本源流与分歧.md`）。若要引用梁评，请查原书。

## 二、白话评注本（`o_baihua/`）的使用规则

### 结构

每一格的组织是：

```
原文（无标记）
徐乐吾曰：（评注层）
方先生曰：（现代作者评注层）
命例
```

全书出现「徐乐吾曰」约 1,009 处、「方先生曰」约 710 处。

### 已知 OCR 讹误

与底本同类的形近字，且更严重：

| 误 | 正 | 频次 |
|---|---|---|
| 两 | 丙 | 极高（「两火」= 丙火，「两透」= 丙透） |
| 业 | 丙 | 高（「业藏两透」=「丙藏丙透」） |
| 已 / 全 / 类 | 己 / 癸 | 高 |
| 成 / 戌 | 戊 | 高 |
| 森 / 林 / 本 / 未 | 木 | 高 |
| 王 / 汪 | 壬 | 中 |
| 刁 / 了 | 丁 | 中 |

### 使用方式

- ✅ 用来看「这一格的白话意思大致是什么」。
- ✅ 用来定位底本对应的段落（白话本每格起首都重复原文首句）。
- ❌ 不可引用其原文层（讹误多）。
- ❌ 不可引用「方先生曰」（现代发挥，与徐注立场常有出入，且非古籍）。
- ⚠️ 引用「徐乐吾曰」前，须回底本核对（底本「按」字段内容与其一致度约 0.9）。

## 三、华龄本（`o_hualing/`）的使用规则

- 2015 年华龄出版社「四库存目子平汇刊〔五〕」，余春台辑 / 徐乐吾注 / 郑同校，简体横排。
- 优点是**简体横排、句读清楚**，适合校对底本的字形（底本形近字多为抄录所致，华龄本已改正）。
- OCR 为黑白石刻体，字形识别尚可，但标点与段落结构丢失。
- ⚠️ 同样**不可直接引用**，只作校字参考。
