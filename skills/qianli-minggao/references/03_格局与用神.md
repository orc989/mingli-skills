## 一句话立场

韦千里的格局观只有一个判准：**「今有一字，能助格局之成功，救格局之破败，抑格局之太过，扶格局之不及——此字即用神也。」**

格局是躯体，用神是灵魂。断命断的是用神，不是断格局名。

> 原书原话：「日主有强，有弱，格局有成，有败，有太过，有不及。今有一字，能助格局之成功，救格局之破败，抑格局之太过，日主之太强，扶格局之不及，日主之太弱，此字即用神也。命以用神得力为上，用神不得力为下，无用神为更下。日主格局，犹人之躯体；用神，犹人之灵魂。」

这句话有三层实操含义：

1. **先论强弱，再定格局，然后才有用神** —— 顺序不能倒。同一个月令，日干强弱不同，用神可以完全相反。
2. **用神是「字」，不是「神」** —— 落实到具体的甲乙丙丁，不是「宜用财」这种抽象结论。
3. **用神有力无力，直接定命之上下三等** —— 所以拿到一个八字，先问「用神在哪、有没有被克合刑冲」，而不是先喊格局名。

## 一、取格四法（按顺序走，不跳步）

月令是取格的唯一准绳。四法按优先级排列，**能用第一法就不用第二法**。

| 序 | 条件 | 取法 | 例 |
|---|---|---|---|
| ① | 月支**本气**透干 | 取本气为格 | 寅月透甲 → 木（甲日则非格，见下）；辰月透戊 |
| ② | 本气不透，月支**所藏之神**透干 | 取该神为格 | 寅月不透甲，透丙或戊 → 食神格／偏财格 |
| ③ | 支藏两神并透干上 | **择其一**（有力而无克合者为上） | 寅月丙戊并透 |
| ④ | 本气与所藏**皆不透** | 以人元轻重较量，择一有力无克合者为格 | 寅月甲丙戊全藏 |

### 两条硬边界

- **比劫不能取格。**
- **禄、刃不在八格之内**（甲生寅月为禄、甲生卯月为刃）——归外格篇处理。

月令为禄为刃时，不是「没有格」，而是**八格的路走不通，必须转外格篇**。这一步走错，后面全错。

> 原书：「惟取格为推命第一部手续，格定，然后可以论用神及喜休咎。其关系最为重要。」

### 八格名单

正财格、偏财格、正官格、七杀格、正印格、偏印格、食神格、伤官格。

十二个月 × 十干 = 120 条取格详例，全在 `vol_geju.md`（PDF 33—36）。**遇到具体月份直接查表，不要凭印象推**——原书的详例与机械推导有多处不合，例如：

- 甲生辰月，戊癸皆不透，「**亦可酌取其一**」；
- 甲生酉月透辛为正官格，「**不透亦可取**」（独气之月，不待透干）；
- 甲生亥月、子月同理，「不透亦可取」。

**规律**：月支只藏一干（子、卯、酉）或本气独旺之月，**不必等透干**即可取格；月支藏两三干者，必须透干或较量轻重。

## 二、成败太过不及：四把尺子

同一个格，有四种病、四种成。这是取用神前的最后一道筛。

| 格 | 成（成功） | 败（破坏） | 太过 | 不及 |
|---|---|---|---|---|
| **正官** | ①日强有财生官 ②日弱官强有印生身 ③不见七杀混杂 | ①见伤官而无印 ②刑冲破害 ③杀来混杂 | ①官得令众多，日主衰弱不堪 ②官强身弱又多财生官 | ①身强过于官，无财滋官 ②身强过官，多印泄官、伤食克官 |
| **正偏财** | ①日强财强再见官 ②日弱财强有印比护身 ③日强财弱有伤食生财 | ①日强财轻劫比重 ②刑冲破害 ③日弱杀重财又生杀 | ①财得令众多，日主衰弱不堪 ②财旺身弱又多伤食泄身生财 | ①身强多比劫禄刃 ②财无伤食之生，多劫印剥夺 |
| **正偏印** | ①日强印轻逢官杀 ②日强印强有伤食泄身 ③日强印多见，财透出减印力（**财根不可太深，否则印财互断而印败**） | ①日弱印本轻又逢财坏 ②日弱印太重而多官杀 ③刑冲破害 | ①印重得令，日弱财轻 ②印与劫比皆强，独伤食财官轻浅 | ①财重无官 ②多比劫禄刃 |
| **食神** | ①日强食强再见财 ②日强杀尤过之，食神制杀不见财 ③日强食神泄气太过，见印护身 | ①日强食轻又逢枭 ②日弱食神生财又露杀 ③刑冲破害 | ①伤食太重，日主太轻，无印或多财 ②身强杀浅，伤食制杀太过又无财解 | ①印重身轻 ②身弱财官太多 |
| **七杀** | ①身强 ②日强杀尤过之，有食制杀 ③日弱杀旺有印生身 ④杀身两停无官混杀 | ①刑冲破害 ②日干弱 ③财当杀而无制 | ①杀太重身太轻不见伤食 ②财多身弱，杀又得财生 | ①食重无财 ②身强印强 |
| **伤官** | ①日强伤官生财 ②日弱伤官泄气有印护身 ③日弱伤官旺而杀印双透 ④日强杀重伤官驾杀 | ①见官 ②日弱又多财 ③日强伤官轻而多印 ④刑冲破害 | ①伤食太重，日主太轻，无印或多财 ②身强杀浅，伤食重而制杀太过，又无财解 | ①印重身轻 ②身弱财官太多 |

### 用这四把尺子的正确姿势

1. **先看有没有「败」**，有败先议救。伤官见官无印 = 败已成，任何用神都要先解决这一条。
2. **再看「太过」还是「不及」**，这两个方向决定用神是泄是扶。
3. **「成」的三条只是加分项，不是取格条件**——原书列「成」，是在告诉你这个格**最理想的配置长什么样**，用来反推用神方向。
4. **刑冲破害一票否决**：财、官、印、食、伤五格都把「遇刑冲破害」列在破坏项。这是硬伤，且贯穿全书（`vol_pingduan.md` 岁运诸条反复引用）。

## 三、八格取用速查表

**读法**：先定日干强弱 → 找对应行 → 看其余六神哪一路最重 → 得到用神。表格直接来自原书 PDF 39—40「八格之用神」，未作改写。

| 格 | 日干 | 局中之病 | 用神 |
|---|---|---|---|
| **正官** | 弱 | 财星重 | 比劫；无比劫则用印 |
| | 弱 | 伤食多 | 印 |
| | 弱 | 官杀重 | 印 |
| | 强 | 劫比多 | 官 |
| | 强 | 印多 | 财 |
| | 强 | 多见伤食 | 财 |
| **偏正财** | 弱 | 伤食多 | 印 |
| | 弱 | 财重 | 比劫 |
| | 弱 | 官杀多见 | 印 |
| | 强 | 劫比重重 | 伤食为宜，官杀亦宜 |
| | 强 | 印多见 | 财 |
| **偏正印** | 弱 | 多官杀 | 印 |
| | 弱 | 多伤食 | 印（**尤宜**） |
| | 弱 | 多财 | 劫比 |
| | 强 | 比劫重重 | 有官杀用官杀，无官杀用伤食 |
| | 强 | 印重 | 财 |
| | 强 | 财多 | 官杀 |
| **食神** | 弱 | 官杀多见 | 印 |

| **七杀** | 弱 | 财多 | 比劫 |

| | 弱 | 官杀重重 | 印 |
| | 强 | 比劫多见 | 杀 |
| | 强 | 印多见 | 财 |
| | 强 | 官杀重重 | 伤食 |
| **伤官** | 弱 | 财多 | 比劫 |
| | 弱 | 官杀多 | 印 |
| | 强 | 伤食重重 | 印 |
| | 强 | 比劫多 | 七杀 |
| | 强 | 印多 | 财 |

### 表里读不出来的三条暗线

1. **「弱用印、强用财」是主干，但七杀格反着走**：日弱杀重不取印以外的路（印既生身又化杀，一举两得）；日强杀重却取**伤食**（食神制杀），不取财。这是全书唯一「强弱两头都用同一逻辑之外」的格，最容易错。
2. **身强印多用财，但正印格写明「财根不可太深」**——财太重会把印连根拔断，反成败格。所以「身强印多用财」是有刻度的，不是无限用财。
3. **伤官格身强比劫多，用七杀而不用财**。理由在六神篇：伤官已能生财，再加财则日干更泄；用杀者，以杀制比劫而护财。

## 四、取用补缀：七条「用神之需要」

原书明说前表「寥寥数例，岂能包括意万命造……拘泥拗执，则不免毫厘千里之弊」，故补七条检核标准。**这七条是用神的验收清单，取到用神后必须逐条过**：

| # | 条件 | 判法 | 若不合 |
|---|---|---|---|
| ① | **有势** | 用甲木，适当春月 | 得令则力足 |
| ② | **有援助** | 用甲木，见乙木或癸水之助 | 无援则孤 |
| ③ | **在干得气** | 用甲木，支见寅卯 | 干透无根则虚 |
| ④ | **在干不见克合** | 用甲木，无庚克己合 | 被克合则伤 |
| ⑤ | **在支得干生助** | 用巳火，得甲木资生、丙火帮助 | — |
| ⑥ | **在支无刑冲合害** | 用巳火，不见亥冲寅刑 | — |
| ⑦ | **既见冲克而有解救** | 用甲木受庚克，有乙木合庚或丙火克庚；用巳火被亥冲，见卯木三合亥水 | 无救则用神亡 |

**实操顺序**：④⑥ 先查（有没有伤）→ ⑦ 次查（伤了有没有救）→ ①②③⑤ 后查（本来有多足）。

一条命能不能断准，八成取决于这七条过不过。**用神被合被冲而无救，就是「无用神」，命属下等**，此时不要硬断富贵，只能断「奔波、无成、依人作嫁」（`vol_buchong.md` 事业条）。

### 用神的三等区别

| 名 | 定义 | 断语权重 |
|---|---|---|
| **健全** | 用神无克合刑冲 | 可直接断富贵层次 |
| **相神** | 用神力不足，有他字生助；或用神受刑冲克合，有他字解救。「**与用神有同等之重要**」 | 断命必须同时看相神，相神受伤等同用神受伤 |
| **格局相兼** | 如以财为格，用神亦属财，格局而兼用神 | 力最厚，「其重要更可知矣」 |

⚠️ **相神这个概念是韦千里的关键贡献，也是初学者最常漏的一条**。看到「用神有救」就放心断吉，是错的——要去查那个「救它的字」自己有没有被伤。

## 五、外格：什么时候才轮到它

原书给外格设了一个门槛：

> 「论命由阴阳五行干支之生克，进而取八格与用神，已可十得八九。然尚有越出常理，非八格所通及者，遂有外格之设。」

**所以外格的启用条件是：月令为禄为刃，或全局气象专一至极，八格的路确实走不通。** 不是「八格取得不好看就换外格」。

### 五大局（气象专一）

| 格 | 构成 | 用神 | 喜 | 忌 |
|---|---|---|---|---|
| **曲直**（木） | 甲乙日生春月，支全寅卯辰东方或亥卯未木局，无庚辛申酉 | 木 | 水木相助；见火吐秀亦善；逢土为财有火则不妨 | 金克伐 |
| **炎上**（火） | 丙丁日生夏月，支全巳午未南方或寅午戌火局，无壬癸亥子 | 火 | 木火相助 | 水克伐 |
| **稼穑**（土） | 戊己日，土局土旺无木 | 土 | 火土；金泄秀 | 木克 |
| **从革**（金） | 庚辛日生秋月，支全申酉戌西方或巳酉丑金局，无丙丁 | 金 | 土金；水泄秀 | 火克 |
| **润下**（水） | 壬癸日生冬月，支全亥子丑北方或申子辰水局，无戊己 | 水 | 金水；木泄秀 | 土克 |

（炎上、稼穑、从革、润下的完整构成与命例见 `vol_waige.md` PDF 40—45。曲直格原文见 PDF 40。）

### 外格的判准要害

1. **「全无冲克」是硬条件**，不是「大体没有」。曲直格见一个庚字就破。
2. **既成外格，就以所成之五行为用神，不再论八格那套扶抑**。曲直格「其秀气完全萃聚于日木之木，即以木为用神」。
3. **外格喜「泄」**：木见火吐秀、金见水吐秀、水见木泄秀。这是外格与八格最大的差别——八格讲扶抑，外格讲流通。
4. **化气格、从格另有一套门槛**（见 `vol_waige.md`），其中化气格有五道关卡：时令、宾主、明暗、地位、岁运。**日干逢合才可化，他干逢合不能化；岁运逢合只作本气论，不作化论**。这三条否掉了市面上大部分「化气格」。

> 补充篇原话：「**甲日逢己运或己岁，应以正财论，不作化土论。**」——《vol_buchong.md》干合而化

## 六、常见错误清单

| 错法 | 后果 | 正解 |
|---|---|---|
| 先喊格局名，后看强弱 | 用神取反 | 顺序：强弱 → 格局 → 用神（评断八步第①②③） |
| 月令为禄为刃仍强取八格 | 全盘皆错 | 转外格，或按 `vol_bijieluren.md` 专论 |
| 月支独气之月非要等透干 | 取不出格 | 子午卯酉等独气月，「不透亦可取」 |
| 用神取到「神」不到「字」 | 无法查喜忌、无法查岁运 | 必须落到甲乙丙丁 |
| 只看用神不看相神 | 误判吉凶 | 相神与用神同等重要 |
| 八格取不成便套外格 | 断语虚高 | 外格有硬门槛：全无冲克 |
| 化气格不看「日干逢合」 | 满盘化气 | 只有日干逢合才可化；岁运不作化论 |
| 忽视刑冲破害 | 成败判断失真 | 五格破坏项皆列此条，属一票否决 |
