# 事业关

事业关
事业关就是断人家是干什么的。如果方法掌握了，就不难。
什么方法呢，就是这三部曲。
第一步，找格局，
第二步，检查格局是否成立，
第三步，取象
为什么要找格局呢，因为，世界上的工作千万种，但是不管怎么变，永远是这几
种情况。第一种，在国家单位上班的，我们称之为吃皇粮的。第二种，在私人单位打
工。第三种，自己开买卖的。无非就是这几种。所以要先定格局，看看属于哪一种。
检查一下是否成立，就可以取象了。为何不可以直接 取象? 因为，你比如说火克金，
可能是设计院上班设计图纸的，设计院一般是国家单位。也可能是干电工，或者是干
电子的，格局不定，你不好取象他到底是干嘛的。而格局实战用到的是这几种。
化官生印，食神生财，食神制杀，杀印同宫，印禄相随。符合这几条的，家里家
外有联系，断国家单位上班的工作。家里有财官有印，有资源，断开买卖的。取外面
财官，又不符合条件的，一律是私人地方打工。有印生，可以有点管理。食神生财销
售多。女命制金财，一般是二财务的，先断格局，再分析就简单了。
不按这个步又，就是神仙也不能断定命主是干嘛的。化官生印，要求的是，官印
必须都有自己的份，其中一个跑出去了，又立得住，这就是官生印.
食神生财与以上要求也一样，然后检查食神能否立的住。食神制杀也是如此。
印禄相随，需要禄是自己的，印在家里和外面有关系。
