# 六亲断法要点汇编

把六份资料里关于夫妻、子女、父母、兄弟、性情、疾病的可操作判语集中在一处，供快速调用。**每条都标了出处层级**，引用时要如实标注。

## 一、夫妻（任注：`chanwei_夫妻.md`；民间：金镖门第八课）

### 任注的核心判语（可直引）

- 「夫妻因缘宿世来，喜神有意傍天财」——看妻先看「喜神」（即用神邻近的财）是否有意。
- 依财看妻：「喜神即是财神，其妻美而且富贵；喜神与财神不相妒忌亦好，否则克妻，亦或不美，或欠和。」
- 财神薄 → 须助财；财旺身弱 → 喜比劫；财神伤印 → 要官星；财薄官多 → 要伤官。
- 任注列出的克妻/妻贤条件（可直接对照）：
  - 财神轻而无官、比劫多 → 克妻
  - 财神重而身弱、无比劫 → 克妻
  - 官杀旺而用印、见财星 → 妻陋而克
  - 官杀轻而身旺、见财星遇比劫 → 妻美而克
  - 劫刃重、财星轻、有食伤逢枭印 → 妻遭凶死
  - 财星微、官杀旺、无食伤有印绶 → 妻有弱病
  - 身强煞浅，财星滋杀／官轻伤重，财星化伤／印绶重叠，财星得气 → 妻贤而美，或得妻财致富
  - 杀重身轻，财星党杀／官多用印，财星坏印 → 妻不贤而陋，或因妻招祸
  - 日主坐财、财为喜用 → 必得妻财
  - 日主喜财、财合闲神而化财 → 必得妻力
  - 日主喜财、财合闲神而化忌神 → 主妻有外情
  - 日主忌财、财合闲神而化财 → 主琴瑟不和

### 金镖门的两条总口诀（民间层，可作辅助）

- 「财是命中情缘线，男女财星不可断，情线一断财门关，男女皆是半路缘」
  → 财星是六亲星里唯一能与夫星、妻星、子星都发生关系的星，所以断任何六亲都要回头看财。
- 「劫财见财婚可恼，配偶要跟别人跑」
  → 但**不是见劫财见财就离婚**。判断分支：
    - 财轻劫重 + 有官星护财 → 离不成
    - 财星得局 + 日主身弱不胜财 → 来比劫帮身反而是好婚
    - 财轻劫重 + 无官护 → 才论离

### 女命取夫的三个分支（金镖门，最实用的一条）

1. 官杀有力且为用 → **官杀就是夫**（原则层）
2. 官杀无气 → 以**财**为夫（财生杀）
3. 官杀太旺、化官生印 → 以**印**为夫（此时最怕财坏印）

## 二、子女（任注：`chanwei_子女.md`；民间：金镖门第六、七课）

**必须先声明取法**：男命子女星存在两套取法——

- 任注体系：我生者為子女 → **食神伤官**
- 金镖门体系：男命以**官杀**为子女

两套取法在同一命上结论可能相反。使用时必须写明「按食伤取」还是「按官杀取」，不得混用。

生男生女的民间判法（金镖门第六课）：以子女星的阴阳与旺衰定，且要看该星是否被克。**准确率作者自己承认不是 100%（有四对三、七对五的案例）**，引用时须带上这个限制。

## 三、父母、兄弟

- 父母＝印（任注改定，反对「财为父」）。依据：`chanwei_父母.md`
- 兄弟＝比劫。依据：`chanwei_兄弟.md`
- 民间层补充（金镖门第十二、十三课）：出身看年月柱与印星层次；兄弟有无看比劫的旺衰与是否被冲。

## 四、性情（`chanwei_性情.md`，35 例，是全书命例最多的一章）

任注的路子：**五行的偏全与燥湿决定性情**，不是拿十神套性格。

- 木旺无金 → 仁而少断
- 火旺无制 → 急而少礼
- 金旺无水 → 义而寡恩
- 水旺无土 → 智而多诈
- 土旺无木 → 信而少通

金镖门的补充：性情要看用神是否被坏——用神得力者「心气平和」，用神受克者「心多忧疑」。

## 五、疾病（`chanwei_疾病.md`，23 例）

任注的口径：**忌神克身、用神受伤** 对应脏腑。五行配属需按具体命局，不做泛化套表。

添情在多个命例上补充了一条方法论：若原局有「最凶组合」（如卯木合拌亥水根、辰土晦午火），且该组合在晚年柱位，则对应疾病多发于晚年。这是**限运定位**的思路，不是流年断法。

## 六、岁运（`chanwei_岁运.md`）

任注只论大运，不论流年。梁湘润批评这是任氏论式的天生缺陷。

实操约定（本技能强制）：
- 大运层判断 → 可直接引任注
- 流年层判断 → 必须标注「外推」，并说明外推依据（如「引动原局某组合」）

## 八、不能省的一句话

所有六亲断语都建立在**用神已定**的前提上。用神未定就断六亲，等于没有地基。金镖门第一课的原话：「一个八字是有用神的，找不到用神，就不可能断对六亲。否则只能是刻舟求剑，缘木求鱼。」
