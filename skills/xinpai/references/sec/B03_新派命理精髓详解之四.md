# 新派命理精髓详解之四

新派命理精髓详解之三十 
 
乙巳 辛巳 辛巳 庚寅(申酉) 
 
辛金生于巳火月，日干弱于月令，日支巳火有力制日干，日干肯定弱。日
干弱的八字有两种可能：可能是从弱格，也可能是身弱用印比。区分究竟是哪种
格局，就看局中印比的力量大小了，如果局中印比有根、有力．日干就不从弱。
如果局中印比无根、无力，日干就从弱。 
本命局中帮扶日干辛金的字有时干庚金，时干庚金坐下寅木无根，时干庚

金不能帮扶日干辛金；月干辛金为日干之比肩。为帮日干的字，但是辛金坐下是
巳火，并且局中再也没有哪个字能够使月干这个辛金增加力量了，月干辛金无力，
也不能使日干辛金增力，所以本命为从弱格。 
年干乙木为父亲，制月干辛金对日干起了好作用，为用神。年支巳火为父
亲身体，巳火泄年干乙木为凶．更有时支寅木生日支巳火，日支巳火有力帮月令
巳火，月令巳火很有力地帮年支巳火，可断本命父亲的身体十分不好，由此可断
父亲的寿命不长。但是本命我断为爷爷去世的很早，应当去世于自己出生以前．但
是父亲的寿命却很长。答:正是。至今父亲已经七十多岁了，仍然身体健康。 
为什么会有如此一断，不仅不懂八字预测术的朋友不明白。就连一些读了
涵辰所写的八字预测教材的易学爱好者，也会深感不好理解。 
涵辰八字预测术，不是孤立存在的一个独立的八字预测术，是集八字预测
与风水预测术于一体的一个十分先进的预测体系。世上相同八字的人有若干，其
吉凶不同，便有力地证明了要想做到准确地预测，必须真正全面掌握预测术，浅
尝辄止、是不能真正做到准确地预测的。 
本命就是那种不克父亲的命局组合，从拿到八字的最初，就可以十分把握
地断定其父亲为寿长之人，要做到这一点必须具有十分高超的八字预测技能才能
做得到，在前面的例子中，有许多这样的话：“本命是为官不久的命”，“本命为
婚姻不吉之命”，或“本命一生必定三婚”等，诸如此类的话语，就是从八字的
构成上做出的判定。这属于八字预测与风水预测完美结合的技能，要想掌握这个
技能，必须是熟练掌握了涵辰的八字预测术、与涵辰独家风水预测术的人，才有
可能掌握。在以后的著作中，会逐步进行讲解涵辰风水与涵辰八子相结合的独门
秘技。

新派命理精髓详解之二十八 
 
 
丁亥 乙巳 庚戌 壬午(寅卯) 
 
日干庚金生于巳火月，巳火在局中仅一次受制，月令对日干的作用足够50%，
所以日干有一半弱的可能，此时，只要日干旁边的字再有一个制日干，日干肯定
就弱。

月干乙木是使日干庚金减力的字，由此可断日干弱。 
本命局中没有一个字是使日干庚金增力的，所以本命从弱。 
用神：乙、壬。忌神：丁。 
生活中常见到有的人婚姻十分不顺，已至到了相当大的岁数了。还没有成
婚。无论男性还是女性，这种情况在生活中不鲜见，直到岁数较大或很大时，对
其婚事都不抱希望了，却突然顺利结婚并生子。这种命局的组合多是局中婚姻组
合不吉，行运又是于婚姻这个字不利的字，或使局中达到最吉利的那个字还没有
行到，故而婚姻会迟。一个人结婚在哪年、定亲在哪年、父母亲去世于哪年、升
官于哪年等，都是命中注定的，只要年运还没有行到、这一切就不会出现，只要
导致这些事情发生的那个年运一到、事情就会发生。如果不是这样，我们算命就
算不准了。而决定这些大事发生的时机，往往就一个字决定，决定大事情发生的
字，叫命门。从八字中找出决定事情发生的命门至关重要，是搞好预测的唯一法
门。 
本命局中月干乙木为正财为妻，为用神，在先天风水中弱，本命婚姻不十
分好。更有年干丁火在先天风水中旺泄乙木，日干庚金在先天风水中旺克乙木，
乙木这个字为多方受制。好在壬水时干在先天风水中有力泄日干庚金，使日干庚
金减力，乙木得救，这就是本命婚姻的组合情况。要想婚姻成功，必须是在壬水
制去庚金时，才能有婚姻之庆。 
28 岁后行壬寅大运，壬水制日干庚金，这一运中才会婚动。在这一运中，
再使乙木旺的流年时婚吉。 
壬寅大运中乙木旺的流年有以下这几年： 
壬寅大运，壬戌流年。两个壬水有力泄日干庚金，庚金弱，不制月干乙，
为日干导致了正财吉时，可断这一年有女性追。答:是。为什么不断是定亲？原
因是庚金减力不制乙木了，可乙木在本年并没有旺起来。乙木在先天风水中本不
旺，只有使乙木旺时，婚姻才会大吉，实际情况时，该女长相不好自己不同意。 
壬寅大运，乙丑流年。乙木在流年出现，帮局中月干乙木，乙木有力了，
这一年有一个长相较好的女性又追我，同意了。并断其当年结婚。 
凡是流年出现的字所代表的六亲，在生活中都是主动来就我。 
月干乙木为母亲，在原命局中丁火泄乙木为凶，丁火在先天风水中旺制乙
木力大，所以逢丁火旺年母亲应凶。母亲去世于丁未年。时干壬水为儿子，孙子，
壬水旺时子孙吉。而壬水旺，必须是制去月干乙木时，日干庚金最旺，生时干壬
水时。而丁火制乙木为最有力，所以逢丁年就是时干壬水最旺之时。丁卯得之子，
丁亥得孙。 
时干壬水还为父亲，身体看午火，午火旺父亲才会身体好，命局中巳火生
戌土，戌土制时支午火，父亲身体不好，父亲去世于丁巳年。

新派命理精髓详解之二十七 
 
庚午 甲申 乙丑 丁亥(戌亥) 
 
乙木生于申金月，弱于月令，日支丑土制日干，日干肯定弱。在本命局中，
月干甲木是帮日干乙木的字。但是月干甲木在局中无根、无力，甲木不能帮扶日
干乙木，乙木日干不得局中的帮扶，时支亥水空亡，又与日干隔不作用，不能帮
扶日干，日干从弱。

用神：庚、丁 
忌神：甲 
地支中的用神忌神，要视所测的内容而定地支某字的用忌神之性，八字预
测中，有一个内外环境论，在测不同的事情时，地支的看法不同，在某一件事上，
地支这个字的力量以大为应吉事。在用这同一个字测其他的事情时，地支这个字
的力量可能就是以弱为吉，这就是根据百神论法则得出的六亲地支反断之法则，
也就是地支反断论。 
甲木为正财、普通人所做的生意，或其他事业，最终的目的还是为了自己
利益的最大化，利润的高低，看局中的正财，如果正财吉一命主所做的事业营利
就好，利润率就会高。本命局中甲木在先天风水中弱，断此命所做的任何事业都
不会有大的利润。时干丁火在先天风水十分弱，制去丁火时，丁火无力泄乙木，
乙木日干旺帮扶局中的月干甲木，甲木旺必劳而无获。 
进入辛金大运辛金同性制时干丁火，时干丁火弱，本运中做事的利润十分
微薄。 
本命局中的年干庚金为正官，为用神，旺时谈成对象，壬水大运中，壬水
生甲木，制庚金，婚姻吉的时机必定是在流年制住壬水，使局中的庚旺时。 
壬申大运，戊子流年。戊土有力制大运壬水、大运壬水无力，局中的年干
庚金旺，这一年谈成了对象，并且这一个一定是要结婚的老公，谈成的月份必定
是在戊子年的午月。其回答说：就是在去年的夏天谈了对象。

新派命理精髓详解之二十九 
 
 
丁亥 乙巳 丙申 丁酉(辰巳) 
 
丙火生于巳火月，但巳火月令空亡，决定日干旺衰的50%以年支定，丙火日
干生于亥水年，弱于年支，日干弱。乙木生日干丙火，身弱用乙木。时干丁火反
断为忌神。

年干丁火泄月干乙木用神，对日干起了坏作用，年干丁火为忌神。 
月干乙木为正官，为用神，靠近日干，可断本命为官命．在乙木旺的大运
上当官。 
癸卯大运，癸水同性制年干丁火，同性生月干乙木，都会使月干乙木旺起
来，所以在癸卯大运中可提升。 
癸卯大运，戊申流流。癸卯大运异性制流年戊土，戊仍然有力量与局中的
字发生作用，制日干丙火，丙火减力对月干乙木正官起好作用，正官吉，这一年
提升。 
日干丙火在先天风水中弱，泄月干乙木力小，本命属于日干对正官起好作
用的命，此命为技术性干部。在丙火弱的流年上当官时，必定是当技术干部。由
此可断，本命在戊申流年时，成了技术科长。答：是技术科长。 
时干丁火为偏财，为忌神，在丁火旺的时候会破财，在制去丁火时会发偏
财。本命的组合还有一个十分显著的特点：为官不长。象这种为官不长的命．在
正官凶时，必定会被撤职。 
辛丑大运，辛金制月干乙木．本运中就会因自己犯事而下来。辛金大运同
时制时干丁火，丁火弱时会发偏财。丁火弱了，日干丙火会旺，日干丙火有力泄
月干乙木正官，可断为因为在这个技术科长的位置上贪污了钱，被顶头上司发现
被告发，而遭撤职。 
此命有趣的事还有很多，辛金大运制乙木，辛金大运制时干丁火，辛金大
运还制年干丁火。制月干乙木时正官凶，断官不当了。制时干丁火，断发偏财了。
制年干丁火，断本运中本命很受单位一把手的赏识．是一把手的红人。 
无论你的人际关系如何，只要是正官凶时，都不会逃掉官灾的命运。 
丁火在先天风水中旺，只要是丁火旺时，就会破偏财，丁火在流年出现时，
定会有大的破财之事。直断2007 年的丁火流年，刚买了新楼房，并且是买得四
楼。答：是。
