# 君象（中册）

2021.4.16 君象

  日主是“君”，财星是“臣”，实际“君象”说的就是日主比劫跟财的关系。当
“君”特别旺，“臣”弱极的时候，就要顺着“君”，顺着君，就要用食伤，用食伤
泄秀生财。
  君旺就克“臣”太过了，所以要顺着“君”的气势，用食伤把君给泄了，转而生
财，但是不能用官煞。因为日主是旺极，就是君是旺极的情况下，这时财肯定是太弱
的，财弱的情况下，官杀肯定也是弱，因为源头小了，而且日主特别旺，这时用官杀
也制不住日主。就是因为财星，也就是“臣”太弱了，来了官杀也没有多大力量。当
财官特别弱的时候，日主特别旺。这时要是用官杀，本身官煞没有力量，反倒让日主
“君”或者说比劫反克了，也就是激怒这个“君”了。
  比如咱们以木为日主，那木就是君了，土是财，土就是臣，你八字里全是木，那
就全是君或者君的比劫。这君肯定是旺极了，如果八字里只有一点土，也就是这土特
别弱，那就需要用火泄日主君的旺气，把君泄完之后用食伤再去生财去。因为臣不是
弱吗?如果八字里有金官杀，但是金的元神臣，还是太弱了，它扶不起这个君了，这时
金再去克制日主的时候，他反倒激怒了日主，因为日主木太旺了，所以金就不能为用
神，就是当财弱的时候，就不能用这个金。
  这个君象，他的前提是日主到了很旺的一个状态了。“臣”也就是这个财星弱，
主要就是君臣之间的一个比较，根据他俩的力量再取用神。如果要是能用官杀金的时
候，那日主也不会达到特别旺极的程度，所以对比五行的力量是很关键的，这个也是
取用神的前提。
  总结一下君象，前提是八字里有君臣这两种五行势力的关系，就是以这两种五行
为主，对比他们五行的旺衰，都是这个君是很旺，臣非常弱，君占有绝对的势力和力
量。然后八字里略有一到两个字的财星，就是说财星臣弱，以这两种关系的比较，再
取用神。
