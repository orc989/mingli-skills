# 新派命理精髓详解之三十九



    甲寅 辛未 壬申 乙巳(戌亥)
    [pic]
    壬水日干生于未土月，弱于月令，未土在局中一次受制，对日干的作用有50%，再制
申金日支．日干弱。局中月干辛金无根，不能生扶日干；日支申金在局中两次受制，也
不能生扶日干，日干从弱。
    用神：甲，乙，忌神：辛
    月干辛金是正官，为忌神，在先天风水中弱，这个命是老板命。甲木旺时，一段时
间上会在某单位工作，在偏官大凶或大吉时就会脱离单位。
    看一个是不是有文凭．先看这个人的正官是不是足够好，如果正官不足够好，就不
会正常读书完毕。会中途做偏官。如果命局中正偏印很吉，会在工作以后再考入大学拿
到文凭。本命正官为忌神，凶，更有时干乙木为偏官，为用神，所以会在偏官吉时干偏
业的。也就是本命没有读完书，没有读到正常的大学或专科学校毕业就工作了。
    谈对象时，所谈的对象是不是有对象，或者是不是对我对象正与他人谈着。看正财
的社会环境，社会环境吉，对方没有。社会环境凶，对方有目标或有配偶。
    癸酉大运与甲戌运中和我处对象的女朋友没有对象。丁火在先天风水中旺，丁火制
辛金有力，丁火流年正财最吉，丁丑年谈成。
    甲戌大运，丁丑流年。谈对象时，正财的内环境凶，和每个对象都谈不长，天干要
是吉总有对象谈，所以这样的流年上就会谈多个对象。天干十分吉，年底时谈成。丑冲
未，但是丑在先天风水中弱，未在先天风水中旺，未虽然减力，但不可能把未彻底制住
，所以这一年也算作是正财的内环境不够好，谈了多个。反馈说：谈了两三个。丁火旺
，这一年肯定会谈成。在对象肯定谈成的年份里，对象越换越漂亮。
    结婚看时干乙木，壬水在先天风水中较有力，原命局中壬水生乙木，偏官为吉，在
乙木旺时结婚。原局中甲弱、辛弱、壬稍旺、乙弱，壬水生乙木为偏官吉，让乙木旺时
才能结婚，只有壬水旺时才会是乙木旺。让壬水旺的字有庚、壬，断在庚壬年结。哪个
，就在哪个年结。庚年结婚。
    甲戌大运，庚辰流年。庚金流年制甲木，日干壬水旺，有力生时干乙木，偏官吉，
结婚。壬水旺结婚时的天气好。
    生男女的测法：时干乙木为女，年干甲木为男。甲木大运中年干甲木用神旺，大运
甲木制壬水，时干乙木弱、本运生男的可能性大。
    甲戌大运，辛巳流年。时支巳火旺，女孩的内环境凶，不生女。
    大运分析：甲戌大运，正官的社会环境吉，在单位中受到二把手的器重，辛金被制
，所教的课目成绩突出。甲木制日干壬水，壬水日干弱，无力泄月干辛金正官，日干对
正官起了坏作用，不讨直接领导的喜欢。综合一下可断为：在本运中顶着压力做出了较
为出色的工作成绩。同时，壬水日干被制，不生时干乙木，本运中会破财。
    乙亥大运，制辛金正官，正官吉、工作轻松，与直接领导的关系密切，工资也高。
同时，时干乙木为偏官，偏官吉，本运中会干偏业．并在偏业中做出成绩，偏官乙木旺
时，泄日干壬水，壬水减力不制正官辛金，可断为本运中因为喜欢偏业，一定程度上影
响了正常工作。
    丙子大运为事业不吉之运，丙火制去甲木、壬水，正官偏官都凶．所以本运会改行
，一事无成后，又回到原先的行业上。
    甲木大运制辛金，正官的天干吉，在单位中受领导重用，二把手重用我，学校副校
长把我安排在一个重要班级。学生的学习成绩与老师的印之吉凶有关．甲戌大运制月干
辛金正印、正印吉，制壬水时干乙木弱，偏印凶，所以我教理科。辛金弱时，我的学生
学的就好，我的辛金旺时，我的学生学的就不好。
    甲戌大运，辛巳流年，辛金在流年出现，辛金在先天风水中弱，最终以弱断，成绩
好。
    甲戌大运，壬午流年。甲木与壬水都制辛金，正印最吉，这一年学生的学习成绩提
高十分明显。
    甲戌大运，癸未流年。甲戌大运，直接领导不喜欢我。答：教导主任对我不好。癸
水流年生时干乙木，时干乙木旺，泄日干壬水，导致了辛金旺，直接领导对我不满。对
我不满的原因是时干乙木，时干为偏财，我偏财吉，导致了正官凶，大家都给教导主任
送礼，我没有送，他对我不好。
    甲戌大运为社会环境吉的大运，必须是在吉流年才会换工作。逢凶流年时，只是临
时出差，不为调动工作。
    癸水流年泄辛金月干，辛金弱，不制年干甲木，社会环境大吉，这一年换了工作，
是干了个好工作。答：负责实验室，这是个大家都想做的好活。癸水生时干乙木，偏财
吉，在岗位上有外财得。买实验用品时得了些小财。
    甲戌大运，甲申流年。甲木在流年出现，社会环境又吉，有一个岗位要我。教导主
任不同意，但是甲木之力弱于壬水之力，最后去了。
    甲戌大运，乙酉流年。工作干得很顺手，辛金被制，工作成绩突出。深得学生之喜
爱。辛金弱，学生的成绩突出。时干乙木旺，偏财吉，有个女老师喜欢我。日干壬水弱
，这个女老师皮肤不白．乙木旺，长相还好。此女与其情人刚刚要分手，才与我关系近
乎了不少，但是酉金流年制时支巳火，偏财的内环境凶，没有发展到很好的地步。戌土
大运制申金，为我的偏财方面的同行对我偏财内环境起了好作用，可断为该女刚刚与其
男友分手。
    甲戌大运，壬午流年。辛未为妻，辛金为忌神，未土为妻之身体，旺为凶。而未土
在先天风水中是最旺的，所以断妻大凶。在未土旺的大运流年上克妻。戌土在先天风水
中旺，局中年支寅木在先天风水中又最弱．戌土有足够大的力量制去局中年支寅木，未
土旺，本运中妻凶。午火流年克去日支申金，未土旺无制．妻去世。未土在先天风水中
最有力，未土为凶，得胃病，并且是胃的上口有病。答：是胃窦癌。
    甲戌大运，癸未流年。癸水泄月干辛金，正财吉，今年再谈一个。
    甲戌大运，甲申流年。甲戌大运中偏官凶，让乙木弱的流年结婚。甲木大运制月干
辛金，辛金弱，壬水弱，再逢甲木流年时，壬水被制，时干乙木最弱，本年结婚。断时
间在七月。
    母亲的寿命长，辛未为母亲．辛金在先天风水中弱，天干大吉。地支中未土在先天
风水中旺，内环境也吉。只有时支巳火弱，在巳火弱时，不利母亲。卯木在先天风水弱
，卯木不能生巳火，所以断在卯木大运母亲为凶。
    父亲的寿命：乙巳为父亲，巳火在先天风水中弱凶，根据天干、地支间的相互作用
，断父亲应凶在辛金弱时。
    丁丑大运制乙木为父亲应凶之大运。乙亥大运中，辛金月干受制、本运也为父亲身
体不吉之运。
    乙亥大运，戊子流年。这一年的夏天得过病，答：是突然晕了过去。
