# 六部底本的差异对照与选用规则

六份资料不是同一本书的六个版本，而是**四个层次的文本**。用错层次会导致「拿注解当原文」「拿民间口诀当经典」的方法论错误。

## 一、文本层次

| 层级 | 文件 | 性质 | 能否作原文引用 |
|---|---|---|---|
| L0 原文 | `liuji_原文与注.md` | 京图撰、刘基注，仅 34 章「通神论」 | 可（最接近原貌，但无命例、无六亲 28 章） |
| L1 主注 | `chanwei_*.md`（60 章） | 任铁樵《滴天髓阐微》，逐句注 + 大量命例 | 原文可引；「任氏曰」须标注为清代注解 |
| L1' 别注 | `素庵_滴天髓辑要.md` | 明·陈素庵辑本，体例完全另立 | 可引其「天干论／地支论」条，不可当原文 |
| L2 批注 | `liang_滴天髓今注.md` | 梁湘润，批判性批注 | 只作方法论参照，明确标注「梁批」 |
| L3 逐例解读 | `chenwei_添情全部命例.md` + `.csv` | 当代人语过添情对 342 例的再解读 | 只作**解盘范式**参照，不作经义依据 |
| L4 民间实战 | `jinbiaomen_滴天髓与民间应用.md` | 金镖门弟子班教材，13 课 | 只作技法参照，且须过滤其价值判断 |

## 二、四个体系的真实分歧（这是本技能最该讲清的部分）

**分歧 1：以什么为断事总纲**

- 任注：以**气象与格局层次**为纲。「顺则吉兮凶则悖」「天地顺遂而精粹者昌」——先看全局气势能否流通成象，再看六亲。
- 添情：以**用神是否得力、是否被坏**为唯一主线。每个命例第一步都是「身旺格用某／身弱格用某」，然后检查用神有无被合、被拱、被拌、被晦。夫妻、子女、事业全部由用神推出。
- 金镖门：与添情同源，但更进一步——**女命以用神当丈夫**（官杀为夫是原则，断事时用神才是夫），并给出「财是命中情缘线」这一条总口诀。
- 梁湘润：主张**回到子平真诠的格局法**，认为滴天髓的「气」论过于玄虚，且明确「否定神煞」「否定墓库冲发、三刑」「否定方局混」。

**分歧 2：六亲取象能否直接套十神**

- 任注（夫妻章）明确反对「财为父、官为子」的旧说：「若据此为确论，则翁女同宗，岂不失伦常乎？」他重定：生我者父母（印）、我生者子女（食伤）、我克者妇妾（财）、克我者官鬼（祖父）、同我者兄弟（比劫）。
- 梁湘润：「十神只是六亲之取认」——十神是识别六亲的标签，不是断吉凶的依据。
- 金镖门：男命以财为妻是死规矩，女命则须先看官杀旺衰，官杀无力时改以财为夫、官杀过旺化官生印时改以印为夫。

**分歧 3：命例怎么读**

- 任注命例多为「仕至郡守」「生三子皆就书香」式的结论，**极少交代流年**。梁湘润因此批评任氏论式「只有限运，不问流年」。
- 添情在每个命例上补一句「由于本书中的命例很难知道流年如何，只能根据限运看」——这是六份资料里唯一自觉声明证据边界的地方，做预测时应当沿用这条纪律。

## 三、选用规则（按任务类型路由）

| 你要做的事 | 先读哪个 | 再用哪个校验 |
|---|---|---|
| 引一句《滴天髓》原文 | `liuji_原文与注.md` | 与 `chanwei_天干.md` 等对校 |
| 解释某章经义 | `chanwei_<章名>.md` | `素庵_滴天髓辑要.md` 看另解 |
| 判断某个命局层次 | `chanwei_衰旺/中和/源流/通关.md` | `liang_滴天髓今注.md` 的「否定」条目 |
| 断具体事项（婚姻、子女、疾病） | `jinbiaomen_…md` 对应课 | 回 `chanwei_夫妻/子女/疾病.md` 核原注 |
| 看某个八字是怎么被拆解的 | `chenwei_添情命例索引.csv` 按四柱检索 | `chenwei_添情全部命例.md` 读全文 |
| 检验自己的判断是否过拟合 | `liang_滴天髓今注.md`「真理与模糊」 | 本节的分歧清单 |

## 四、已知缺陷与使用纪律

1. **阐微编号错位**：PDF 抽取出的 62 章中，「十二、母象」「二十二、臣象」「二十六、出身」三处编号与前后文不连续，属原件排版问题，已按章名归档，检索时请用章名而非编号。
2. **添情命例不全**：原书自称 518 例、16 例存疑，本 doc 可结构化 342 例，14 例含「存疑」标注。缺口是表格型命例与跨页断裂，**不要声称「全部 518 例已录入」**。
3. **金镖门教材的价值判断不可取**：其「女命贵贱三等」「90% 男人都会出轨」等论述是原作者立场，与本技能的技法部分无关。引用其技法时必须剥离这些内容，也不要拿它去评价真实的人。
4. **缺少流年**：任注、添情两级命例基本只有大运。任何据此做的流年推断都属于外推，必须显式标注为外推。
5. **两处同名异书**：`任铁樵 - 滴天髓阐微.pdf` 与 `滴天髓原文（刘基注）.pdf` 的开头都自称「滴天髓阐微」，但后者实际只有 34 章且无命例，是刘基注本的翻印，不要混用。
