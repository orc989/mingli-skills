# 05 六神喜忌速查

> 对应原书：**六神篇**（PDF 23—31）、**比劫禄刃篇**（31—33）
> 底本：`references/vol_liushen.md`、`references/vol_bijieluren.md`
> 本文是八步评断法**第④步「论喜忌」**的作业手册。

---

## 一、为什么是「六神」而不是十神

原书开篇自设一问：

> 「五行生克比和，有伤官、七杀、正官、食神、偏财、正财、枭神、正印、比肩、劫财等名目，共有十类。而神止取六者，何也？**盖比肩劫财，不能成格；而偏正财、偏正印，又称曰财印——既舍比劫而再合并财印，是以神共有六耳。**」

即：

- **比肩、劫财**——不能成格，另立专篇（比劫禄刃篇）；
- **偏财合于正财** → 统称「财」；
- **偏印合于正印** → 统称「印」；
- 剩下六：伤官、食神、正官、七杀、印、财。

**这个合并有实操后果**：断喜忌时，「财」不分偏正、「印」不分偏正，一律按同一套喜忌走。但**断六亲时必须分**（正财为妻、偏财为妾／父；正印为母、偏印为继母）——见 `07_六亲与女命.md`。

## 二、八神能力总表（一切的起点）

韦千里给每一种神都先定「能力」四个字。**这是全书最精炼的一层抽象：喜忌不是印象，是能力对上了局面的需要。**

| 神 | 能力（四项） |
|---|---|
| **伤官** | 泄身，生财，敌杀，**损官** |
| **食神** | 泄身，生财，制杀，**损官** |
| **正官** | **引财**，生印，拘身，制劫 |
| **七杀** | **耗财**，生印，攻身，制劫 |
| **印（偏正）** | 生身，**泄官杀**，御伤，挫食 |
| **财（偏正）** | 生官杀，**泄伤食**，制枭，坏印 |
| **比肩** | 帮身，任官杀，代泄，制财 |
| **劫财／禄／刃** | 同上（力更猛，见 `vol_bijieluren.md`） |

### 从能力表直接读出的六组对偶

这是本表最有价值的地方——**每一种能力都有它的反面**：

| 对偶 | 机制 | 断命意义 |
|---|---|---|
| 伤官**损官** ↔ 正官**拘身** | 官拘我，伤损官 | 伤官见官之战的根源 |
| 食神**制杀** ↔ 七杀**攻身** | 杀攻我，食制杀 | 食神制杀之所以贵 |
| 财**坏印** ↔ 印**御伤** | 印护我，财坏印 | 财印相战，须通关（官） |
| 财**生官杀** ↔ 印**泄官杀** | 财滋杀，印化杀 | 杀重身轻用印不用财 |
| 印**挫食** ↔ 食神**泄身** | 食吐秀，印夺食 | **枭神夺食**（最忌的一条） |
| 正官**引财** ↔ 七杀**耗财** | 官护财，杀耗财 | 财格见官则成，见杀则败 |

**「引财」与「耗财」这一对，是正官与七杀最本质的区别**，比「有制为偏官、无制为七杀」更根本。原书原文：

> 「正官能**引财拘身**，以存财也。」「七杀……以杀能**耗财**，并能助印也。」

## 三、八神逐条：利 → 弊 → 所喜 → 所忌

**读法（四步固定）**：

1. **利**：在什么局面下这项能力是好事
2. **弊**：在什么局面下这项能力是坏事
3. **所喜**：既见该神，喜见什么来配合
4. **所忌**：既见该神，忌见什么来破坏

注意第 3、4 步与第 1、2 步的**主语切换**：「日干强，爱伤官」→「既见伤，喜见财以流通之」。**喜忌是两层：先定该神本身是喜是忌，再定配合它的字是喜是忌。** 很多人只做第一层就下断语，这是最常见的漏洞。

### 3.1 伤官（泄身·生财·敌杀·损官）

| 项 | 日干强（爱伤官） | 日干弱（怕伤官） |
|---|---|---|
| **泄身** | 财官无气，强为患，喜伤官发越强气使尽行外露 | 一身自顾不暇，不堪再见耗盗 |
| **生财** | 身强财弱，伤官流通日干之气生起财来 | 财太旺，身不能任财，不堪再见生财 |
| **敌杀** | — | 杀重身轻，喜伤官敌杀存身，使一身得以自由 |
| **损官** | — | 官重身轻，喜伤官损官存身，使一身得以舒适 |

**所喜**

| 能力 | 局面 | 喜 |
|---|---|---|
| 泄身 | 日强 | 财以流通之 |
| 泄身 | 日弱 | **印绶以制伏之** |
| 生财 | 身强财弱 | 财多以生发之 |
| 生财 | 身弱财多 | 印绶以制之 |
| 敌杀 | 杀重身轻 | **比劫食伤以生助之** |
| 敌杀 | 身强杀浅 | **财以和解之** |
| 损官 | 官重身轻 | 比劫食神以生助之 |
| 损官 | 身强官弱 | 财以和解之 |

**所忌**

| 能力 | 局面 | 忌 |
|---|---|---|
| 泄身 | 日强 | 印以克去之 |
| 泄身 | 日弱 | 再生财，转辗泄弱 |
| 生财 | 身强财弱 | 印以克去之 |
| 生财 | 身弱财多 | 再生财，转辗泄弱 |
| 敌杀 | 杀重身轻 | **财旺生杀** |
| 敌杀 | 身强杀浅 | 比劫食伤以生助之 |
| 损官 | 官多身弱 | **财旺生官** |
| 损官 | 身重官轻 | 比劫食伤以生助之 |

> **规律**：「忌」几乎都是「所喜」的反面。唯一要死记的是第 6、8 行的**「以财和解」**——身强杀浅、身强官弱时，伤官打过头了，用财在伤官与官杀之间通关，而不是用印制伤官。**此处是最容易误用印的地方。**

**原书浅解（关于伤官的性格判词）**：

> 「伤官格大都好傲好慵，然亦必其人本能自治而大有才者，力克胜任；否则人无拘束，尽蔑法越规，恣意妄为，无恶不作矣。……故伤官者，必有大过人之才遇，而亦复有大惨酷之奇祸也。」

断伤官格之人，**才与祸并存**是标配，不能只断才气也不只断灾祸。

### 3.2 食神（泄身·生财·制杀·损官）

| 项 | 日强（爱食神） | 日弱（怕食神） |
|---|---|---|
| **泄身** | 财官无气，强顽为患，喜食神吐秀气 | 怕再生财，转辗泄弱 |
| **生财** | 身强财弱，喜食神吐秀生财 | 身弱财强，怕财多转辗泄弱 |
| **制杀** | 杀重身轻，喜食神制伏七杀，「一将当关，群邪自服」 | — |
| **损官** | （原书列「官强身弱，举动尽为束缚，亦爱食神」——食神**合官**存身） | — |

**所忌（原书只列忌，未分列喜，喜可从伤官类推）**

| 能力 | 局面 | 忌 |
|---|---|---|
| 泄身 | 日强 | **枭印夺去** |
| 泄身 | 日弱 | 再生财 |
| 生财 | 身强财弱 | **枭印夺去** |
| 生财 | 身弱财强 | 财多转辗泄弱 |
| 制杀 | 杀重身轻 | **财星党杀** |
| 制杀 | 身强杀浅 | 比劫食伤再助食 |
| 损官 | 官多身弱 | **财重泄食生官** |
| 损官 | 身重官轻 | 比劫食伤再助食 |

> ⚠️ **「枭神夺食」是全书反复强调的一条大忌**，也是食神与伤官的最大差别：伤官怕印克，但**伤官可以「以财和解」；食神遇枭，则是直接夺去**，无和解之路。所以：
>
> - **食神制杀**之局，最忌见偏印（枭）；
> - **食神生财**之局，同样最忌见枭。

**食神 vs 伤官的分辨（关键）**

| | 伤官 | 食神 |
|---|---|---|
| 制杀方式 | **敌杀**（硬碰） | **制杀**（温和） |
| 损官方式 | **损官**（克） | **损官**（合） |
| 原书例 | 丙火伤官制辛金正官（庚申 甲申 乙卯 丙戌） | 丙火食神**克合**辛金（辛酉 丙申 甲戌 丙寅） |
| 遇枭 | 可以财和解 | **夺去无救** |

原书食神「损官」例的判词：「丙火食神，克合辛金，使金势稍抑，日主稍扬，则损官即所以救主也。」——**食神合官，用的是「合」不是「克」**，所以后果比伤官见官轻。

### 3.3 正官（引财·生印·拘身·制劫）

原文：

> 「正官者，如一县之有邑宰。人民居其治下，方喜得有规范，不敢肆意妄为。」

| 项 | 判 |
|---|---|
| **利** | 日强而财弱：正官**引财拘身**以存财。日弱而赖印：官**生印**。劫比重重：官**制劫**。 |
| **弊** | 日弱而官旺：**拘身**太过，举动尽为束缚。 |
| **所喜** | 日强：财以生官（官为用则喜财）；日弱：印以化官、比劫以帮身 |
| **所忌** | **伤官损官**（见伤官而无印，为败格）；**杀来混杂**；**刑冲破害** |

**「引财」要专门说一句**：正官不是只管克身。日强财弱时，财无处安放，得正官「引」之，财才成用。**所以「身强财弱」的命，见官反是好事**——这一点常被忽略，因为直觉上「官克身」不像吉。

### 3.4 七杀（耗财·生印·攻身·制劫）

原文（最完整的一段浅解）：

> 「七杀者，又名偏官。二阳相克，二阴相克，犹二男不同处、二女不同居，不成配偶，故谓之偏官。又以其隔七位而相战克，故曰七杀。七杀者，惨覆无恩，专以攻身为尚。譬小人多凶暴，无忌惮，若无礼法制裁之，不惩不戒，必伤其主。**故有制，谓之偏官；无制，谓之七杀。** 必须制合生化，无太过不及，是借小人势力，卫护君子，以成威权，造就大富大贵之命者。」

| 项 | 判 |
|---|---|
| **利** | 身弱印轻财重：杀**耗财**并**助印**。杀重身轻有食制：杀被**制**而成权。杀攻身而有印：印**化**杀而生身。 |
| **弊** | 身弱杀重无制无化：**攻身**，其祸不胜俱述。 |
| **所喜** | 有制（食神）、有化（印）、有合（羊刃合杀） |
| **所忌** | 财旺**党杀**；制杀**太过** |

> ⚠️ **「制杀太过，尽法无民」** 是原书一句极重的话：
>
> 「若七杀祇一，制伏重重，倘运再行制伏，则**尽法无民**。虽猛如虎，亦无所施其技矣。」
>
> 意思是：杀只有一个，制它的字却有一堆，再走制杀的运，就是「法太严而无民可用」——命主反而无所凭依。**制杀太过与制杀不及同样是病。**

**「有制谓之偏官，无制谓之七杀」** —— 严格说这是命名之别，不是两个神。断命时写「七杀有制」即可，不必强分偏官七杀。

### 3.5 印（生身·泄官杀·御伤·挫食）

原文「偏正印杂谈」：

> 「印绶者，乃五行生我之名。乃我气之源，为生气，为父母，又能护我官星，使无伤克。具此格者，主聪明，多智慧，性慈惠，语善良，平生少病，亦且少逢凶横。若为官则必清廉，不拘文武，皆掌印信。」

| 项 | 判 |
|---|---|
| **利** | 日弱：**生身**。官杀重：**泄官杀**（化杀）。伤食重：**御伤**、**挫食**。 |
| **弊** | 日强：印重则身愈旺，为病。印重而财轻，日主反弱（《八格之太过》：「印重又得令，日弱而财轻」）。 |
| **所喜** | 日弱喜印；印重喜财（**但财根不可太深，否则印财互断而印败**） |
| **所忌** | **财坏印**；印重又多官杀 |

**三条要点**

1. **「泄官杀」——印是化杀的唯一正道**。日弱杀重，用印不用食伤。理由：食伤制杀，是硬碰，日弱撑不住；印化杀，把杀的力量转成生我的力量。**这是「杀重身轻宜化杀」的技术含义。**
2. **「御伤」「挫食」——印同时管伤官和食神**，但后果有别：御伤是好事（伤官克官需印制），挫食常常是坏事（枭神夺食）。**同一个「印」，对伤官是救星，对食神是杀手。**
3. **正印偏印之别在六亲不在喜忌**：六神篇把偏正印并为一神论喜忌，只清六亲。断母用正印、断继母用偏印，是 `07` 篇的事。

### 3.6 财（生官杀·泄伤食·制枭·坏印）

| 项 | 判 |
|---|---|
| **利** | 日强官杀轻：**生官杀**以成用。日强伤食重：**泄伤食**。日强不须印生：**制枭**。日强不劳印助：**坏印**，助财破印。 |
| **弊** | 日弱财重：财生官杀而克身；财泄伤食而分日干之力；**制枭则绝日干之生**；**坏印则绝其滋助**。 |
| **所喜** | 见下表 |
| **所忌** | 见下表 |

**财之所喜**

| 能力 | 日强 | 日弱 |
|---|---|---|
| 生官杀 | 有财生官杀，**喜官杀旺则成功** | 有财生官杀，**喜印生比劫以制之** |
| 泄伤食 | 伤食重，有财泄之，**喜财旺生发** | 伤食轻，有财泄之，**喜比劫以制财** |
| 制枭 | 不须枭生身，**喜财来制枭** | 有财制枭，**喜比劫以解之** |
| 坏印 | 不劳印助身，**喜伤食生财、助财破印** | 有财坏印，**喜比劫克去财星以存印** |

**财之所忌**

| 能力 | 日强 | 日弱 |
|---|---|---|
| 生官杀 | 幸有财生官杀，**忌伤食克官杀** | 有财去生官杀，**忌官杀再旺而克身** |
| 泄伤食 | 幸有财泄伤食，**忌比劫夺财** | 有财去泄伤食，**忌财旺分力** |
| 制枭 | 幸有偏财制枭，**忌比劫再夺财** | 有偏财制枭，**忌伤食生财** |
| 坏印 | 幸有正财坏印，**忌比劫再夺财** | 有正财坏印，**忌伤食生财** |

> **一句话记住「财」**：财是双刃——**日强时它是药，日弱时它是刀**。同一味药对日强是「生官杀成用」，对日弱是「生官杀克身」。原书这一整段，是全书「强弱决定喜忌」最集中的体现。

**「财坏印」的具体分寸**：印格「日干强、印又多见，财透出减弱印绶之力」——**但原书紧接着加括号**：「（但不可财根太深，与印互断而印败）」。见 `03_格局与用神.md`。

### 3.7 比肩 / 劫财 / 禄 / 刃

**构成**

| 名 | 定义 | 甲日为例 |
|---|---|---|
| **比肩** | 与我同类而**同性** | 甲、寅 |
| **劫财** | 与我同类而**异性** | 乙、卯 |
| **禄** | 我之本气 | 寅 |
| **刃** | **禄前一位**（阳顺阴逆，阴干以后作前，故亦即禄后一位） | 卯 |

> 原书按：「甲见寅，乙见卯，丙戊见巳，丁己见午，庚见申，辛见酉，壬见亥，癸见子，皆为禄。」
> 「甲见卯，乙见寅，丙戊见午，丁己见巳，庚见酉，辛见申，壬见子，癸见亥，皆为刃。」

⚠️ **阴干之刃在禄后一位**——乙禄在卯，刃在寅。这是最常错的一处，很多人只按「禄前一位」推，把乙刃算成辰。

**浅解**

> 「有谓在干为比、在支为禄，在干为劫、在支为刃。此理甚通，盖甲禄在寅，寅中有甲，木之比肩；乙禄在卯，卯中……」
>
> 即：**比与禄同类，劫与刃同类**，只是干支位置不同。故二者喜忌可通看。

**喜忌（`vol_bijieluren.md` 逐条列出，与本表口径一致）**

| 能力 | 喜 | 忌 |
|---|---|---|
| **帮身** | 日弱有比劫帮身，喜身旺生发 | 日弱幸有比劫，忌官杀来制；日强又见比劫，忌再印生身旺 |
| **任官杀** | 日弱有比劫敌官杀，喜身杀两相停；日强又有比劫敌官杀，喜财生官杀 | 日弱幸有比劫任官杀，忌**财旺助官杀**；日强又有比劫任官杀，忌再印旺生身而泄官杀 |
| **代泄** | 日弱伤食多，有比劫代受伤食之泄，喜**印制伤食而生身**；日强又有比劫代泄，喜财官两旺 | 日弱幸有比劫，忌**官杀将比劫克去**；日强又有比劫，忌**印来破食生身** |
| **制财** | 日弱有比劫制财，喜印生身；日强又有比劫制财，喜官杀制之 | 日弱财多愈弱，幸有比劫制财，忌**伤食生财**；日强财被比劫制去，忌再印旺生身 |

**⚠️ 刃的三条专诫**（原书比其他神多给的）

1. 「**羊刃重重喜食伤，若逢官杀变生殃**」——刃多喜食伤泄，见官杀则生祸。因为刃本身已是极旺之势，官杀来冲，是火上浇油。
2. 「**勿谓羊刃是凶物，财多杀党亦为贞**」——财多杀旺时，刃反而是能任财杀的正神。
3. «禄刃非在八格之内»——**禄刃不能取格**，遇到月令为禄为刃，走外格篇或本专篇。

## 四、喜忌判定五步法

拿到一个八字，第④步「论喜忌」按这个顺序走：

```
① 强弱定了没有？           → 未定不判喜忌（回 02_强弱判定.md）
② 用神是什么字？             → 未定不判喜忌（回 03_格局与用神.md）
③ 八神中哪几个字能助用神？
   → 查第三节「能力表」反推
④ 局中现成的字，是助还是伤？
   → 查第三节「所喜／所忌」两层
⑤ 助的字有没有被克合冲？伤的字有没有被制？
   → 回 04_补充篇精要.md 第四至九节
```

### 第③步的反查表

已知用神，反查「谁帮它」：

| 用神 | 能助它的字 | 能伤它的字 |
|---|---|---|
| **官** | 财（生官）、印（护官）、比劫（任官） | 伤官（损官）、杀（混杂）、刑冲 |
| **杀** | 财（生杀）、印（化杀）、食（制杀而过时需财解） | 食神（制杀太过）、劫刃（敌杀）、刑冲 |
| **财** | 伤食（生财）、官（引财）、比劫（任财而财多时） | 比劫（夺财）、印（不直接克财但印重则财轻） |
| **印** | 官杀（生印）、比劫（护印） | 财（坏印）、伤食（泄印而过时） |
| **食神** | 比劫（代泄）、财（流通）、印（护身） | **枭（夺食）**、财（制杀太过时） |
| **伤官** | 财（流通）、印（制之而日弱时）、比劫 | 印（日强时克去）、官（相战） |
| **比劫** | 印（生身）、同类 | 官杀（制之）、财（分力时则喜，夺财时则忌） |

## 五、全书最常引的八条喜忌谚（初学捷径摘）

见 `04_补充篇精要.md` 第十八节。此处只列与六神直接相关的：

| 谚 | 六神含义 |
|---|---|
| 用之官星不可伤，不用官星尽可伤 | 官为用则护，否则放任伤官 |
| 用之财官不可劫，不用财星尽可劫 | 同上，财为用则护 |
| 用之印绶不可坏，不用印绶尽可坏 | 同上，印为用则护 |
| 用之食神不可夺，不用食神尽可夺 | 同上，食为用则护枭 |
| **用之七杀不可制，制杀太过反为凶** | 杀为用则忌食神 |
| **身杀两停宜制杀，杀重身轻宜化杀，身强杀浅宜生杀** | 杀的三档用法 |
| **莫道枭神无用处，杀多食重最为良** | 枭能制食护杀，杀多食重时反为药 |
| **勿谓羊刃是凶物，财多杀党亦为贞** | 刃能任财杀 |

## 六、六神断性格速查（配 `04` 篇第十四节）

| 神旺而无制 | 性格判词 |
|---|---|
| 伤官 | 聪明干练、好傲好慵、才大而祸亦大；不受管束 |
| 食神 | 温和吐秀、有口福、不喜争 |
| 正官 | 守规范、有秩序感、拘谨 |
| 七杀 | 刚烈、攻击性强、能任大权亦能闯大祸 |
| 印 | 聪明多智慧、性慈惠、语善良、少病少凶横；印重则懒散依赖 |
| 财 | 务实、重实利；财重身弱则劳碌 |
| 比劫 | 独立、自我、朋友多；比肩太多乖僻寡合，劫财太多「敬这耽东」 |
| 羊刃 | 刚猛、不服输；羊刃重重见官杀则生殃 |

> ⚠️ 断性格必须标明「概率性描述」，且必须与 `04` 篇的「身强有抑／无抑、身弱有扶／无扶」二分合用。**单看一神断性格，命中率很低。**
