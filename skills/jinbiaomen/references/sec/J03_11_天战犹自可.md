# 天战犹自可

也是天战犹自可的意思
这个说的就是天战犹自可，我们总结天战犹自可，就是两点;
第一，透出天干的没有力量的即使相战了，也问题不大，然后按照作字取用完了，
定准用神，在看天干相战的那个五行是喜是鼠，忌就去了，是用神就留着。比如说作
字里身旺的同时透杀透了食伤了，杀没有根了，那么这时你肯定就得用食伤泄秀为用
了，那这个杀就没用了，虽然是食神制杀，但是杀太弱了。
第二，就是地支安静的，地支没有发生相战，所有的气都跑到天干上去了，在天
干完成治化了，那么天干气专易于治化，这种是说五行的气流转到了天干，完成治化
的，这种天干相战就比较容易治化了。所以也是天战狂自可。
简单说，一个是弱极了，我克制了它，没问题。另一个就是地支安静，气都流转
到天干完成治化的就有好，有不好，制住就好，制不住也不好。
