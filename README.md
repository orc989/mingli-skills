# mingli-skills · 八字命理知识库（十二体系）

古典命理典籍的结构化知识库。十二个 skill 包来自六份以上底本的原典整理，
共约 2700 个文件、2500+ 篇正文分节，总量约 14MB 纯文本。

> ⚠️ 本仓库仅含**典籍与方法论**，不含任何个人命盘、财务记录或他人信息。

---

## 目录结构

```
skills/<体系名>/          解包后的纯文本（可直接阅读 / diff / 检索）
  SKILL.md                该体系的入口说明与调用方式
  references/             正文分节，按卷/篇编号
packages/<体系名>.skill   原始 zip 包（可直接安装）
docs/                     体系地图、学习计划
```

`.skill` 文件本质是 zip，用 `unzip` 即可展开。仓库同时保留解包版和原始包：
解包版方便版本管理和全文检索，原始包方便直接装回使用环境。

## 使用要点

**别把十二个体系当十二个结论。** 它们对同一张盘经常给出相反判断，原因有三：
起旬口径不同（子平以年柱、盲派以日柱，导致空亡结论相反）、
体用不同（纳音系以年为主、子平系以日干为主）、
强弱标准不同（子平看旺衰、盲派看承载）。

引用时**必须注明依据哪一派**。跨派结论冲突时不要强行调和，先判断该问题归哪一派管辖。

## 底本可靠性

不同体系的质量参差，选底本时注意：

- `lantai` 用东里散人校本（赋文/释文分层，质量最高），另有西窗老人繁体本、了无居士本可对照
- `yuanhai-ziping`、`shenfeng-tongkao` 部分底本存在 OCR 残字，长句引用前建议回查原文
- 网盘同步时**不要相信文件大小字段**，判完整性只认 MD5
