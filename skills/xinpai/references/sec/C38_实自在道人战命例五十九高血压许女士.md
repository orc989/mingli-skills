# 实自在道人战命例五十九高血压许女士

自在道人实战命例五十九高血压许女士
阴历一九四六年六月十三阳历1946年7月11号
坤造：丙戌乙未丙戌戊戌〔午未]
[pic]

一、断旺衰，定格局，区分用忌神
月令未土空亡，日干丙火生在年支戌土月旺51%.时干戊土有力制日干为用神.月干乙木无
根无力反断为用神.年干丙火制月干乙木用神为忌神。
二命局分析：
1日干丙火身旺.越减力越好。
2.虽然时干戊土使日干丙火减力.但是日干丙火本身就是最大忌神
3.丙火对日干没有起好作用.血压不正常
4.日干丙火不需要热能.热量生扶.命局里的组合热能.热量就在日干出现.是日干自己增
加了热能热量.本人高血压
5.日干不需要热能.热量生扶.命局里的组合热能.热量生扶了日干.本人高血压
6.本人是老三.年干是大姐.也是高血压
总结.丙火代表心脑血管.循环主动脉血管.热能.热量.对日干没有起好作用时血压不正常
。
大姐看年干丙火，是忌神是高血压。二姐在时干看，二姐不是高血压。
首先要看日干是老几。再确定其他比肩的排行，与日干相邻的比肩是他(她)上下紧挨的
弟兄或姐妹。
佛学因果
1前生在自家孝敬父母，在社会能尊敬老人长辈，今生得到父母关心爱护，得父母地产财
富福报。
2前生在自家关心爱护兄弟姐妹，和谐邻里同龄男女，友好社会同事同学，今生兄弟姐妹
朋友关心爱护，得兄弟姐妹朋友财物福报。
3前生并非困难，编造谎言，骗取国家低保待遇，享受国家困难补助之人，今生无正式工
作，一生贫穷。
4.前生利用权力工作之便利，贪污自利，读职怠工，给国家经济带来损失之人，今生无
工作，一生贫穷
5前生以假充好，以劣当真销售产品物资，并从中获得暴利，鱼肉众生，今生常被别人骗
财，倾家荡产，一生贫穷。
6前生对配偶关心疼爱，礼让有情，最困难时，把配偶利益看做比自己生命还重，今生得
配偶关心疼爱，男命得贤良之妻，女命得优秀之夫。
