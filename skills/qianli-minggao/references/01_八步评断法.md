# 八步评断法（本书的核心操作流程）

> 出处：`vol_pingduan.md`（评断篇，PDF 071—074）。
> 这是《千里命稿》最有价值的部分——全书近千条零散规则，最后收束为**八个固定步骤**。韦千里的原话：

> 「每一命局，或五行错综，或六神纷杂，评断而无规定程序，极难入手。兹议为八步如后。」

---

## 0. 八步全图

```
①看强弱 → ②定格局 → ③取用神 → ④论喜忌 → ⑤查岁运 → ⑥推六亲 → ⑦评性情 → ⑧断事业
```

| 步 | 做什么 | 判准 | 本技能对应文件 |
|---|---|---|---|
| ① 看强弱 | 定日干是强是弱、强到什么程度 | 以**多寡、盛衰、失时、得令**为标准 | `02_强弱判定.md` |
| ② 定格局 | 定为八格中哪一格，或外格 | 以**月支**为标准（外格不在此例） | `03_格局与用神.md` |
| ③ 取用神 | 找出那个「一字」 | 以**助强扶弱**为标准 | `03_格局与用神.md` |
| ④ 论喜忌 | 定哪些字喜、哪些字忌 | 以**用神**为标准 | `05_六神喜忌速查.md` |
| ⑤ 查岁运 | 逐运逐年断 | 以**喜忌**为标准 | `06_岁运断法.md` |
| ⑥ 推六亲 | 父母妻子兄弟 | 以**四柱六神**为标准 | `07_六亲与女命.md` |
| ⑦ 评性情 | 性情八类 | 以**五行用神**为标准 | `04_补充篇精要.md`、`05_六神喜忌速查.md` |
| ⑧ 断事业 | 宜何业、宜何方 | 以**用神及喜忌**为标准 | `05_六神喜忌速查.md`「事业」条 |

**顺序不可颠倒。** 前三步错了，后五步全废。韦千里自己在举例中，凡前三步判得稳的，后五步都短；前三步有争议的（如许世英造「从杀还是身弱用印」），后五步也都在打补丁。

---

## 1. 评断举例：四则完整示范

`vol_pingduan.md` 给了四个完整的八步示范。这四则是**全书唯一提供标准答案的地方**，用法是：先自己判一遍，再对照。四则的格式统一为「强弱 / 格局 / 用神 / 喜忌 / 岁运 / 六亲 / 性情 / 事业」。

### 例一 陆姓乾命（PDF 072）

| 步 | 原文 | 要点 |
|---|---|---|
| 强弱 | 「丙死于冬。亥子癸三水，既得其令，又競来克。未戌己土虽能制水，乃本身先泄丙火之气，只月上甲木生丙。综计全局，抑者太多，扶者太少，故丙干以弱论」 | **不是数数量，是数「有效的抑制」与「有效的扶助」**。未戌己土虽能制水，但土本身泄火，所以不算扶助 |
| 格局 | 「丙生子月，干透癸水，为正官之格」 | 月令本气透干即取 |
| 用神 | 「丙既云弱，必须生扶。月上甲木泄水之有余，生火之不足，取用无疑，即谓官格用印是也」 | 用神一个字：**既泄水又生火**——同时做两件事 |
| 喜忌 | 「自喜木火助用助身，不畏土之泄火，水之克水，盖土有木制，水有木当也，然亦非所喜耳。最忌金为生水助虐，克木则伤用」 | 喜 = 助用 ＋ 助身；忌 = **生忌神 ＋ 伤用神**（金同时做这两件事） |
| 岁运 | 一岁癸亥「一派水乡，稚年多病」；十一壬戌「水土各半，亦乏善可陈」；**廿一辛酉「甲辰年随某巨公至广东，充记室四载」**——原文理由：「正逢木火流年也」 | **大运凶而流年吉，照样能发**。这是全书最重要的方法论：运是背景，年是开关 |
| 六亲 | 「偏印为用，父母庇荫尚丰；劫财无力，弱弟早夭；日支藏财，然非喜神，妻乃中道云也」 | 六亲断法 = **把六亲星拿来与用神比**。是用神则得力，非用神则不得力 |
| 性情 | 「火日水多，所为欠当，宗旨少决」 | 火日水多 → 见 `04_补充篇精要.md` 性情八类 |
| 事业 | 「官格用印，自以近贵求名之为宜，尤利于东南半壁」 | 用神为木 → 东方；官格用印 → 近贵求名 |

> **这一则示范了一个易被忽略的点**：`日支藏财，然非喜神，妻乃中道云也`。妻星（财）本身不弱，但它**不是喜神**，所以断「中道」（中途离散）。六亲不断「星之有无」，断「星与用神的关系」。

### 例二 潘姓坤命（PDF 072—073）

| 步 | 原文要点 |
|---|---|
| 强弱 | 「庚生季冬为寒金，水旺泄气系忧患。尤病丑土会亥子而化水。且寒金喜火又苦丁火之被克，是诚弱不堪言矣」——**丑土本可生金，但会亥子而化水，反而助泄**。这就是「帮扶反成累」 |
| 格局 | 「庚生丑月。透癸为伤官之格」 |
| 用神 | 「水势泛滥，若用丑中己土，非但不能制水，且激水之怒，不如亥中甲木以为用。赖甲泄水之有余、生火之不足，所谓财能救官是也」——**用土则激水之怒，改用木则泄水生火** |
| 喜忌 | 「最喜为火、土、木，最忌为金水」 |
| 岁运 | 「五岁交足壬子水运，十病九危……及庚午年，怙恃之失相继频乘。壬申岁身世之悲层见叠出……三十三岁甲申流年，用神（甲）得助，当获快婿……四十五岁戊申运，以戊字最佳。五十岁后，岁运皆金水，恐难免赋归于心脏病」 |
| 六亲 | 「金寒水盛则无子。官星无力易克夫」 |
| 性情·事业 | 原书未列（坤命以夫子为重） |

> 注意「三十三岁甲申流年，**用神得助**，当获快婿」——同样是大运申（金，忌神）而流年甲（用神）透出，吉。与例一的「辛酉运甲辰年」完全同一逻辑。

### 例三 王姓坤命（PDF 073）

| 步 | 原文要点 |
|---|---|
| 强弱 | 「甲生酉月而失其令，又多火土，则金之克泄，本当以弱论。然长生于亥，胎于酉，得禄于寅，地支有气，尚非至弱者也」——**失令但四支得气，降为「非至弱」** |
| 格局 | 「甲生酉月，为正官之格」 |
| 用神 | 「官印财食俱全，惟己年癸月，地位接近，财印相克，为美中不足，故取酉（辛金正官）以为用。盖财生官，官生印，五行六神，因此不悖矣」——用神取「能把全局串起来」的那一个字 |
| 喜忌 | 「命中五行不悖，固无所谓喜忌。惟坤以夫星为重，又取正官为格、为用，则不宜逢多量之火也」——**五行不悖时，喜忌从「身份权重」定**（坤命重夫星） |
| 岁运 | 「二十岁戊辰流年，偏财帮夫，于归极利。廿三岁丙子运，丙为食神、子为正印，迭获弄璋之庆……三十三岁行丁火伤官运，幸有印以制之，然辛未年夫病越七月，亦云险矣」 |
| 六亲 | 「印有官生，父母双庆；正官为格为用，夫既荣显；时下一比，令弟亦云克家；时上食神吐秀，子更英奇特达」——**四亲全吉，因为四亲星全在「不悖」的格局里** |

### 例四 詹姓乾命（PDF 073—074）

| 步 | 原文要点 |
|---|---|
| 强弱 | 「甲生暮春土令，又见三土二金，财杀太旺。幸子辰成产水之局，辰土之财化印生身，故专弱为强矣」——**辰土本为财，但因会子辰水局而化印**。同一个字，位置不同则身份不同 |
| 格局 | 「甲生辰月，干透戊土，是为偏财之格」 |
| 用神 | 「干头尽是财杀，自取年支子印为用，赖以化杀生身也」 |
| 喜忌 | 「最喜水木而忌土，火亦不利，因能生土也。金却不忌，因能生水也」——**忌神所生者为忌，忌神所生之反为喜** |
| 岁运 | 「六岁行辛巳运，一金一火，乏善可陈。十六岁之壬运，大病三年」 |
| 性情·事业 | 「火有水济，能刚能柔。见解必清楚，处事多得当」「命本可富，自宜置身金融界。若趋北地，尤称佳妙」 |

## 2. 从四则中提炼的五条通则

| 序号 | 通则 | 依据 |
|---|---|---|
| **通一** | **强弱不看数量，看「有效与否」**。土能制水但土本身泄火 → 不算扶助；辰土是财但会水局化印 → 反而助身 | 例一、例四 |
| **通二** | **用神是「一个字做两件事」**。甲木既泄水之有余、又生火之不足；甲木既泄水又生火救官 | 例一、例二 |
| **通三** | **五行不悖时，喜忌改由「身份权重」定**。坤命重夫星，故虽不悖仍忌多火 | 例三 |
| **通四** | **运凶年吉，照样发**；运吉年凶，照样败。运是十年背景，流年是当年开关 | 例一（辛酉运甲辰年）、例二（甲申年得婿） |
| **通五** | **六亲断「星与用神的关系」，不断「星之有无」**。财非喜神 → 妻中道；官为格局用神 → 夫荣显 | 例一、例三 |

## 3. 评断的姿态：韦千里的三条自述

这三句散在 `vol_yingyun.md` 里，价值不亚于八步本身：

> 「**论偏枯之命局易，推中和之命局难。**」
> ——镇江孙君例（PDF 083）

> 「**论命者，论休咎而已。断生决死，有验有不验。**盖生寄死归，有梦必醒。」
> ——某造例（PDF 085）

> 「**富贵人未必皆富贵命，或行运辅之以成也。反之贫贱人亦然。**」
> ——哈同例（PDF 077）

对应到输出规范：

- 遇中和之命，**不要硬找病**，如实说「五行不悖，喜忌不显」，只在大运上找偏枯点。
- **不决生死**。判出凶运，说「此运宜守、宜退、宜改途」，不说「必死」「必亡」。原书自己说「有验有不验」。
- **命与运分开说**。命好而运不辅，说不成；命平庸而运辅之成，照样断贵。

## 4. 与原书体例相配的输出格式

原书每一则命例的批语都极短（多则二三百字），且**格式固定：先一句定性，再逐运说，最后一句归总**。照此格式输出，最贴近本书风味。

```
【定性】一句话说清强弱、格局、用神三者（不超过 40 字）
【喜忌】一句「最喜 X，最忌 Y」
【岁运】逐运说，每运一句，标明该运是助用神还是伤用神
【六亲】只断与用神有关的，其余不断
【性情·事业】各一句
```

**反面示范**（不要这样写）：把八步当清单逐项填空、每项写三段。原书没有这种写法。
