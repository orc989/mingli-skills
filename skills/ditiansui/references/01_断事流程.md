# 断事流程（把六本书压成一条可执行的路径）

滴天髓的原文是诗诀，不能不拆直接照搬。下面是六份资料共同支持、且能落成步骤的流程。每一步都注明依据来自哪一层。

## 第 0 步：先定「问什么」

滴天髓分两大块：**通神论 34 章**（论气、论格局、论成败）与**六亲论 28 章**（夫妻、子女、父母、兄弟、性情、疾病、出身、地位、岁运）。

不可跳过的一步：确认问题是「这个命局层次如何」还是「某事何时发生」。

- 层次问题（能不能成大事、格局高低）→ 走 A 线
- 时间问题（哪年结婚、哪年发病）→ 走 B 线，且必须先声明「命例无流年，以下为外推」

## A 线：定层次

1. **看季节**（月令）→ 得日主旺衰基调。依据：`chanwei_月令.md`、`chanwei_衰旺.md`
2. **看通根与天覆地载** → 「干以载之支为切，支以覆之干为切」。依据：`chanwei_天干.md`、`chanwei_干支总论.md`
3. **判身强身弱** → 只在「身旺取克耗泄、身弱取生扶」两条主干上落锤，特殊格局另论。依据：金镖门第一、二课
4. **定用神** → 身旺先看官杀，再看食伤，再看财；身弱先看印，再看比劫。有官杀先论官杀。
5. **检查用神被什么坏** → 合、冲、拱、拌、晦、盖头、截脚。依据：`chanwei_通关.md`、`chanwei_源流.md`，添情全套命例的检查清单
6. **判层次** → 「天地顺遂而精粹者昌，阴阳乖悖而混乱者亡」。用神有力且不被坏＝层次高；用神无力或被坏＝层次低。

## B 线：定事项

1. **先定用神（同 A 线 1-4）**，因为六亲的吉凶由用神推出，不由十神直接推出。
2. **定位六亲星**
   - 男命：妻＝财星（财是情缘线）；子女＝官杀（金镖门）或食伤（任注，须标明取法）
   - 女命：夫＝先看官杀，官杀无力取财为夫，官杀过旺化印则以印为夫；子女＝食伤
   - 父母＝印（任注改定），兄弟＝比劫
3. **看星与宫的呼应** → 星（六亲星）在柱中的位置，是否坐忌神，是否被冲合。典型判语：「夫妻宫坐忌神，星又是忌神，凶」。
4. **看引动** → 大运或流年是否引动原局的关键组合（拱、合、冲）。添情常用判语：「辛丑大运引动原局巳酉丑拱金用神，吉」。
5. **落到事项** → 婚姻看财星/官杀是否受生受坏；子女看子女星是否得气、是否被克绝；疾病看忌神克身与用神受伤；地位看出身与官星配合。

## 三条硬约束（六份资料里反复出现，最容易被忽略）

**约束 1：六亲「死」的定义是念头被克绝，不是星弱**

金镖门原话：「对于这个六亲的死亡，并非是六亲星弱被克没了就死了……得把六亲星的念头克死了，才死的。」

即：六亲星弱时若有生扶（如弱官杀有财生），只是该六亲地位低、能力差，不是死亡或不出现。只有当那个生扶源被彻底去掉（财被合去、被化去），才论绝。

**约束 2：不能只看神煞与刑冲**

梁湘润专设「否定：神煞」「否定：墓库冲发、三刑」两节。任注亦不重神煞。做判断时，刑冲合害只是「作用关系」的一种，不是独立吉凶信号。

**约束 3：命例无流年，流年断必须标外推**

添情原文：「由于本书中的命例很难知道流年如何，只能根据限运看。」任何跨越到大运以下的判断都要说明这是外推，不能让读者误以为是书里给的结论。

## 常见错误的对照表

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 看到财星就当妻子好 | 财星若无用、被劫，反而克妻 | 先定用神，再看财星是对用神起好作用还是坏作用 |
| 女命见伤官就断「福不真」 | 金镖门明确反驳：有的犯伤官反而是好事 | 看伤官是克了夫星，还是泄了身旺之秀 |
| 劫财见财就断离婚 | 财得局身弱时，比劫来帮身反而婚姻好 | 看财轻劫重还是财旺身弱，再看有无官星护财 |
| 用神受伤就直接断死亡 | 星弱不等于绝 | 看生扶源是否被彻底去掉 |
| 直接拿任注命例推流年 | 命例只有大运 | 显式声明外推 |
