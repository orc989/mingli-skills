# 版本源流与分歧

> 穷通宝鉴不是一本书，是**一条六百年的改书链**。同一条「正月甲木」的口诀，
> 在不同版本里字句可能相差十几个字，而用神次序往往就藏在这十几个字里。

## 二、韦千里序透露的底本状况（关键）

1957 年丙午，韦千里在台北作序，自述此书的流传经过，是判断底本可靠性的第一手材料：

> 顾以出于术者之手，义精理奥，词不达意；名转传抄，鲁鱼亥豕，不可卒读，沉沦几五百年，不为世重。

> 于评《宝鉴》时，病其书未能尽解其义，遍求善本不可得，虑其有误而不敢擅易。
> 半由友人之介，于旧书肆中购得真州吴氏有福读书堂珍藏精抄本，两相比对，相互校正。
> 一字出入，义理迥殊。

> 所列命造，亦多数合，则为有清官所增附者也。

**三个可直接引用的结论**：

1. **底本有大量形近字讹误**——「鲁鱼亥豕，不可卒读」是作者自述，不是后人推测。
2. **底本有夺文**——徐乐吾「虑其有误而不敢擅易」，说明他也拿不准。
3. **命例是清代官署增附的**——不是余春台原编，所以命例的断语与正文口诀并非同一作者，口气也不同。

## 三、五处主要分歧

### 分歧 1：「正月甲木」的正用是丙癸还是庚丁

| 版本/层次 | 说法 |
|---|---|
| 底本原文（初春段） | 「正月甲木，初春尚有余寒，得丙癸透，富贵双全，癸藏丙透，名寒木向阳」 |
| 底本原文（仲春段） | 「正二月甲木一例，木乘旺气，无金必殃，先看庚、次取丁」 |
| 徐乐吾评注 | 「初春气寒，以丙癸为上命；春深木老，以庚戊为上命」——即**承认正月内部要再分两段** |
| 白话本（方先生） | 「正月甲木以水火既济为正轨，余皆变局」 |

**分歧点**：正月到底算「初春」还是「仲春」？
底本的编排把两段都塞在「正二月甲木一例」这个标题下，导致：
- 若按农历正月 = 初春 → 用丙癸
- 若按「雨水后」 = 仲春 → 用庚丁

**本技能的处理**：以**雨水**为界。雨水前用丙癸，雨水后用庚丁。
依据是底本自己写的「以上初春，专指雨水前而言」与「正二月甲木者，言雨水之后，清明之前，看法相同也」。

### 分歧 2：「三秋丁火」的甲庚丙次序

| 版本/层次 | 说法 |
|---|---|
| 底本标题 | 「三秋丁火一例」——七八九三个月共用一节 |
| 底本正文 | 「三秋丁火，阴柔退气，专用甲木……仍取庚劈甲，为引火之物，又借丙暖金晒甲」 |
| 底本续文 | 「三秋甲庚丙并用，仍分优劣……七月甲丙，申中有庚；八月甲丙庚皆用；九月专用甲庚」 |

**分歧点**：三秋到底是「甲庚丙并用」还是「逐月不同」？
底本前后两段自相矛盾：前段说并用，后段说分优劣。

**本技能的处理**：按后段（更具体）为准——七月甲丙为主（申中自有庚），
八月甲丙庚皆用，九月专用甲庚。这一处理与徐注「七月甲丙，八月甲丙庚，九月甲庚」一致。

### 分歧 3：「五月丁火」到底用不用甲

| 版本/层次 | 说法 |
|---|---|
| 底本原文 | 「五月丁火时逢建禄，不得轻用甲木，遇干透隔位之壬，不贪丁膈，忠而且孝」 |
| 徐乐吾评注 | 「丁火不离甲木，因其本性衰竭也，生於五月，火旺秉令，不[得]轻用甲木」 |
| 底本末段 | 「五月丁火，以用壬癸为正轨，壬癸太旺用甲木，乃例外也」 |

**分歧点**：丁火本性离不开甲，但五月火旺，甲木反助火。
**本技能的处理**：五月丁火首选壬癸，甲木只在「壬癸太旺」时作救应用。
这是全书少数明确说「例外」的地方，不可反推。

### 分歧 4：「三冬己土」可用癸吗

| 版本/层次 | 说法 |
|---|---|
| 底本原文 | 「三冬己土，湿泥寒冻，非丙暖不生，取丙为尊，甲木能参用，**不可用癸**」 |
| 徐乐吾评注 | 「癸水为十一月当旺之神，然三冬己土，以寒冻为病，癸出则愈寒愈冻，故以为忌，除非四柱火土旺极，借用癸水，然此特别之命，极罕遇之」 |
| 白话本编排 | 十月「丙甲戊」、十一月「丙戊甲」、十二月「丙戊甲」，均不含癸 |

**分歧点**：严格禁癸，还是「火土旺极时可借用」。
**本技能的处理**：列为**硬忌**，同时保留徐注的例外条款。实际操作中若见火土旺极而用癸，
须明说是「徐注例外」，不可说是原书正法。

### 分歧 5：戊土与己土在「四季月」（辰戌丑未）的归属

| 版本/层次 | 说法 |
|---|---|
| 底本 | 三月戊土单列，六月戊土单列，九月戊土单列，十二月戊土并入「十一、二月戊土总论」 |
| 底本 | 三月己土单列，六月己土单列，九月己土并入「三秋己土总论」，十二月己土并入「十月十一月十二月己土总论」 |

**分歧点**：四季月土旺，究竟该按「土旺用甲疏」还是按「月令气候」取用？
底本的处理是**气候优先**：三月戊土用甲丙癸（因春木旺、土受克），
九月戊土先甲后癸（因秋金泄土、土燥），十二月戊土用丙甲（因严寒）。

**本技能的处理**：一律气候优先。这是穷通宝鉴区别于《子平真诠》「月令用神」体系的根本处。

## 四、底本的结构性缺陷（使用前必读）

1. **合并标题**——底本有 7 处用合并标题统摄多个月份，导致部分格位没有独立标题：
   - 「正二月甲木一例」（正月、二月）
   - 「五六月甲木一例」（五月、六月）
   - 「三秋丁火一例」（七月、八月、九月）
   - 「三冬丁火」（十月、十一月、十二月共用一节，其后才分列「十月丁火」「十一月丁火」「十二月丁火」，而这三节只有命例、没有口诀）
   - 「正二三月戊土一例」（正月、二月、三月）
   - 「十一、二月戊土总论」（十一月、十二月）
   - 「十月十一月十二月己土总论」（十月、十一月、十二月）
   - 「三秋己土总论」（七月、八月、九月）

   后果：**这 20 余格的「口诀」实际上只有总论一句**，逐月的差别藏在总论的行文里，
   不能指望像其他格那样有一句独立口诀。

2. **标题行与正文粘连**——部分标题行带缩进（如 `                                  二月丙火`），
   部分标题行下方紧接口诀而无空行，机器切分极易错位。

3. **命例段落与正文交错**——命例通常以「四柱。生时。命主名：断语」四行一组出现，
   但生时行常缺失（1029 条中仅 524 条有生时），且部分命例只有批语无名。

4. **「按」字段归属不明**——底本用「按」引出评注，但未标明是徐乐吾还是整理者所加。
   徐乐吾在序中自称「述而不作」，而底本的「按」有明显发挥（如「此造疑为己巳时」），
   应属评注层而非原文。

## 五、引用规范

| 场合 | 建议写法 |
|---|---|
| 引用口诀 | 「《穷通宝鉴》正月甲木：『初春尚有余寒，得丙癸透，富贵双全』」——不加版本注 |
| 引用评注 | 「徐乐吾注：『初春气寒，以丙癸为上命；春深木老，以庚戊为上命』」——**必须标「徐注」** |
| 引用白话本 | 「白话评注本（方先生）：……」——**不可写作「穷通宝鉴云」** |
| 引用命例 | 「陈济棠造（庚寅 戊寅 甲子 丙寅）」——四柱可引，断语须标「底本按语」 |
| 存疑处 | 依 `06_校勘须知.md` 标注，不可默默改字 |
