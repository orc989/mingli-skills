# 千里命稿（韦千里）

> 底本：《千里命稿》，韦千里著，民国乙亥（1935）夏成书于上海，原名《命学讲义》，系韦氏命学函授讲义结集。
> 本技能文本据 **96 页 PDF 文字层**抽取（`pdftotext -layout`，121,826 字），同批 .doc 版仅 59,006 字，质量远逊，仅作参照。

---

## 这是什么

这是民国上海命学家韦千里（1911—1988）的代表作，**子平法的教科书式整理**。它的特点不是秘传，而是**流程化**：

- 全书唯一给出**标准作业流程**的命书——**评断八步**；
- 每一格、每一神、每一天干、每一地支都按「**构成 → 浅解 → 能力 → 利弊 → 喜忌 → 命例**」的固定体例写；
- **103 则民国实批命例**（应运篇），每则都有四柱与完整批语，可对照验证；
- 对旧说有多处**明确的否定**（下面第二节），不是照抄古籍。

**它不是**：神煞全书、盲派口诀、紫微斗数、择日合婚。本技能只做子平四柱。

## 三条硬纪律（违反即误用）

### 纪律一：先定强弱，再定格局，才有用神

八步不可跳步、不可倒序。常见错法是先喊格局名，再凑用神。

> 「日主有强，有弱，格局有成，有败，有太过，有不及。今有一字，能助格局之成功，救格局之破败，抑格局之太过，扶格局之不及……此字即用神也。」——格局篇

**并且用神必须落到具体的字**（甲乙丙丁），不是「宜用财」这种抽象结论。

### 纪律二：用神未定，不碰六亲、不评性情、不断事业

六亲、性情、事业都是**用神的函数**。用神没定就断六亲，是拿空气当尺子。

> 女命篇的二十七条取用法，每一条都在推「用神」，只是多了一层夫子星的权衡。

### 纪律三：不断生死、不断贫富贵贱等级、不预断疾病官非

原书偶有「不死必贫」「必成灾祸」「必克夫」「无子」「夭」这类极值表述，那是**民国命书的语气**，且多数出现在极端配置下。

**本技能一律改写为方向性、行为性、可改进的描述。** 完整改写对照表见 `references/07_六亲与女命.md` 第九节。

**另加一条**：六亲与性情断语必须标明「**此为概率性描述**」。原书自己就说：「可以意会，难能言传者，乃贵乎活看，而不可拘泥也。」

## 五条方法论标记（千里命稿区别于其他命书的地方）

这五条是本技能的识别特征，也是和其他命理技能（滴天髓、兰台妙选、命理探源）分工的界线。

### ① 八步评断法 —— 全书唯一的标准化流程

```
看强弱 → 定格局 → 取用神 → 论喜忌 → 查岁运 → 推六亲 → 评性情 → 断事业
```

前五步是技术，后三步是落地。**每一步都有明确的判准与输出格式**，见 `references/01_八步评断法.md`。

### ② 六亲之更定 —— 子女改按「我生」论，男女同

> 「旧论父子殊多谬误，特更定六亲看法如后。……（六）子：**男女命，皆以我生之伤官食神为子。**」——六亲篇

旧论男命以官杀为子、女命以食伤为子；韦千里一律改为食伤。同时**父改为印**（旧论偏财为父）。

**这是全书方法论最一致的一处**：六亲取法依据「生克关系的实质」，不依据「社会角色的比喻」。

### ③ 行运七三折衷法 —— 明确反对「干管五年、支管五年」

> 「今人以一干一支各为一运，一运管五年……管见谓**折衷办法**最为精当。即如甲午运：**前五年注重甲字兼看午字，甲占七分、午占三分；后五年注重午字兼看甲字，午居七分、甲居三分。**」——运限篇

古法干支合管十年，今法干支各管五年，韦千里取折衷。**断大运必须切前后两段说，不能笼统断十年。**

### ④ 否定「十干比喻」

> 「命家作为歌赋，比喻失伦。如称甲为栋梁、乙为萝藤、丙为太阳……**不可信也**。」——补充篇

代之以「气／质」二分与物性推导（甲为木之生气、乙为木之形质 → 甲以庚为杀、乙以辛为杀）。**这是十神可推导、不必死背的理据。**

### ⑤ 「贱」字辨义

> 「贱者，思想龌龊、操行卑鄙之谓也，**非阶级低下之称也**。上级人未必无贱，下级人未必皆贱。」——贫贱凶夭篇

即：所谓「贱」指**无所依托、不能自立**，与出身阶层无关。


用法：

1. **找同类**：按身份（政界／军界／商界／文艺／女命／早夭）或按批语结构，找结构相似的命例；

## 快速上手

用户给了完整八字，直接按这个模板走：

```
【排盘确认】年柱／月柱／日柱／时柱；性别；出生地与时区校正
【一、强弱】得令？得地？得势？→ 判为某档（强三档／中和／弱三档）
【二、格局】月令为何？本气透否？→ 取某格（附取格依据第几条）
【三、用神】某格＋日干强弱＋局中之病 → 取某字为用
      验收七条：①势 ②援 ③干得气 ④无克合 ⑤支得干助 ⑥无刑冲 ⑦有救
      → 健全／有相神／用神受伤无救
【四、喜忌】喜某神（因某能力）／忌某神（因某能力）
【五、岁运】当前大运某（前五年7:3／后五年3:7）；本流年与运的关系（十二则之第几条）
【六、六亲】（须时辰已确认）分星／宫／用三项写
【七、性情】有抑无抑／有扶无扶 → 三条以内，标「概率性描述」
【八、事业】五行需＋格局特征＋能否自立＋稳定性
```

**每一步都要写出判准，不能只给结论。** 韦千里的批语之所以可信，就是因为他每条断语都带着因果链。
