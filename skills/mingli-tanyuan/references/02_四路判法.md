# 命理探源的四路判法

> 本文件把《命理探源》散在八卷里的操作规则**重排成可执行的判断顺序**，不是原书结构。
> 原文以 `vol_*.md` 为准；本文件只做提炼，凡标「袁按」者为袁树珊本人按语，标「沈按」者为沈孝瞻（《子平真诠》），标「陈按」者为陈素庵。

---

## 0. 为什么这本书值得单独做一个技能

民国命书大多「只抄口诀不给理由」。此书的特出之处有三条：

| 特征 | 表现 | 对使用者的意义 |
|---|---|---|
| **校时优先** | 卷五专设「论时刻及夜子时与子时正不同」等六节 | 见一个盘先问：时辰准不准？不准则后面全废 |
| **命与运分判** | 卷五「论运岁」明说命局是体、岁运是用 | 断语必须标注「原局 / 大运 / 流年」的层级，不可混说 |
| **对俗说正面开火** | 卷三驳小限十二月神煞、卷五驳犯太岁、卷六驳星煞关格 | 引用神煞必须过筛，不能照搬《三命通会》 |

同时它也有明显的**时代局限**（第三部分详列），用之前必须知道。

## 1. 四路判法总图

```
        ① 校时路（卷五·22—27）           —— 先把「盘」确定下来
                 ↓
        ② 旺衰路（卷三·1—3）             —— 定日主强弱，先判季令再判党众
                 ↓
        ③ 格局路（卷四·16—33 + 卷六赋论） —— 定用神：成败救应 → 高低 → 先后
                 ↓
        ④ 岁运路（卷五·4—15）            —— 命局为体，岁运为用，逐层叠加
                 ↓
        ⑤ 表述路（卷八·星家十要）        —— 说什么、不说什么、怎么说
```

**顺序不可颠倒**。原书卷次正是按这个顺序排的：卷一基础 → 卷二排盘 → 卷三强弱 → 卷四宜忌与用神 → 卷五岁运 → 卷六古论 → 卷七实例 → 卷八伦理。

## 2. 第①路 校时：盘不准，断语全废

**入口**：卷五 22—27（PDF 150—154）

| 事项 | 原书立场 | 实操 |
|---|---|---|
| 夜子时归属 | 前四刻属昨日、后四刻属今日（`vol_suiyun.md` PDF 150—151） | 23:00—24:00 出生者必须两盘并推 |
| 百刻制 | 万育吾「初四/正四」、顾炎武「初初/正初」，实同名异 | 换算成 1440 分钟再定时辰，不要用「几点几刻」口传 |
| 真太阳时 | 卷五 23—27 给「定寅时法、定日出日没时法、看日定时法」 | 无经度校正时，跨时区出生者须重定时柱 |
| 时柱分刻 | 卷四「论生时法之二」：寅时一二刻丙火用事、三四刻戊土、后四刻甲木 | 时辰卡在交界者，按时柱分刻取用神，不硬取一柱 |

> **袁按立场**：他明确说「月支尚没有分日用事的道理，时柱却可以分刻」（PDF 118—119）。即：**月令只取本气与透干，不按日切分；时柱反而可分刻**。

## 3. 第②路 旺衰：三个来源，只认两个

原书卷三给了三套独立标尺，袁树珊的取舍很干脆：

### 3.1 天干生旺死绝（卷三·1，PDF 62—67）
十二宫（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养）逐干定局，附五阳干/五阴干两张表。

**书内争议点**：水土是否同生于申。原文倾向「水土同宫」，并引「申为坤、坤为地，水土凝合构成」为据。→ **本技能取水土同宫**，但注明这是选择而非定论。

### 3.2 五行用事（卷三·2，PDF 67—70）
- 《神枢经》：四立前各旺十八日
- 《历例》：木火金水各旺七十二日，土于四立前各旺十八日（合七十二），四者相加成岁
- 《醉醒子》：立春后阳木旺三十六日、惊蛰后六日阴木旺三十六日、清明后十二日戊土旺十八日 —— **这是按月令内部再分段的最细一档**

### 3.3 四时休旺（卷三·3，PDF 70）
旺 / 相 / 休 / 囚 / 死 五档表，四时各一行。

### 3.4 判强弱的正确次序

```
第一步：日主生于何月？该月是当令、得生、被泄、受克？
        → 查卷三·3 的四时休旺表
第二步：月令本气是否透干？透则力量加倍；不透则看月支所藏余气
        → 查卷二·10 支藏人元
第三步：统计日主同类（比肩劫财 + 印）与异类（食伤 + 财 + 官杀）的数量与位置
第四步：日支坐支最亲、月支次之、年时又次
        → 卷四「论日主法」（PDF 117—118）：「紧贴的左邻右舍是哪几个字」
```

> **关键纪律**（据卷四「论衰旺」PDF 110—111）：
> 「衰之中有旺势存在，这种情况就不应加以增益；旺之中有衰势存在，就不应该减损。」
> ——即**数量统计不能取代气机判断**。一个八字满盘比劫而日主无根于月令者，仍按弱论。

## 4. 第③路 格局：沈孝瞻骨架 + 张神峰病药 + 京图刘基四论

原书把三种体系的术语混着用，最容易出错。分辨如下：

| 体系 | 出处 | 核心问题 | 本书位置 |
|---|---|---|---|
| **病药说** | 张神峰《神峰通考》 | 何者为病、何者为药 | 卷四·16（PDF 108—110） |
| **用神成败救应** | 沈孝瞻《子平真诠》 | 格之成、格之败、如何救应 | 卷四·27—33（PDF 119—127） |
| **四吉神能破格 / 四凶神能成格** | 沈孝瞻 | 反直觉命题：吉神亦可败格 | 卷四·27—28（PDF 119—120） |
| **形象、八格、体用、清浊、真假** | 京图撰 刘基注（即《滴天髓》正文系统） | 气象与体用 | 卷六·8—13（PDF 171—176） |

### 4.1 五步法

```
1) 取格：月令本气透干者先取；不透取余气透干；均不透则取月令本气
   → 卷四「论月令法之一/之二」
2) 问病：格中何者为病？（病即"本身带有的害神"）
   → 病有六类：官被伤克、财轻比劫重、印轻被财、食伤太旺、日主太弱、日主太旺
3) 问药：药在命？在运？命中有药为「救应」，运来药为「成格」
4) 问高低：有药而药有力＝高；有药而药无力＝中；无药＝低
   → 卷四「论用神格局高低」
5) 问先后：同一用神，出现在年与出现在时，吉凶大不同
   → 卷四「论生克先后分吉凶」；典型例：丙先庚后主老运吉，庚先丙后主富貴兩空
```

### 4.2 「四凶神能成格」的正确用法

这是沈孝瞻最容易被误用的一条。原文（PDF 119—120）：

- 印轻透了杀而为助 → **杀也能成格**
- 财遇比劫，伤官能化解 → **伤官也能成格**
- 食神带杀，枭可化用 → **枭也能成格**
- 财逢七杀，刃可解危 → **刃也能成格**

> 所以「印不怕杀、财不怕伤、官不怕枭、杀不怕刃」——**前提都是格已成而病可救**。格未成而先见凶神，仍是败格。
> 袁树珊在此处按语（PDF 120）特意补了一句：「就像治理国家……」，提醒这是**条件句**，不是无条件句。

## 5. 第④路 岁运：命为体、运为用，三层不混

### 5.1 层级

| 层 | 时间尺度 | 判什么 | 出处 |
|---|---|---|---|
| 原局 | 一生 | 格局高低、性情、六亲根基 | 卷四 |
| 大运 | 十年 | 成格 / 变格（运来成就或破坏原格） | 卷五·4—9 |
| 流年（太岁） | 一年 | 吉凶触发点、应期 | 卷五·10—13 |
| 小运 | 未交大运之幼年 | 补大运之不足 | 卷五·15 |

### 5.2 大运三条铁律

1. **干支分管**：上干管前五年、下支管后五年（原书明载，并说「古今推算命运的人，没有不以干管五年支管五年来讨论的」PDF 125）。但同页也有反对意见，**本技能取干支同参、以支为重**，因为原书紧接着的例子都是按地支定吉凶。
2. **成格变格**：运来完全成格 → 十年皆佳；运来破格 → 十年皆滞。既不成又不破 → 看「透清」（卷五·9）。
3. **透清之法**：地支所藏之喜神，原局不出，运干透出即为「透清」，此十年大吉。反之藏忌神被运透出，十年大凶。

### 5.3 太岁：只论生克，不论冲犯

> 卷五「论太岁」（PDF 140—141）明确否定「日干冲克岁君为犯」的说法：「征指的是上伐下，太岁是君，日干是臣，臣不能伐君——这种说法本无道理。」
> **实操结论**：流年只按「太岁与原局、与大运的生克会合」判，不套「值太岁、冲太岁、刑太岁」的民俗框架。

### 5.4 宫限与小限的取舍

卷五·14「论运岁（附宫限）」与卷五·34「论流年神煞及月建吉凶」两节，袁树珊的态度是本技能必须照抄的：

- 命宫、小限**可参不可主**：他举实例（PDF 144）说明命宫癸水冲克用神丁火时，「小限逢甲或寅可生用神」——即小限只作**救应触发器**用。
- 卷五·34 则直接斥小限十二月神煞为「会弃干支五行生克的正理，而一味以这虚亡之歌为准……必然为方雅之人耻笑」，并说因有人来问「所以特别补录出来」。
- **实操结论**：小限与命宫只在「已判出用神、需要找触发月份」时才用；不作主判依据。

## 6. 第⑤路 表述：星家十要

卷八（PDF 225—241）是这个技能里最不像「命理」的部分，但也是最该照做的部分。十要：

|---|---|---|
| 1 | 学问 | 术不精则信服者少，非分之图谋更甚 |
| 2 | （标题 OCR 不可读，按体例待核） | — |
| 3 | 言语 | 命佳者劝其惜福，命蹇者劝其安命 |
| 4 | 敦品 | 术士自身品行先立 |

## 7. 本技能的三条硬纪律

1. **时辰未确认不做六亲断。** 时柱是子女宫，也是「分刻取用」的落点（卷四「论生时法」）。时辰错一小时，子女数与性别判断基本必错。
2. **断语须标层级。** 每条断言后注明「原局 / 大运 / 流年 / 命宫小限」。原书自己不混说，我们也不能混说。
3. **神煞只作形容词，不作主语。** 卷三收了 22 个神煞，但卷六「论星煞无关格局」（PDF 180—183）已把立场讲明：格局定贵贱，星煞只定风味。凡是「因带羊刃所以凶」这类句子，一律改写为「因原局如何，故于某运某年触发；羊刃只是其象」。
