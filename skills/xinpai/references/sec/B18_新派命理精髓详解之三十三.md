# 新派命理精髓详解之三十三







    戊申 庚申 丁巳 乙巳(子丑)
    [pic]
    先天风水：庚旺，戊弱，丁旺，乙弱，申弱，巳旺。
    庚金先天风水中旺．不当官。庚为妻，与爱人的关系不好，戊土为正官社会环境、
弱，在单位工作得到领导的重用。时干乙木为偏官、偏印，为忌神、弱。本命出名，喜
欢干偏官、而且一干就成功。反馈：所有的生意在最初时，都能赚到钱。这就是偏官应
吉。
    辛酉大运中，时干乙木弱，再逢丁火旺年．就会干偏官。辛金大运同时制丁火，和
乙木，先天风水中丁旺，乙弱，所以辛金大运论乙木弱，而不能论制去丁火乙木旺。本
运中干偏官时，必须是在偏官大吉之年才会干偏官。现在辛金大运制了乙木，再找一个
让丁火旺的流年时，就是干偏官之时。
    干偏官，只有局中偏官在大吉、或大凶时，才会干偏官。
    壬戌大运，壬水制戊、制庚，制去戊土，正官吉，在单位中工作，受领导重用，戊
土弱，常换工作岗位，越换越好，在戊土弱年换工作。
    壬水大运中，能够让年干戊土弱的年份，有庚、戊、甲。时干乙木生丁火，丁火日
干弱，庚金旺，也是一个让庚旺的途径，但是，乙木在先天风水弱，乙木使日干丁火弱
的力量十分弱，庚金不会很旺的，所以乙木旺的这个途径，不是一个最佳的变换工作路
径。
    我是农民，社会环境吉，就是种地的条件越来越好了，我那个地方是个怕旱的地方
，断他的土地每重新分一次土地，水源条件就更加好一点。
    壬水大运制年干戊土，最终导致时干乙木弱，正官吉，偏官也吉。也就是说，本运
中我常常干个偏业，干得还不错。丁火旺年偏官最吉。
    壬戌大运，丁卯流年，正官的天干最吉，活干得很轻松。
    壬戌大运，戊辰流年，年干戊土最弱，正官的社会环境大吉，今年换了个好地方。

    壬戌大运，甲戌流年，甲木克年干戊土，又换了地方。
    癸亥大运，偏官凶，正官凶。但是正官的社会环境却好，本运中偏财导致了正财凶
。偏财凶时花钱特别多，老婆就不高兴，于是两口就为一些经济上的小问题而发生争吵
。
    癸亥大运，庚辰流年。庚在流年出现，妻或妻家的女人，来对我表示不满，姨妹来
同我吵了一架。
    癸亥大运，乙亥流年。吵架最凶，时干乙木旺，日干丁火最弱．不制庚，正财凶。

    癸亥大运，无论正官还是偏官，都不好。因为癸水在先天风水中旺
。生乙破财多，制丁庚旺、正官凶．事业干不成。
    正官的社会环境吉．划宅基地时，痛快给了我。宅基地是偏印。看乙木，丁火弱，
位置不好，把我弄到低处了，亥水大运，亥水无力制巳火，巳火更旺了，所以我的宅基
地在巳火旺的地方。
    甲子大运，十分好的运。制戊正官吉，事业顺利。时干弱，出名。
    姐姐；看月干庚金，为忌神旺，与姐姐的感情一般化。
    庚金旺，制年干戊土，姐夫能干。
    姐姐的正官是年干戊土，姐姐的偏官是丁火，丁火旺，偏官较好，所以姐姐对感情
的要求比较高，对姐夫不满。甲木大运中，戊土弱，庚金旺，丁火旺所以本运中姐姐的
偏官好，姐姐或许有了更好的工作，要不就是有了中意的男友，所以才离开了姐夫。
    姐妹的官灾，看戊土，甲木大运年干戊土弱，本运中不会有大的官灾，己土流年制
时干乙木，时干乙木弱，日干丁火旺，庚金就弱，年干戊土会稍旺一点，有点小小的官
灾，不重，很快就解决好了。乙木在先天风水中弱，制乙木时．日干丁火旺的程度较大
，年干戊土旺较有力，所以这个问题不能太轻视了。得罚款才能解决了。
    父亲：父亲应凶在地支。
    天干中乙木弱，丁火有力制乙木，年干戊土弱，也是时干乙木弱的一个途径。只有
庚金旺这一个凶。
    地支中巳火旺，日支巳火帮巳火，两个凶。年支与月支申金本身又弱，也是巳火旺
的途径。地支三凶，所以父亲应凶在地支。本命克父亲极重，因为是异六亲，所以父亲
寿命较长，但是不可能见到爷爷。
    甲子大运，子水制申金，申金弱，巳火旺，本运中父亲应凶。丑在先天风水中弱，
不能制巳火，所以今年应凶。
    甲子大运，己丑流年，丑土弱，不制巳火、在巳火旺的月份，父亲去世。
    甲子大运，丁亥流年。亥水在先天风水中弱、这一年父亲就生了病。
