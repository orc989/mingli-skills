## ⚠️ 阅读前必读：本文的三条使用纪律

本文收录的六亲、女命、贫贱条文，**均为 1935 年前后的民国命书原文口径**。其中有相当一部分内容（尤其是女命篇的「淫贱」「克夫」、贫贱凶夭篇的「夭」「贱」）带着明确的时代与性别偏见。

**本技能一律按以下三条处理：**

1. **术语改写**：凡原文的贬义判断，一律改写为中性行为倾向描述。对照表见第九节。
2. **不做价值判断**：只断「关系质量、亲缘厚薄、相处模式」，**不断人的品性优劣、不断生死、不断贫富贵贱的等级**。
3. **必须标明「此为概率性描述」**：六亲与性情断语的可验证性远低于格局用神，原书自己也说「可以意会，难能言传」。

**违反上述三条，即视为误用本技能。**

## 一、六亲之更定：千里命稿最重要的一次改定

韦千里在六亲篇开头做了一件在当时相当大胆的事：

> 「**旧论父子殊多谬误**（详见《命理约言》），**特更定六亲看法如后。**」

### 新旧对照

| 六亲 | **旧论**（韦千里所指的谬误） | **千里命稿之更定** |
|---|---|---|
| **父** | 偏财为父 | **男女命皆以生我之印为父** |
| **母** | 正印为母 | **同父**（皆以印为母） |
| **夫** | 官杀为夫 | **克我之官杀为夫**（未变） |
| **妻** | 正财为妻 | **所克之财为妻**（未变） |
| **兄弟** | 比劫为兄弟 | **男女命皆以同我之比劫为兄弟**（未变） |
| **子** | **男命**以官杀为子，**女命**以食伤为子 | **男女命皆以我生之伤官食神为子** |

### 这次改定的实质：两处

**第一处：父改为印。**
旧论以偏财为父，是「我克者为父」，逻辑上父亲成了受我支配的对象，韦千里认为不通。改为「生我之印为父」——父与母同为生我之源，只是阴阳之别。

**第二处（更重要）：子改为食伤，男女同。**
旧论男命以官杀为子（因为「克我者」代表「管我的人」，父管子），女命以食伤为子（因为「我生者」代表「我生的人」）。韦千里把**男命也改成食伤**，理由是：**子女是「我生」的，不分男女。**

> 原文：「（六）子：**男女命，皆以我生之伤官食神为子。**」

**这是全书方法论上最一致的一处**——六亲的取法应当依据「**生克关系的实质**」，而不是「社会角色的比喻」。

### 父母妻子之「宫位」（与「星」并行）

| 六亲 | 宫位 |
|---|---|
| 父母 | **月柱** |
| 妻（女命为夫） | **日支** |
| 子息 | **时柱** |

> ⚠️ **星与宫是两套坐标，可以相反。** 补充篇「妻财」条讲得最清楚：
>
> 「或**财得用而日支为忌神**，或**财不足而日支为喜神**。**妻星与妻宫，难以两全其美耳。**」
>
> 所以断妻：财星管「妻的条件与助力」，日支管「夫妻相处的实际质量」。**两套都要看，结论可以是矛盾的——这种矛盾本身就是信息。**

### 2.3 关键分辨：「妻美」与「妻贤」是两件事

原书反复用这两组词，且经常拆开说：

- **「妻美」** = 财星本身的质量（财为喜、财不受克）
- **「妻贤」** = 财星对日主的作用（财能助用、不克身）
- **「妻美而克」「妻贤必克」「妻陋不伤」** = 星好但宫凶

> **这是千里命稿断妻最精细的地方**：不是「妻好」「妻坏」二选一，而是**星、宫、克不克**三个独立维度。断语必须分开写。

### 2.4 断妻的正确输出

```
【妻星】财为喜/忌；财有力/无力；财被克合否
【妻宫】日支为喜/忌；日支被冲合否
【克否】有无比劫夺财、财生杀克身
【结论】（分项写）
  · 妻的条件与助力：…
  · 夫妻相处质量：…
  · 有无刑克：…（用「亲缘较薄／聚少离多」表述，不用「克妻」）
```

## 三、夫（女命）

### 3.1 夫之荣枯：十一条「以某救之」

原书这一节体例非常整齐，一律是「**某病 → 以某神救之 → 救神之力有余则夫荣，不足则夫枯**」。

| # | 局中之病 | 以何救之 |
|---|---|---|
| 1 | 官星太旺 | **伤官** |
| 2 | 官星太微 | **财** |
| 3 | 伤官旺而无财官 | **印** |
| 4 | 官星太旺，无比劫 | **印** |
| 5 | 官星太弱有伤官 | **财** |
| 6 | 满盘比劫，无印无官 | **伤食** |
| 7 | 满局印绶，无官无伤 | **财** |
| 8 | 伤官旺，日主衰 | **印** |
| 9 | 日主旺，伤食多 | **财** |
| 10 | 官星轻，印绶重 | **财** |
| 11 | 官有杀混 | **食神** |
| 12 | — | **日支利于用神则夫荣，不利于用神则夫枯** |

> **这张表是全篇最有技术价值的部分**，因为它把「夫星」换算成了「用神问题」——**救夫就是救用神**。第 11 条「官有杀混，以食神救之」尤精：食神制杀留官，去混则夫星清。

|---|---|
| 1 | 官星微，无财星，日主强，伤官重 |
| 2 | 官星微，无财星，日主旺，印绶重 |

| 2 | 制杀太过，比劫助食 | 兄弟多累 |

| 7 | **比劫破坏用神** | 兄弟多累 |
| 8 | **比劫被用神所破** | 自己兴而兄弟衰 |
| 9 | **比劫应扶而不得扶，或应抑而不得抑** | 兄弟非稀少，即枯涩 |

### 6.3 全节只有一条主线

**比劫是兄弟星，比劫与用神的关系决定兄弟的吉凶**：

```
比劫为用神   → 得兄弟之力
比劫破坏用神 → 受兄弟之累
比劫被用神破 → 自己兴而兄弟衰
比劫扶抑失当 → 兄弟稀少或枯涩
```

其余八条都是这条主线的具体情形（比劫帮身、比劫合杀、比劫助食等）。**记住主线，比背十三条有用。**

## 七、女命篇

### 7.1 总纲：女命与男命无大异

> 「女命看法，**与男命无大异**。惟女重夫子二星，取用之道，能**夫子、自身三者兼顾最妙**，否则**宁愿身主较弱**。夫星与子星切不可受挫；再次必须顾全夫星，更次必须顾全子星。总以**夫子两全者为上命**，至少或夫或子有一可靠。若全不可恃，则为下命决矣。」

**这段话要分层读：**

| 层次 | 排序 |
|---|---|
| 最上 | 夫、子、自身三者兼顾 |
| 次 | 宁愿身主较弱（牺牲自己保夫星子星） |
| 再次 | 必须顾全夫星 |
| 更次 | 必须顾全子星 |
| 下命 | 夫子全不可恃 |

> ⚠️ **这是明确的时代价值观：「牺牲自身保夫星」。本技能不采纳此排序。**
>
> **本技能的处理**：女命取用**与男命同法**（强弱→格局→用神），只在**第六步推六亲时**才引入「夫星／子星」的检视。**取用神时不因「女命」而降低标准、不因「夫子」而牺牲自身。**

### 7.2 女命取用二十七法

原书的二十七条，实为**日主强弱（强／弱）× 局中何神最多（伤食／官杀／财／印／比劫）× 有无救神**的三维展开，且**逐条附有解释**。

**二十六、二十七两条原文排在解释里（PDF 55 页末），系排版次序之误，实为第（二十六）（二十七）条。**

#### 日主强（1—15）

| # | 局 | 用神 | 原书解释 |
|---|---|---|---|
| 1 | 伤食多 | **财** | 身主子星既美，赖财生官杀则夫亦荣 |
| 2 | 伤食多，无财 | **印** | 赖印制伤食以保官杀之夫星 |
| 3 | 伤食多，无财无印 | **伤食** | 官杀受伤食之克而无救，夫不可靠，唯鞠养爱子恃以终老 |
| 4 | 官杀多 | **伤食** | 身与夫星皆健，冀子星亦成立；且制官杀亦帮夫之道 |
| 5 | 官杀多，无伤食 | **财** | 仅身与夫星之健，赖财帮夫 |

### 7.3 这张表怎么用

**先说结论：这张表在技术上与八格用神表高度重合，重复度高，不必全背。**

检验：以第 1 条「日主强，伤食多，取财」对 `03_格局与用神.md` 的「伤官格日强伤食重重 → 取印」——**不一致**。原因：女命表把「伤食」同时当「子星」，取用时要兼顾子星，所以日强伤食多时，宁可取财（生官杀、帮夫）而不取印（克伤食、伤子星）。

**所以这张表的真正价值不是「取用神」，而是「解释为什么女命的用神有时要偏离标准答案」**——它给出的是一套**权衡逻辑**，不是一套取用规则。

**本技能的规定**：

1. **取用神一律按 `03_格局与用神.md` 的八格表**，不因「女命」而改。
2. **女命表只作核对**：若两表结论不同，说明该命「自身利益」与「夫星子星」存在张力，**这正是要断出来的内容**，而不是要回避的。
3. 断语中若引用女命表，必须说明「此处依原书女命权衡法，与八格标准取用不同，差异本身即为命局张力所在」。

### 7.4 女命取用的一个亮点

第 10 条的解释是全篇最有理论价值的：

> 「或曰：何勿用官杀拘身？**殊不知有多印之泄官杀而生身，官杀岂能制身**，如妻不受夫制，用财则尚能助夫也。」

**这一句的技术含量**：日强印多，为什么不用官杀？因为印多会泄官杀而生身，官杀无力制身。所以只能取财制印。**这是「印重则官杀失效」的机制说明**，男女命通用，与 `05_六神喜忌速查.md` 里「印泄官杀」一条完全吻合。

### 8.1 富（11 条）

| # | 条件 |

| 2 | 忌印而财能坏印 |

> 第 1 条「**财星生官，官星卫财**」是全篇的枢纽：财生官，官反过来护财（制比劫）。**这是一个闭环，比单纯的「财旺」高一个层次。**

### 8.3 贫贱凶夭

> 底本 `vol_pinqiong.md`（PDF 57—59）。**本技能的处理原则：不收录具体贬义判词，只保留机制。**

原书「贫」「贱」「凶」「夭」四类条文的共同机制，可归为四条：

| 机制 | 说明 |
|---|---|
| **用神遭克破而无救** | 与「富」「贵」第 13／15 条恰成反面 |
| **偏枯无出路** | 一气独旺而无泄无克（如满局比劫无食伤、满局印绶无财） |
| **病重药轻** | 局中有病而药无力（参 `04` 篇事业条「病重药轻者作事多出自动，而费力不计好」） |
| **刑冲破坏关键宫位** | 日支、月柱、时柱被冲，对应妻、父母、子 |

> **「夭」的部分（原书列「金寒水冷而土湿」「火炎土燥而木枯」等）本技能一律不作寿命预断**，改写为「**体质偏弱，宜早作健康管理**」。

### 8.4 「贱」字辨义（原书的一个重要澄清）

原书在贫贱篇中特别说明，「贱」**「非阶级低下之称」**，指的是**「无所依托、不能自立、为人所轻」**的状态——即 `04_补充篇精要.md` 事业条所说的「**身旺无依，或身弱无助，只合依人作嫁**」。

**本技能采纳此义，并进一步限定**：断语中不出现「贱」字，一律写「**难自立，宜依附平台或他人成事**」。

## 十一、事业（第⑧步）

> 完整表见 `04_补充篇精要.md` 第十五节。此处只给决策流程与三条最具操作性的观察。

### 11.1 决策流程

```
① 看用神五行需什么
   ├─ 需水 / 命有驿马 → 流动事业、外勤
   ├─ 需火 / 需金     → 工厂、机械、技术
   └─ 需木 / 需土     → 农林、种植、固定实业

② 看格局特征
   ├─ 伤官伤尽 / 有杀有刃 / 杀印相生 → 武备、执法、竞技
   ├─ 伤食生财 / 身财两停           → 商贸、经营
   ├─ 食神吐秀 / 带文昌             → 文学、教育、内容
   ├─ 正官清粹 / 官印相生           → 公共事务、组织管理
   ├─ 劫比成群                     → 自由职业（「空拳觅利」）
   └─ 财官并美                     → 财务、金融

③ 看能否自立
   ├─ 财官有力、日主朗健 → 可自立为主
   └─ 身旺无依 / 身弱无助 → 依人作嫁（依附平台）

④ 看稳定性
   ├─ 冲合少 → 成专一
   └─ 冲合多 → 频年变迁

⑤ 看做事方式（原书独有）
   ├─ 病重药轻 → 多出自动，费力不计好
   └─ 病药相济 → 多出于被动，易成而省力
```

### 11.2 三条最有操作性的观察

1. **「五行偏枯之命，所事多风波起落，亦有此业利而彼业不利者」** ——偏枯之命不是「做什么都不顺」，而是「**这一业顺，那一业不顺**」。所以断事业必须具体到行业五行，不能笼统。
2. **「八字病重药轻，作事多出自动，而费力不计好」** ——这类人**主动但无效**，断语应建议「先补药，再动手」。
3. **「身旺无依，或身弱无助，只合依人作嫁」** ——这句话不是贬低，是**策略建议**：依附平台、借力成事，比单干成功率高。

## 十二、六亲断法的三条通则（全篇提炼）

### 通则一：星系与宫系分开看，可以相反

> 「妻星与妻宫，难以两全其美。」（`vol_buchong.md`）

每一个六亲都有「星」（财、官、印、食伤、比劫）和「宫」（月柱、日支、时柱）。**星管条件与助力，宫管实际相处质量。** 两者可以矛盾，**矛盾本身就是要断出来的内容**。

### 通则二：六亲之吉凶，取决于「该星与用神的关系」

不是「该星旺就吉、弱就凶」，而是：

```
该星为用神     → 得力
该星生助用神   → 得力
该星破坏用神   → 多累
该星被用神所破 → 该六亲衰，自己兴
该星扶抑失当   → 亲缘稀薄
```

（兄弟节的九条吉、九条不吉，是这条通则最完整的示范。）

### 通则三：六亲断语必须分层，不可混成一句

```
【星】该星强弱、为喜为忌、被克合否
【宫】该宫位为喜为忌、被冲合否
【用】该星与用神的关系
【结论】分三项写：条件／助力 · 相处质量 · 亲缘厚薄
```

**做不到分层，就不要断六亲。** 一句「你克妻」既不可验证，也不可改进，是最低质量的断语。
