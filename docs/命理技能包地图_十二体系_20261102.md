```
① 穷通宝鉴  定用神（君臣佐使）
② 子平真诠  定格局与相神（成败、高低）
```

## 三、三处真分歧（引用必须标派别）

### 分歧一：看不看地支藏干

| 派 | 立场 |
|---|---|
| **神峰通考** | **明确反对**：「地支所藏且不必看，再看则混杂不明，从重者论。」只论透干与月令 |
| **盲派/新派/子平部分** | 藏干必看（丑藏辛、申藏庚、未藏乙丁、戌藏戊辛丁） |

**影响**：本库「庚辛分君臣」「借某盘申中庚」「辛丑丑藏辛」全部建立在藏干上。
按神峰口径，这些推论不成立；按盲派口径，成立。
→ **凡用藏干的判断，必须标注「依据藏干一派」**，否则会被神峰系统直接否掉。

### 分歧二：比劫是帮身还是夺财

| 派 | 立场 |
|---|---|
| **三命通会·正财格** | 「财旺身旺有官护财」为成；**「比劫夺财、身弱不能任财」为破** |
| **金镖门/新派** | 身弱时比劫是药，帮身担财 |

**分界点＝身强弱**：身弱是药，身旺是贼。药有剂量，过多即转分财。
→ 四条件第二条「比劫帮身」须带前提：**身弱为前提 ＋ 名分封顶**。

### 分歧三：太岁刑冲能不能用

| 派 | 立场 |
|---|---|
| **命理探源** | **明确否定**：「太岁是君，日干是臣，臣不能伐君，此说本无道理」 |
| **渊海子平/盲派/新派** | 大量使用冲合害、伏吟、三刑断应期 |

**处置**：三套并行，引用标派别。
- 判**应期、动象、触发点** → 用盲派/新派地支关系
- 判**格局高低、药之有力无力** → 用命理探源生克会合
- 两者一致时可信度最高；不一致时须写明依据哪一派

## 四、本盘对照：十二派对同一张盘怎么说

盘：**乾造 丁卯 · 丙午 · 壬寅 · 辛亥**（壬水日主，午月）

| 包 | 关键原文/条目 | 对本盘的判断 |
|---|---|---|
| **穷通宝鉴** | 五月壬：「丁旺壬弱，**取庚为君，癸为臣**，无庚不能蓄源，无癸不能伤丁」；自注「辛金为用最清，取庚为君者惧丁火伤辛也」 | 要**庚**（盾）＋**癸**（帮手）；庚＝挡丁、辛＝守财 |
| **子平真诠** | 成格条件「**财格透印而位置妥贴，两不相克**」；高低「**有情而无力＝格之高而次者**」 | **成格，中上，属有情而无力**（丁年辛时隔两位不相克） |
| **神峰通考** | 四病之「弱」：「日主太弱……尤忌极弱无根」（水至巳为极弱，然巳中有庚金为水根）；「**弱而无根，则不复可救**」 | 壬在**亥为临官（有根）**→ 属**弱而有根，可救**；治则「扶其所弱，使其有根」 |
| **三命通会** | 正财格：成＝财旺身旺有官护财；破＝比劫夺财、身弱不能任财 | 财旺（丙丁午）、**身弱**、无官护（己土不透）→ 格有破，须补身 |
| **渊海子平** | 「财官旺而日主弱」＝富屋贫人；身弱行身旺则发 | 早年财旺身弱＝能见财不能守；**行身旺运则发** |
| **滴天髓** | 中和／众寡；何知章富贵贫贱 | 偏枯（火旺水弱），须取中和 |
| **金镖门（盲派）** | 旺衰六档第 4 档「**不旺不弱（能承载财官）**」：坐下或近处有强根，虽财官旺而不倒 | **定「能承载」而非「身弱」**；且明训：**断婚须取帮身，断事业可直接用财官** |
| **千里命稿** | 八步评断＋行运七三折衷 | 按八步走：强弱→格局→用神→喜忌→岁运 |
| **命理探源** | 五路：校时→旺衰→格局用神→岁运→表述 | 旺衰判「财多身弱」，与子平一致；但否定太岁刑冲 |
| **新派** | 内外环境论＋**断流月流日流时** | 应期最细，可落到月日 |
| **五行精纪** | 纳音：丁卯炉中火、丙午天河水、壬寅金箔金、辛亥钗钏金 | 另一坐标系，仅作旁证 |
| **兰台妙选** | 220 格目 | 同上，不入子平判断 |

### 关键：三派在「能不能救」上罕见地一致

| 派 | 说法 | 指向 |
|---|---|---|
| 子平真诠 | 格成，但「有情而无力」 | **格没破，是力不够** |
| 穷通宝鉴 | 「无庚不能蓄源」 | **缺的是源，不是格** |
| 神峰通考 | 「弱而无根则不复可救」→ 本盘**有根** | **可救** |

> 三本不同体系的书，指向同一个结论：**这张盘不是废盘，是欠力。**
> 这与 V4.2 定论「命不是破的，是浮的」互证。

## 五、本次读取新得三条（2026-11-02）

1. **神峰「弱而有根可救」是「格成力弱」的第三重独立支撑**——此前只有子平（成格条件）与穷通（无庚不能蓄源）两重，现在三派同向。且它给出了**可救的判据**：有根。本盘壬在亥为临官，故在「可救」一侧。

2. **神峰明确反对「贪看藏干」**——「地支所藏且不必看，再看则混杂不明」。这与本库大量藏干推理（丑藏辛、申藏庚、未藏乙）正面冲突。**处置：凡藏干结论须标派别。**

3. **金镖门给了「身弱 vs 能承载」之争的调和办法**——不争孰是，而是**分用途**：「断婚期因财官过重，大运仍须取帮身；断事业可直接取财官为用」。即：**论婚取帮身，论事业取财官。** 这一条比「身弱/不弱」的争论实用得多。
