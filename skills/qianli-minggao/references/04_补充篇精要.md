# 04 补充篇精要

> 对应原书：**补充篇**（PDF 59—71），全书体量最大之一篇
> 底本：`references/vol_buchong.md`
> 原书自述写作缘起：「上辑四卷述焉未详，致从学诸君，或病简短，或竟质疑。特作补充篇，以济不逮。」

这一篇是千里命稿的**技术底座**。前面各篇讲「怎么看」，这一篇讲「凭什么这么看」——干支之间到底怎么作用、作用力有多大、什么情况下不算作用。八步评断法里第①步到第④步的每一个结论，最后都要落回这一篇的规则来检验。

## 一、天干：先扔掉那套比喻

韦千里在补充篇开篇做了全书最不客气的一次清理：

> 「命家作为歌赋，比喻失伦。如称甲为栋梁，乙为萝藤，丙为太阳，丁为灯烛，戊为城墙，己为田园，庚为顽铁，辛为珠玉，壬为江河，癸为雨露，**不可信也**。」

他给的正解只有一句：**「十干阴阳之异，不过阳刚阴柔，阳健阴顺。阳不甚受阴克，阴不甚畏阳克。阴易于他从，阳难于他从。阳干气旺，阴干质坚而已。」**

### 甲乙气质的推导（这一段是全书最精彩的推理）

韦千里用「气／质」两个字，把十干的阴阳关系一次讲通：

- **甲者乙之气，乙者甲之质。** 在天为生气而流行于万物者，甲也；在地为万物而承此生气者，乙也。
- 细分：生气之散布者，甲之甲；生气之凝成者，甲之乙；万物之所以有枝叶者，乙之甲；而万木之枝枝叶叶者，乙之乙。
- **「方其为甲，而乙之气已备；及其为乙，而甲之质乃坚。」**

由此推出杀官之别：

| 干 | 是什么 | 遇庚（阳金，肃杀之气） | 遇辛（阴金，人间五金之质） |
|---|---|---|---|
| 甲 | 木之**生气**，行于天 | **七杀**——肃杀之气能销克生气 | **正官**——金铁刀斧伤不到气 |
| 乙 | 木之**形质**，存于地 | **正官**——肃杀之气只扫落叶，根柢愈固 | **七杀**——刀斧斩伐无余 |

同理推火金：

- 丙为阳火（融和之气），丁为阴火（薪传之火）。
- 肃杀之气逢阳和而克去 → **庚以丙为煞**；
- 人间之金不畏阳和 → **辛以丙为官**；
- 人间金铁逢薪传之火立化 → **辛以丁为煞**；
- 肃杀之气不畏薪传之火 → **庚以丁为官**。

**结论**：甲庚杀、乙辛杀、庚丙杀、辛丁杀这套「阳克阳、阴克阴为杀」的格局，不是规定，是气与质的物性推出来的。理解了这层，十神就不是背表格，是可推导的。

### 阳干阴干的性格判词

> 「阳干主刚，威武不屈，而有恻隐之心，其处世不苟且。阴干主柔，见势忘义，而有鄙吝之心，其处世多骄谄。大都趋利忘义之徒，皆阴气之为戾；豪侠慷慨之人，皆阳气之独钟。」

但紧接着一句自我修正：**「然阴阳停匀，不偏不倚，尤属顺正之命，自无损人利己之心也。」**——不要拿阳干阴干直接给人贴标签，`07` 篇评性情时以此为准。

## 二、地支：三条容易漏的定性

> 「地支所藏，非仅一干。故生克制化，其理多端，然以本气为主。寅必先甲而后及丙，申必先庚而后及壬。」

| 定性 | 内容 | 用处 |
|---|---|---|
| **动静** | 「阳支性动而强，吉凶之验恒速；阴支性静而弱，福祸之应较迟。在局在运，均以此意消息之。」 | 断应期早晚 |
| **专／广／收** | 子午卯酉**秉气最专**；寅申巳亥**容积最广**；辰戌丑未**收敛最宜** | 断力量纯度 |
| **体阳用阴／体阴用阳** | 子午未属阳（因子藏癸、午藏丁），体阳而有阴，故作**阴**论；巳亥本属阴（巳藏丙、亥藏壬），体阴而用阳，故作**阳**论 | ⚠️ 与常识相反，断六合、断阴阳属性时务必按此 |

**「寅申巳亥容积最广」** 是解「为什么寅申巳亥之冲两败俱伤」的钥匙：四生方各藏三干，气杂，一冲则三干俱动。

## 三、阴阳生死：阳顺阴逆的理据

> 「干动而不息，支静而有常。以每干流地于十二支之月，而生旺墓绝系焉。阳主聚，以进为进，故主顺；阴主散，以退为进，故主逆。此长生沐浴等项，所以有阳顺阴逆之殊也。」

以甲乙为例：

- 甲为木之阳，天之生气流行万木 → **生于亥，死于午**。
- 乙为木之阴，木之枝枝叶叶受天生 → **生于午，死于亥**。
- 理据：木当亥月，枝叶剥落而内之生气已收藏饱足，可为来春发泄之机，故甲生；木当午月，枝叶繁盛而内之生气发泄已尽，故甲死。乙木反是——以**质**论，自与**气**殊。

**十二名是形容，不是实体**：长生（犹人之初生）、沐浴（既生之后沐浴去垢，如核既为苗则青壳洗去）、冠带（形气渐长）、临官（由长而壮，可以出任）、帝旺（壮盛之极，可以辅帝）、衰（盛极而……）。

> 断命时若见某干「在沐浴」「在死地」，断的是**气的阶段**，不是断人死。这一点在 `07_六亲与女命.md` 里反复出现——原书屡以「绝」字断六亲，指的也是**念头被克绝**，不是死亡。

## 四、干克：两败俱伤与力之轻重

### 三条总纲

1. 「**受克者败尽无余，主克者虽胜亦劳**」——所谓两败俱伤。
2. **日干本身不作此论**：「日干本身，逢克我或我克，不作两败俱伤论。盖克我者为官，我克者为财，是我之财官，何为两败俱伤。」
3. **相克不必然是坏事**：「或庚或甲，若为局中喜神，相克固凶；若为局中忌神相克，则反为吉。」

### 克力轻重十三条（PDF 60—61）

| # | 情形 | 克力 |
|---|---|---|
| 1 | 年庚月甲，地位最贴 | 最重 |
| 2 | 庚载申、甲载寅，或两庚两甲 | 势均力敌，亦重 |
| 3 | 两庚一甲 | 摧枯拉朽，**战克反轻** |
| 4 | 两甲一庚 | 一甲不敌，两甲则力较劲，**战克反重** |
| 5 | 一庚一甲，甲得时得势 | 庚难取胜，甲未受创；须「两弱庚而一强甲」方成强战 |
| 6 | 庚年甲日（隔一月柱） | 较轻 |
| 7 | 庚年甲时（隔月日两柱） | 愈远愈轻 |
| 8 | 庚年壬月甲日 | 壬泄庚生甲，**似克而非克**（有调解） |
| 9 | 庚年丙月甲日 | 丙克庚，庚不再克甲，反而转成「丙庚相克」 |
| 10 | 庚年甲月壬时 | 壬虽泄庚生甲，但壬远隔、庚甲贴近，**仍作克论** |
| 11 | 庚年甲月丙时 | 丙远不能克庚，庚甲贴近，**仍以庚克甲论** |
| 12 | 庚年甲月戊日 | 谁最强谁生效：庚最强则庚克甲，甲最强则甲克戊 |
| 13 | 阳克阳、阴克阴 | 克力最重；阴克阳次之；**阳往往不克阴，作干合论** |

**第 8、9 条是「通关」的原型，第 10、11 条是「通关失效」的边界。** 两者合起来就是一条铁律：**调解之神必须贴身在两者之间，隔位即无效。**

## 五、干合：合之力与化之难

### 合的三种效果

1. **合去**：「如甲日见辛，辛为甲官；若透丙合辛，则辛非甲官矣。丙为甲食，然既作合，亦非甲食矣。故合者，并去而两有所绊也。」——双方同时失去原有功能。
2. **日干本身之合不受影响**：六阳逢财、六阴逢官，俱是作合（如乙日逢庚，庚为我官，合而不去）。
3. **合吉神则凶，合凶神则吉**：视所合之字在局中为喜为忌。

### 合力轻重五条

| # | 情形 | 判 |
|---|---|---|
| 1 | 甲年己月，紧贴 | 合力最重 |
| 2 | 甲年己时，隔位太远 | 「合而不能合也，半合也」，得十之二三 |
| 3 | 丙辛相合而强弱悬殊 | 强者「纵为所绊，仍有六七分能力」；弱者力更轻 |
| 4 | 两辛一丙、两丙一辛等 | **妒合**——「犹二女一夫，一女二夫，难免争妒」 |
| 5 | 庚年乙月甲日乙时 | 虽两乙合一庚，因甲日隔之，**全无争妒之意**，年庚月乙仍作纯粹之合 |

### 克合并见：按「主克受克」判

| 情形 | 判 |
|---|---|
| 庚年乙月甲日 | 庚乙紧贴、庚甲间隔 → **作合不作克** |
| 庚年辛月乙日 | 辛乙紧贴、庚乙间隔 → **作克不作合** |
| 甲年庚月乙日 | 克合并见且皆贴近 → 庚可胜甲，故庚乙相合、甲不克乙 |
| 丙年庚月乙日 | 丙能胜庚，故乙庚相合、丙克庚 |

**规律：贴身者优先；贴身者不止一个时，谁强谁生效。**

### 合而化：五道关卡（最容易被滥用的一条）

| 关 | 内容 |
|---|---|
| **时令** | 辰戌丑未月**只可化土**，亥卯未月只可化木，巳酉丑月只可化金，寅午戌月只可化火，申子辰月只可化水 |
| **宾主** | **日干逢合则可化**（日干为命之主）；**他干逢合不能化**（他干为命之宾） |
| **明暗** | 透干为明，藏支为暗。**明与暗，只合不化**——如己土透干，与亥中所藏之甲，可合不可化 |
| **地位** | 甲日己年，被月柱所隔，**合且勉强，况乎化** |
| **岁运** | 甲日逢己运己岁，**应以正财论，不作化土论**；若日干非甲，他干有甲者逢己运己岁，亦然 |

> 五关一过不了就不成化格。市面上「化气格」断得满天飞，多数栽在**宾主**和**岁运**两关。

## 六、支冲：四种冲法各不相同

### 总原则

> 「局中喜神冲败则凶，凶神冲败反吉。」

### 按组合分

| 组合 | 性质 | 判 |
|---|---|---|
| **寅申巳亥** | 四生方，各藏三干 | **两败俱伤**（申中庚克寅中甲，寅中丙未尝不克申中庚） |
| **辰戌丑未** | 本气皆土，同类 | **只算冲动，无战克意**；「土因激起而愈旺」 |
| **子午卯酉** | 四专气，所藏最简 | **胜败最易分**（子中癸克午中丁，午中己克子中癸） |

### 冲力减损七则

1. 年时相冲（**海底冲**）——地位远隔，**全无冲意**
2. 年日冲、月时冲（隔一位）——冲力减轻
3. 一支为**旬空**——冲力亦减
4. 午年午月子日——只作午月子日相冲，**不作午年子日相冲**
5. 午年子月午日而午力强——两强午一弱子，**胜败立分，冲击极暂**
6. 地支多藏干，冲的复杂度远高于天干
7. 本气、时令、多寡三者并看

**第 1、3、4 条是断「冲了但没冲」的主要依据**，实务上最能减少误断。

## 七、支合：六合、局合、方合

### 三种合

| 名 | 构成 | 原理 |
|---|---|---|
| **六合** | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 由日月合朔而来 |
| **局合** | 亥卯未木、寅午戌火、巳酉丑金、申子辰水 | 三合局 |
| **方合** | 寅卯辰东、巳午未南、申酉戌西、亥子丑北 | 取方位之气 |

### 合的吉凶

- **六合**：犹羁绊也。凶神逢合减凶，吉神逢合减吉。
- **局合／方合**：命中喜该五行则吉，忌则凶。

### 合力十条（含冲突时的优先级）

| # | 规则 |
|---|---|
| 1 | **局合以旺支最重**：亥卯未以卯为旺，巳酉丑以酉，寅午戌以午，申子辰以子 |
| 2 | **方合须三支全**，只二支不作合论 |
| 3 | **六合须紧贴**，隔一位或二位即不能合 |
| 4 | 方合局合三支全者，**有一闲字间隔仍作合论**；只二支而间隔则不能合 |
| 5 | 六合而一支旬空，合力减轻 |
| 6 | 戊日寅月全成东方，**俱以杀论**；戊日卯月全成东方，**俱以官论** |
| 7 | 二卯一戌、二寅一亥，皆**六合之妒合** |
| 8 | 方局中重出（二寅二卯等）见下条 |
| 9 | 寅卯辰见亥字，是**生方之神**；见未字，是**方克之财**——皆非「局混方」 |
| 10 | 亥卯未见寅字是同气，见辰字是财神——皆非「方混局」 |

**第 6 条极重要**：同一片东方木，对戊土日干而言，**寅月论杀、卯月论官**。方合之名不变，十神之实随月令变。这是「不可只看合局名，要落到日干」的典型。

## 八、刑与害：韦千里的降级处理

### 三刑

- 寅刑巳、巳刑申、丑刑戌、戌刑未 —— 三刑
- 子卯 —— 相刑
- 辰、午、酉、亥 —— **自刑**

韦千里的态度值得注意：**「寅刑巳，乃木火相生；巳刑申，巳申本合；丑刑戌、戌刑未，皆属同类之土；子卯相刑，又为水相生。」**

即：**多数所谓「刑」，本质是相生或本合，刑的凶意被他大幅降级。** 这是千里命稿区别于其他命书的一个显著立场——`05_六神喜忌速查.md` 与 `06_岁运断法.md` 里引「刑冲」时，要按这个分量来用。

### 支害

| # | 规则 |
|---|---|
| 1 | 子午冲而丑合子、害午：若子吉午凶，则丑合子**减轻吉力**——「虽害吉，实亦害凶」 |
| 2 | **只两支相害而无冲，于命局上无甚影响** |
| 3 | 两支相害，其一逢合，**以合论吉凶** |
| 4 | 两支相害而地位间隔，**不以害论** |

> 第 2 条是硬话：**没有冲的害，基本可以不断。** 这一条能砍掉市面上大量「害」的无谓恐吓。

## 九、冲合刑害并见：五条优先级

这是补充篇处理冲突的总规则表：

| # | 规则 |
|---|---|
| 1 | **并见以紧贴者为有力**。丑年子月寅日午时：子丑贴、子午隔，**作合不作冲** |
| 2 | **方合 > 局合**；**局合 > 六冲** |
| 3 | 局合三支全，旺支逢冲而紧贴 → **以冲论**；旺支逢冲而间隔 → **以局合论**。局合只二支者亦然 |
| 4 | 局合三支全，**非旺支**逢冲，虽紧贴**亦不以冲论** |
| 5 | **方合见冲，作合不作冲** |

### 实战排序（由强到弱）

```
方合  >  局合  >  六冲  >  六合  >  六害  >  刑
         （并见时以紧贴者为有力）
```

原书例：「（地支）六冲之力，大于六合，故作丑未冲论，不作子丑及午未合论。」「六害之力，小于六合，故作子丑合、午未合，不作丑午害。」

## 十、神煞：韦千里的六种，各有各的分量

千里命稿只取六种神煞，且每一种都写明「忌」什么——这是它比一般神煞书克制的地方。

> ⚠️ **底本校勘**：原书 PDF 第 65 页「文昌之构成」作「丙日见甲，丁日见酉，戊日见申，己日见酉」，「丙日见甲」显系**「丙日见申」之讹**（甲为天干，不当作所「见」之支；且通行程式丙戊同见申）。上表已按通行本订正。引用原文时须知此处底本有讹。

### 驿马的两条关键

- **「驿马逢冲，譬之加鞭，吉则愈吉，凶则愈凶。」**
- **「驿马逢合，等于系足，吉凶皆为羁绊而迟发。」**

### 旬空八则（影响面最广的一条）

1. 逢冲 → 冲力减轻
2. 逢刑 → 刑力减轻
3. 逢合 → 合力减轻
4. 逢害 → 害力减轻
5. **吉神为旬空，其吉虚而不实**
6. **凶神为旬空，其凶虚而不实**
7. 吉运吉年为旬空 → 吉力减轻
8. 凶运凶年为旬空 → 凶力减轻

> 旬空是「减力器」，不是「消失」。断语要写「虚而不实」「力减」，不能写「没有」。

### 神煞使用纪律

⚠️ **本技能的统一纪律：神煞只作形容词，不作断事依据。** 韦千里自己的用法也是如此——天月德、贵人的条目全部写成「增吉减凶」「助吉解凶」，是在已有吉凶上做加减，从不单凭一个神煞断事。详见 `SKILL.md` 第三条纪律。

## 十一、女命淫贱：十四条（原书口径）

> ⚠️ **收录原书条文以备查考，不等于认可其价值判断。** 「淫贱」是民国命书用语，本技能在使用时一律改写为**「婚姻不稳、易生感情纠葛」**，且必须叠加现代语境说明。原文见 `vol_buchong.md` PDF 66—67。

十四条可归为四类：

| 类 | 条目 | 共同机制 |
|---|---|---|
| **日主旺、官星弱** | ①官微无财，日主足以敌官 ②官微伤食重无财，日主足以欺官 ③官弱而日主之气生助他神而去官 ④官弱而官星之气依日主之势 ⑤官轻食伤重，官星无依 ⑥官无根，日主不顾官星而合财星去 | **夫星（官）无力，日主不受约束** |
| **日主弱、食伤重** | ⑦食伤重印轻 ⑧食伤重无印有财 | **泄气太过而无所制** |
| **食伤当令** | ⑨食伤当令，财官失势 ⑩官无财滋，比劫生食伤 ⑪满局伤官无财 | **伤官旺而无财通关** |
| **满局偏枯** | ⑫满局官星无印 ⑬满局比劫无食伤 ⑭满局印绶无财 | **一气独旺而无出路** |

**技术上有价值的部分**：这十四条其实是一套「夫星无力」的检测清单，可用于现代断**婚姻质量**（不论男女）——把「官」换成「配偶星」，逻辑完全成立。第四类则是纯粹的「偏枯无出路」，与男女无关。

## 十二、疾病：五行配五脏，重在「泄」

> 「衡命论疾病宜以五行配五藏。木为肝，金为肺，水为肾，火为心，土为脾。命中水太过或不及，肝必有病……故五行贵和，和则无疾。」

### 核心判准（这一段是整篇最实用的一条）

> 「所谓五行和者，**非生而不克、全而不缺之谓**，乃贵乎**泄其旺神、泻其有余**也。盖有余之旺神泻，不足之弱神受益矣。**若强制旺神，寡不敌众，触怒其性，旺神不能损，弱神反受伤矣。** 是以旺神太过者宜泄，不太过者，方宜克耳。」

这条直接推翻「缺什么补什么」的民间思路：

| 民间说法 | 韦千里正解 |
|---|---|
| 缺木补木 | 看旺神是谁，**泄旺神**才是「和」 |
| 太过就克 | 太过宜**泄**；只有不太过才宜克 |
| 五行俱全即好 | 「非全而不缺之谓」——全而偏枯一样有病 |

## 十四、性情：五行的八类判词

### 基础

> 「木主仁，火主礼，金主义，水主智，土主信。八字中五行不戾，中和纯粹，则有恻隐谦让敦实之情。若偏枯混浊、太过不及，则有是非乖逆骄傲之性矣。」

### 五行太过无制

| 五行多 | 性情 |
|---|---|
| 火多无制 | 急躁而欠涵养 |
| 水多无制 | 聪颖而意志不坚，亦且好动 |
| 木多无制 | 情重而仁厚 |
| 金多无制 | 精干而敏锐 |
| 土多无制 | 敦厚而好静 |

### 八类模型（每一日干皆可套）

原书给金、木、水、火、土五个日干各列八类，格式统一：

| # | 类 | 含义 |
|---|---|---|
| 1 | **旺相** | 得中和之正 |
| 2 | **太过** | 本气过盛 |
| 3 | **不及** | 本气过衰 |
| 4 | **金多** | 他神偏盛 |
| 5 | **木多** | |
| 6 | **火多** | |
| 7 | **水多** | |
| 8 | **土多** | |

例（金日干）：

- 旺相：誉高义重、体健神清、威武刚烈、临事果决
- 太过：尚勇无谋、多欲损刚、刻薄内毒、喜淫好杀
- 不及：思深决少、事多挫志、性虽好义、为之不终
- 金多：刚直尚勇、见义必为、过不自知、思礼好胜
- 木多：辨分曲直、利害兼资、置德怀念、朋友失意
- 火多：口才辨利、好礼寡义、动止宽和、心中鄙吝
- 水多：计虑不胜、为人无恩、临事龌龊、或是或非
- 土多：无中有成、口俭心慈、作为暗昧、多处嫌疑

其余四干的完整八类见 `vol_buchong.md` PDF 67—68。

### 身强身弱的性情二分（更好用的模型）

| 类型 | 判词 |
|---|---|
| **身强有抑** | 天性明白、豁达大度、顺物而动、遇事能断、常欢乐、好施与、多情多义、不畏不疑 |
| **身强无抑**（又不成外格） | 残暴好斗、性气无常、不自检束、不顾危亡、当恶侮善、持强凌弱 |
| **身弱有扶** | 生性俭约、不忘设施、深机密虑、寡合少遇、多疑忌、拘礼节、言行相顾、仪貌整饬 |
| **身弱无扶**（又不成外格） | 淫邪虚为、拘缩执拗、矜奇炫异、多非少是、萎靡怠惰、作事无断 |

**关键在「有抑／无抑」「有扶／无扶」这个二分**——同样是身强，有抑者是豪杰，无抑者是暴徒。断性情先看有没有制，再看强弱。

> 原书自注：「按推断性情，其法多端，尤非学理与经验合参，难得精确。且有可以意会、难能言传者，乃贵乎活看，而不可拘泥也。」

⚠️ **断性情必须标明「概率性描述」，不可写成定论。** 原书自己都说「可以意会，难能言传」。

## 十六、官杀并见：混杂与去留

### 影响八则

1. 日主喜克，官杀并见 → **吉力加增**
2. 日主忌克，官杀并见 → **凶力更显**
3. 用正官见杀混杂 → 八字不清，主多磨折
4. 用七杀见官混杂 → 命局淆乱，亦主奔波
5. 用官而杀混，有去杀之神 → 凶而不凶
6. 用杀而官混，有去官之神 → 凶而不凶
7. 用官而杀混，无去杀之神 → 凶不可免
8. 用杀而官混，无去官之神 → 亦以凶论

### 喜忌六则

| 条件 | 判 |
|---|---|
| 身弱有印 | **喜**官杀并见 |
| 身强有财 | **喜**官杀并见 |
| 身弱无印 | **忌**官杀并见 |
| 身强有伤食而无财 | **忌**官杀并见 |
| 忌官而幸有伤官制，又见七杀 | 忌 |
| 忌杀而幸有食神制，又见正官 | 忌 |

### 去留十三则（可用部分）

| # | 规则 |
|---|---|
| 1 | 嫌混杂者，先谋去之之道；**一者既去，一者自留** |
| 2 | 爱其互相协助者，**不必议去留，听其自然** |
| 3 | 只有**食神** → **去杀留官** |
| 4 | 只有**伤官** → **去官留杀** |
| 5 | 食伤并见 → 官杀**皆可去净** |
| 6 | 甲日见辛官庚杀，又有丙火合辛 → **合官留杀**（合者绊也，绊亦可去） |
| 7 | 甲日透庚杀又支见酉金 → 庚杀乘旺，**不作官杀混杂，不必议去留** |
| 8 | 按日干列「以某去某」的具体地支（如甲乙日见申酉，以巳去申、以寅去申……） |
| 9 | 三合改变当权者：戊己日见寅卯又遇午戌 → 寅合午戌成火，**卯独当权** |
| 10 | 合入库改变当权者：丙丁日见亥子，若子随辰合入库 → **亥当权** |
| 11 | 庚辛申酉并见，足可以去一甲一乙一寅一卯，亦可去甲寅乙卯；若一庚一申一辛一酉，去甲乙寅卯**势必不能** |
| 12 | 官杀并见且食伤并见：**伤官较有力则去官，食神较有力则去杀** |
| 13 | 阴日伤官可去官又可合杀（贴近官则去官论，贴近杀则合杀论）；阳日食神可去杀又可合官；**阴日食神只可去杀不能合官，阳日伤官只可去官不能合杀** |

**第 3、4 条是全篇最好用的一句话**：食神制杀、伤官伤官——方向是固定的，不是看谁强。第 13 条则是一条细密的分辨，阴日食神无法合官，很多人会搞错。

## 十七、燥湿：地支的隐性属性

天干五行**无分燥湿**，地支**昭然有别**。这条在断「需水需火」时最有用。

| 支 | 所藏 | 属性 |
|---|---|---|
| 子 | 癸 | 纯水，无燥湿之分 |
| 卯 | 乙 | 纯木，无燥湿之分 |
| 酉 | 辛 | 纯金，无燥湿之分 |
| 丑 | 己辛癸 | **湿**土湿金（有癸水） |
| 寅 | 甲丙戊 | **燥**木燥土（有丙火） |
| 辰 | 戊乙癸 | **湿**土湿木（有癸水） |
| 巳 | 丙戊庚 | **燥**火燥土燥金（有丙火） |
| 午 | 丁己 | **燥**土（有丁火） |
| 未 | 己丁乙 | **燥**土燥木（有丁火） |
| 申 | 庚壬戊 | **湿**金湿土（有壬水） |
| 戌 | 戊辛丁 | **燥**土燥金（有丁火） |
| 亥 | 壬甲 | **湿**木（有壬水） |

### 用法

> 「命局亢燥，则喜润泽；命局潮湿，则喜暄燠。」
> - 无水或少水、值夏令、多木多火 → **亢燥之局**。命中喜土，逢**湿土**则得滋，上加吉；逢燥土则益燥，未必佳妙。
> - 无火或火少、时在冬令、多金多水 → **潮湿之局**。命中喜土，逢**燥土**则去湿，花添锦上；逢湿土则更湿，未易言吉。

**这是「用土」时到底用辰丑还是用未戌的判据。** 只说「喜土」而不分燥湿，等于没说。

## 十九、五行生克衰旺颠倒（补充篇最深的一段）

这一节讲的是**生克关系的反转**，是全书理论层次最高的部分。

### 生之反转：本生而实不生

| 原句 | 解 |
|---|---|
| 木本生火，**木多火炽**；有金克木，则可生火矣 | 木太多反而把火逼成灾，要克木 |
| 火本生土，**火多土焦**；有水克火，则可生土矣 | |
| 土本生金，**土多金埋**；有木克土，则可生金矣 | |
| 金本生水，**金多水弱**；有火克金，则可生水矣 | |
| 水本生木，**水多木浮**；有土克水，则可生木矣 | |

模式：**A 生 B，但 A 太多时 B 反被伤，须克 A 才能救 B。**

### 生之反转第二型：被生者太旺反伤生者

| 原句 | 解 |
|---|---|
| 木本生火，**火多木焚**；水克火则生木，火生土则存木也 | |
| 火本生土，**土重火熄**；木克土则生火，土生金则存火也 | |
| 土本生金，**金多土泄**；火克金则生土，金生水则存土也 | |
| 金本生水，**水泛金沉**；土克水则生金，水生木则存金也 | |
| 水本生木，**木旺水涸**；金克木则生水，木生火则存水也 | |

**「火生土则存木」** 这种句式尤其要留意：**给被生者找出路，就是保生者。** 这是「通关」思想的另一面。

### 两旺者的调停

| 局 | 宜 |
|---|---|
| 木火两旺 | 宜**水**以养木 |
| 火土两旺 | 宜**木**以养火 |
| 土金两旺 | 宜**火**以助土 |
| 金水两旺 | 宜**土**以生金 |

### 反向相生（克中带生）

> 「木能生火，然**火亦能生木**也。水生木者，润地之燥也；火生木者，解天之冻也。」

逐条：

- 火生木：解天之冻
- 土生火：夏土之燥（木生火者，冬木之枯也）
- 金生土：防土之倾（火生土者，去地之湿也）
- 水生金：制火之烈（土生金者，砥水之溢也）
- 木生水：去其淤塞（金生水者，阻其泄漏也）

**即：生我者不只一个。** 冬木枯，火能生木；夏土燥，木能生火。「五行相生」在具体时令下是双向的。

### 克之反转

| 原句 | 解 |
|---|---|
| 木本克土，**土多木折**；水生木，则木能克土 | 被克者太多，克者反伤；须先扶克者 |
| 火本克金，**金多火熄**；木生火，则火能克金 | |
| 土本克水，**水多土荡**；火生土，则土能克水 | |
| 金本克木，**木多金缺**；土生金，则金能克木 | |
| 水本克火，**火多水涸**；金生水，则水能克火 | |

### 克之调停

| 局 | 宜 |
|---|---|
| 木克土，土太多 | 宜**金**以卫土 |
| 火克金，火太多 | 宜**水**以养金 |
| 土克水，水太多 | 宜**木**以纳水 |
| 金克木，木太多 | 宜**火**以荣木 |
| 水克火，火太多 | 宜**土**以扶火 |

### 两旺者的调停（克）

| 局 | 宜 |
|---|---|
| 木土两旺 | 宜**水**以润土 |
| 水土两旺 | 宜**火**以湿水 |
| 水火两旺 | 宜**金**以熄火 |
| 火金两旺 | 宜**木**以缺金 |
| 金木两旺 | 宜**土**以折木 |

### 反向相克（生中带克）

> 「木能克土，然**水亦能克木**也。木克土者，春土之柔也；土克木者，夏土之燥也。」

逐条：

- 木克土：春土之柔（春土松软易被木克）
- 土克木：夏土之燥（夏土干硬反能伤木）
- 土克水：夏水之涸
- 水克土：冬水之冻
- 水克火：金水寒凝
- 火克水：杯水车薪
- 火克金：春火之相
- 金克火：冬火之囚
- 金克木：金坚木冻
- 木克金：木盛金脆

**「克」在具体时令下也是双向的。** 这一整段是千里命稿对「死记生克」最有力的反驳。

### 最后两条总纲（极其重要）

> **「旺者宜克，然旺之极者，宜泄而不宜克也。所谓实则泻其子。」**
> 春木森森 → 宜火旺以通耀；夏火炎炎 → 宜土多而敛威；秋金锐锐 → 宜水盛以流清；冬水洋洋 → 宜木众而纳势；季土叠叠 → 宜重金以吐秀。

> **「弱者宜生，然弱之极者，宜克而不宜生也。所谓虚则补其母。」**
> 秋木凋落 → 宜金而不宜水；冬火熄灭 → 宜水而不宜木；仲春之土无火生，反宜木；仲秋之土无火生，反宜金。

⚠️ **这两条与原书引的「实则泻其子，虚则补其母」字面上是反的**，原书原文如此。技术与第十二节疾病条「旺神太过者宜泄，不太过者方宜克」可以互证，但**「虚则补其母」四字与其后例证不合，疑为引用错位或排印脱误**。引用时建议只引结论句：**「旺之极者宜泄不宜克，弱之极者宜克不宜生」**。

实务上这条门槛极高，**只在极端偏枯之局才用**。用时必须在断语里写「此为极旺（极弱）之局，故用反法」，否则读者会认为你断反了。

> 收尾一句：「阳之极者，阴至也；阴之极者，阳至也。寒极则热生也，热极则寒生也。」

## 二十一、容易读错的地方

| 原文 | 易错读法 | 正解 |
|---|---|---|
| 「寅申巳亥容积最广」 | 以为力量最大 | 指所藏三干、气杂，故冲则两败俱伤 |
| 「子午未属阳……故作阴论」 | 按字面当阳干用 | 体阳用阴，**按阴论**；巳亥反之 |
| 「阳往往不克阴，作干合论」 | 以为阳绝不克阴 | 「往往」，非绝对；须看是否成合 |
| 「合者并去而两有所绊」 | 以为只绊一方 | **双方同时失去原功能** |
| 「他干逢合不能化」 | 忽略宾主 | 只有**日干**逢合才可化 |
| 「甲日逢己运，应以正财论」 | 岁运可化 | **岁运不作化论** |
| 「只两支相害而无冲，无甚影响」 | 仍然大断害 | 没有冲的害基本不断 |
| 「三刑」 | 一律当凶 | 原书明言多属相生或本合，凶意大降 |
| 「神煞」 | 凭一个神煞断事 | 只作加减，不作主断 |
| 「旺之极者宜泄不宜克」 | 与「虚则补其母」字面矛盾而改原书 | **原书原文如此**，限定极旺极弱之局 |
