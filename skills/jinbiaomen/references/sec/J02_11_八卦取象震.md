# 八卦取象·震

震:
震卦卦德为奋励，起也。表示阳刚在下不愿被淫那所压制，而奋起之状。表示不
愿墨守成规，不甘落后，勇往直前。故“万物出乎震”，震为激 发性，主动性。
象意:
震为疾 〈快，激烈) :
震与乾组合，乾为大，表示十分的快，十分的激烈
震与侈组合，兔为小，表示有点快，有点激烈，竞为毁折，表示快而易有损坏。
震与离组合，离为美丽，表示快而美丽，离为电，表示像电一样快，激烈，离为
中虚，表示快而没有发辰后劲。
震与震组合，震为雷，表示像雷一样快，激烈，震为向上发辰，表示快而蒸燕日
上;， 震为果，表示快而没有结果，震为过，表示快，激烈而有过失，震为鲁莽，表示
快而鲁莽，震为鸣，表示激烈而动静很大。
震与虹组合，吕为风，表示像风一样快，激烈，吕为犹疑不决，表示快而有所顾
虑; 吕为巧，表示快而巧妙，顺势而行，典为迷，表示快而容 易迷失。
震与坎组合，坎为思想，表示脑子转的很快，急中生智，变幻莫测，天马行空;
坎为劳苦，表示激烈但劳苦;坎为曲，表示激烈而曲折;坎为变，表示快而有变化。
震与民组合，民为阻，表示快但是有阻碍，民为终止，表示快到了极点，要减速

震与坤组合，坤为虚，表示快而不实，快不起来。
