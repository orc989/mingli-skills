## 四、每日学习包格式（我给你的形态）

每课固定五段，控制在一屏以内，方便每天真读得下去：

```
【第 N 课 · 书名 · 篇名】
① 原文摘句（1–3 句核心）
② 白话直译（不绕术语）
③ 关键概念（1–2 个，讲透）
④ 实战怎么用（落到断命动作）
⑤ 自测一问（答不上来就回看）
```
