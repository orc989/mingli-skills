# 穷通宝鉴 · 调候用神体系

## 这本书到底是什么

**一句话**：把十个日干分别放到十二个月里，逐格诊断「这个命的气候病灶是什么」，然后开药。

- 全书 **120 格**（12 月 × 10 日干），每格 = 一句用神口诀 + 原文 + 徐乐吾评注 + 命例。
- 唯一的方法论是**调候优先**：冬用丙、夏用水，不因日主强弱而改。这与《子平真诠》的格局法、
  《滴天髓》的旺衰法是三条不同的路。
- 成书链：明《栏江网》→ 清初《造化元钥》→ 光绪余春台《穷通宝鉴》→ 1930s 徐乐吾评注 → 1957 韦千里序本。

**它的长处**：断语爽利，不含糊；体系整齐，120 格一查即得。
**它的短处**（韦千里序自陈）：原作者文笔不通顺，转辗抄录错字百出，徐评有牵强附会处。

## 三条硬纪律

### ① 先定月令，再定日干，不可倒序

这本书的索引是「**月令 × 日干**」，不是「日干喜什么」。
「甲木喜庚」这种说法在穷通宝鉴里是不成立的——正月的甲木要丙癸，七月的甲木要庚丁，
同是甲木，药方完全不同。

> 若用户只给了日干没给月令，**必须先问月份（以节气定，不是农历）**，不能凭日干直接给用神。

### ② 调候用神与格局成败是两件事，不可混说

穷通宝鉴只回答「这一格缺什么」。
它**不回答**「这个八字成不成格」「能不能发」「几时发」——那些是《子平真诠》《千里命稿》的活。

> 断语里可以说「此造丙透癸藏，合正月甲木『寒木向阳』之格」，但不能说
> 「因此必富贵」——底本的命例断语是**名家命造的事后追述**，不是可外推的规则。

### ③ 原文、徐注、白话评注三层必须分开

底本（1957 韦千里序本）里，「按」字段是徐乐吾（或整理者）的评注，与余春台原文混排。
现代白话评注本（方先生评）又是第三层，且立场常与徐注冲突。

> 引用口诀时说「《穷通宝鉴》」；引用评注时**必须说「徐乐吾注」**；
> 引用白话本时**必须说「白话评注本」**，不可写作「穷通宝鉴云」。

## 五步取用流程

```
① 排掉不能论从化的 → ② 定节气段 → ③ 判病灶 → ④ 查用神次序 → ⑤ 判透藏有根
```

### ① 先挡掉特殊结构

月令是日干的**临官、帝旺**（甲寅卯、丙巳午、庚申酉、壬亥子）→ 一律按身旺用克泄，**不论从格**。
月令死绝而全局一边倒 → 才考虑从财／从杀／从化。
专旺格须五行的气势纯而不杂，杂一位即破。
化气格须月令有化神之根（甲己化土须见辰）。

### ② 定节气段（不是农历月份）

| 月建 | 分界 | 界线前 | 界线后 |
|---|---|---|---|
| 寅 | 雨水 | 初春余寒，丙癸并用，丙为主 | 仲春木旺，先庚次丁 |
| 辰 | 谷雨 | 与二月同看 | 土旺用事，阳壮木渴 |
| 午 | 夏至 | 阳盛，先癸次丙 | 阴生，三伏生寒，丙癸俱尊 |
| 未 | 大暑 | 同五月 | 金水进气 |
| 戌 | 霜降 | 同八月 | 土旺用事 |
| 子 | 冬至 | 阴盛 | 一阳来复，弱中生旺 |
| 丑 | 朔望 | 上半月癸辛主事 | 下半月己土主事 |

### ③ 判四类病灶

| 病灶 | 典型表述 | 用药 |
|---|---|---|
| **寒** | 余寒、严寒、冻木 | **丙**（唯一解，丁是灯烛不能解冻） |
| **燥** | 木性虚焦、火炎土燥、阳壮木渴 | **癸 ≻ 壬**（须庚辛为源） |
| **湿** | 湿乙伤丁、湿泥寒冻、水泛木浮 | **戊 ≻ 甲 ≻ 丙** |
| **塞** | 木多火塞、土厚埋金、己土浊壬 | **庚 ≻ 甲 ≻ 壬** |

### ④ 查 `references/01_调候用神总表.csv`

120 行，列：月份 / 日干 / 首选 / 次选 / 再选 / 所忌 / 底本首句。

三列是**主次**不是并列：
- 首选缺则格不成（三月甲木无庚 = 钝斧无钢）
- 次选是配合（三月甲木之壬，为泄庚润木）
- 再选是救应（四月甲木之庚，为调和癸丁）

「所忌」是硬约束（三冬己土忌癸、十一月辛金忌癸、五月戊土忌癸）。

### ⑤ 判透藏与有根

1. **透干 vs 藏支**：藏支力薄，透干显达。
2. **有根**：用神须有生它之神。「壬透，庚辛亦透，壬水有根，科甲无疑」；无源之水则「不过秀才小富」。
3. **不相碍**：「丙癸并透，名为不晴不雨」——两味药不能互相克伐，中间要有通关之神。

## 常见误用（按后果排序）

| 误用 | 后果 | 正解 |
|---|---|---|
| 只给日干就问用神 | 全错 | 缺月令不可答 |
| 用农历月份代替节气 | 边界格错（正月雨水前后是两个方案） | 一律以节气 |
| 把「用X者，Y妻Z子」当取用依据 | 倒因为果 | 那是用神已定后的六亲推演 |
| 把 1029 条命例当统计样本归纳 | 结论不可靠（名家命造成分不纯，断语多为事后追述） | 命例只作「验证口诀」的证例 |
| 把白话本的「方先生曰」当徐注引 | 张冠李戴 | 三层分开，详见 `06_校勘须知.md` |
| 认为 120 格每格都有独立口诀 | 20 余格没有（合并标题），误以为脱漏 | 见 `05_版本源流与分歧.md` 第四节 |

## 已知局限

1. **OCR 状况**：华龄本（邓同注）、白话本（920 页）已完成 OCR，质量中等（形近字多）；
   梁湘润评注本是 **黑底白字的石刻体扫描**，OCR 完全不可用，本技能只保留其书目信息与版本位置，
   **不提供梁评内容**。
2. **合并标题格**：正二月甲木、五六月甲木、三秋丁火、三冬丁火、正二三月戊土、十一二月戊土、
   三秋己土、十月十一月十二月己土，共 20 余格在底本中合写，逐月差别需从行文里辨。
3. **用神互斥的格**：约 20 余格的首选与次选相克（丙壬、丁癸），底本只以「不相碍」「有间隔」
   含糊带过，实际判断歧义很大，须结合全局，不宜给唯一答案。
4. **不论六亲、不论女命、不定寿夭**：底本除命例按语外，无此类内容。
