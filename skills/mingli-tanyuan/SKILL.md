# 命理探源 · 八字判断技能

## 这是什么

袁树珊《命理探源》八卷体系的可执行版本。共 **241 页正文、8 卷、约 130 个小节**，已全部 OCR 并按卷切成 8 个正文文件。

**关键前提**：底本是一份**无文字层的扫描 PDF**，经 OCR 得到。能读懂大意，**不能引用原文**。见 `references/05_引文校勘须知.md`——引用前必读。

## 三条硬纪律

1. **时辰未确认，不做六亲断。**
   时柱是子女宫，也是「分刻取用神」的落点（卷四「论生时法」明说「寅时一二刻丙火用事、三四刻戊土、后四刻甲木」）。时辰错一小时，子女数与性别判断基本必错。
   跨时区、23:00—24:00 出生、时辰卡在交界者，先处理校时（`references/02_四路判法.md` 第 2 节）。

2. **每条断语必须标层级：原局 / 大运 / 流年 / 命宫小限。**
   原书自己在卷五把「命为体、运为用」讲得很清楚，从不混说。混说就是失效。
   格式示例：`【原局】……；【乙运】……；【丙午年】……`

3. **神煞只作形容词，不作主语。**
   卷三收了 22 个神煞，但卷六「论星煞无关格局」已明说「命之格局星辰是不起什么作用的」。
   凡「因带羊刃所以凶」「因带咸池所以淫」这类句子，一律改写成「因原局如何，故于某运某年触发；羊刃只是其象」。

## 使用方式

### 场景 A：给一个八字，要判断
1. 先确认时柱（纪律 1）。不确定就明说不确定，并给出两盘并推的结果。
2. 走 `02_四路判法.md` 的五步。
3. 每条断语标层级（纪律 2）。
4. 找同类命例校准：查 `01_润德堂命例索引.csv`，看是否有同天干同季节的实例，读 `vol_gaocun.md` 对应页袁树珊怎么批。

### 场景 B：要查某个具体规则
1. 查 `00_mulu_章节索引.csv` 的「章题」列，定位到 PDF 页。
2. 打开对应的 `vol_*.md`，按 `## PDF 第 NNN 页` 标题跳转。
3. 若涉及诸家分歧，先查 `03_流派分歧清单.md` 拿采信建议，不要直接照抄原文。

### 场景 C：要引用原书原文
**先读 `05_引文校勘须知.md`**，按其中「引用前必做的三步」走。不可跳过。

### 场景 D：要排盘/校时/推大运
查卷二（`vol_tuiming.md`）。注意：**卷二的大运排盘表在 OCR 后已损坏**，只能取方法不能取表。

## 与原书立场一致的表述原则

卷八「议论」反复申说：**命与力相辅、命与相须而成、有命无力则候时**。

所以：
- 断凶不断死。判出凶运，说「此十年宜守、宜退、宜转换方向」，不说「必有灾祸」。
- 断贵不断必贵。判出贵格，说「此格有可为之资」，同时指出「须岁运配合」。
- 遇贫困难堪者，「虽命当富贵亦须留余地」（星家十要·济贫）。
- 遇贞妇节夫，不可妄断「伤官克夫」（星家十要·节义）。

这不是道德姿态，是**原书的方法论要求**：只讲命不讲力，即违背《命理探源》的立场。
