# 攻成润从暖

攻、成、润、从、暖也。
    说的是金木相战有五种取用神的方法。攻是克制的意思，成就是生的意思，润就
是用水的意思，比如生在夏天的要用水，从就是从格的意思，暖也是气象上取用的意
思，比如生在冬天的，需要用火暖局。
    一共有基本五种模型
    1 春初之木，木嫩金坚，火以攻之
    例：庚 丙 木 X
      申 寅 X   X
    木生在初春，也不一定非得出春，主要的意思木弱的，但是有根，金旺的，金旺
克木，这时用神最好是用火，用火克金，用水日主就更旺了，所以用火，但是得有根
或者有气，没根没气，或者太弱的，火也会泄日主太过。这个就是用火制金为用神的。
这种也就是用食伤的。

                     辛丑年弟子班中册

      2、仲春之木，木旺金衰，土以成之
      例：土 庚 木 X
        土 卯 木 X
      这种是木旺，木生在春天，同根月令，而且木还特别旺的，这时金就休囚无力了，
木旺就得克制，或者泄，因为咱们这个说的是金木局的关系，所以肯定是用金，金弱
就得用土来生金，让金旺起来，来制约旺木，以达到平衡的目的。这种是用金喜土的。
这种也是用官杀的。
      3、夏令之木，木泄金燥，水以润之
       例：庚 水 木 X
          X   午 X   X
      夏天的木，木生在夏天的，火是泄木的，火势太旺，并且还燥热，金也不能用，
这时候需要用水，用水通关金和木，生身，金生水，水生木，然后水还起到降燥热的
作用，也就是气象上的调节。所以说用水以润之。这种就是金木相战用水的，也就是
用印的。
      4、秋令之木，木凋金锐，土以从之
      例：X 庚 木 X
        金 申 土 土
      木生在秋天，木太弱，金太旺，旺极的，这时候木没根没气休囚的，用水没有，
用火也没有，就只能从金的气势了，不能用帮扶了，只能从了，这种也是用土和金的。
所以说土以从之，意思就是用土生金。
      5、冬令之木，木衰金寒，火以暖之
      例：X 庚 木 丙
        X 子 木 X
      这个是木生冬天的，太寒了，需要用火暖局，金生水，水生木，木又生火。所以
生在冬天的木要首先考虑用火暖局，这种就是就是太寒需要火的，就是用火的。
      大家不要执着于这个模型，这些模型都是假设的，实际还得看其他四柱的配合，
咱们主要是用模型化的方式给大家解读这个意思，这种比较直观，便于记忆，同时理
解还深刻。
      例：丙 庚 甲 乙
        寅 寅 申 丑

       攻、成、润、从、暖必须记住了

      坎离
      坎离宰天地之中气，成不独成，而有相持者在
      坎为水，为北方，离为火，是南方，之前说的震兑是对立的关系，那么水与火也
是一种对立的关系，那么在讲震兑的时候，主要说的是震兑在每个季节上取用特点，
以前咱们也说过，月令的重要性，它的本质还是通过月令来看八字中每个五行的旺衰，
然后找出取用神，实际上坎离也是一样，但是区别在于坎离在气象上不需要在考虑寒
暖的问题。本身水与火在同一命局出现，在气象上本身就解决了寒暖的问题。
      所以水和火这种关系不光是对峙，对立，也是一种在相互配合以达到发育万物的
作用。坎离与震兑本质上还是要有区别。坎离宰天地之中气，天气，地气分别指的天
干和地支。坎离就是调和的中气。说的就是用水火调解天干，地支的平衡问题。要同
时平衡的存在，才能生发万物。
      同样水火相持也有 5 种基本取用神的模型，分别是升，降，和，解，制。
      1、升，天干火弱，地支水旺，必须地支有木，木化水生火，上地支克天干转而相
生，这就是所谓的地气上升
      火 X 火 X
      木 水水 X
      天干火弱的，地支水旺，火在地支没有根，必须地支要有木，用木化解地支的旺
水，木起了化解水的作用，然后把力量传导到天干的，让火旺起来，没有木，水火就
相战了，就不是相持了，也就不能调节天干与地支了。
      2、降，天干水弱，地支火旺，必须天干有金，金生水，金能耗火，这样天干的水
就有力量克地支的旺火克，这就是所谓的天气下降
      金 水 水 X
      X 火 火 X
      天干水弱，地支火旺，水弱无根无气，水没有力量克制不住旺火，所以必须天干
有金，金是水的源头，生水助力，这样水就有力量克制旺火，五行平衡。
      3、和者，天干全是火的，地支全是水的，必须用木运调和天干，地支的相战。
      火 火 火 火
      水 水 水 水

  4、解者，天干全是水，地支全是火，必须有金运生水泄火这样才能解决水弱的情
