# 校勘须知

## 零、底本情况

本 skill 所用底本为《五行精纪》（题宋·廖中撰）纯文本电子本，34 卷全，正文约 18.3 万字，已按卷与篇切分为 69 个文件（`references/sec/`）。

**好消息**：这是**文字层文本，不是 OCR**，因此没有扫描件常见的整句崩坏、字序颠倒、标点全失等问题。

**坏消息**：底本经过至少一次人工录入与转码（原文件为 GB18030 编码、CRLF 换行），存在**系统性形近字混用**、**引书名异写**，以及**底本编者夹入的批注**。使用前必须知道以下六条。

---

## 一、形近字混用（最高频，务必先过一遍）

### 1. 己 / 已

全书「己巳、己卯、己丑、己亥、己酉、己未」六组，正文中误作「已」者共 **22 处**：

| 正 | 误作「已」的次数 |
|---|---|
| 己巳 | 2 |
| 己卯 | 5 |
| 己丑 | 3 |
| 己亥 | 5 |
| 己酉 | 3 |
| 己未 | 4 |

正确写法共 454 处，误写 22 处，**占比很小但分布零散**。典型如卷一：

> 甲寅自病之水，**已卯**自死之水……（应为「己卯」）

**处理原则**：凡见「已＋地支」，一律读作「己＋地支」。干支里没有「已」这个天干。

### 2. 戌 / 戍

「戌」（地支）653 处，「戍」（戍守）89 处。**在本书语境里，几乎全部「戍」都是「戌」之误**：

> 亥子(水)寅卯(木)巳午(火)申酉(金)辰**戍**丑未(土)　（卷六，应为「戌」）

「戍」只在「戍守、征戍」等词中才成立，而本书极少这类词。**见到「戍」先按「戌」读，再回看上下文有无例外。**

### 3. 剋 / 克 / 尅

三者并存：克 368、尅 149、剋 58。**均为「克制」之意，无义差别**，是录入时未统一。引用原文时不必改，但检索时三个字都要试。

### 4. 其他零散形误

- 「煑」「煮」；「菴」「庵」；「閒」「闲」——底本新旧字形混用，不影响文义。
- 数字「二」「两」混用（「二重福」「两重福」并存）。

## 三、底本编者批注（不是原文，引用时须剔除）

底本录入者随手加了三类批注，**均非《五行精纪》原文**，引用时务必删除：

### 1.「（ps：……）」形式（5 处）

| 位置 | 原文 | 编者批注 |
|---|---|---|
| 卷六 论支神 | （三命吟） | （ps：吟原为金和今，也查不到） |
| 卷六 论支神 | 又*山如老庚辰年 | （ps：*为足和束这个字怎么都查不到） |
| 卷七 论五行一 | 到已（ps：怀疑实为巳）酉丑 | 批注本身也有错：「已」应为「己」，「巳」是地支 |
| 卷十八 论食神 | 甲食丙（这里的顿号都应该是逗号，逗号才能突出强调） | 纯属录入者意见 |

> 注：卷七那条批注说「怀疑实为巳」，但「巳酉丑」正是三合金局，原文无误，批注正确；只是批注把天干「己」误作「已」，与它要纠正的对象犯了同一个错。

### 2.「【？】」形式（3 处）

底本遇到无法辨认的字，用【？】占位：

| 位置 | 原文 |
|---|---|
| 卷廿八 释小儿例 | 卯併辰【？】巳申知 |
| 卷卅一 论疾病 | 少年主多【？】疖之患 |
| 卷卅三 论大运 | 小满后【？】麂相溷 |

按文义推测：论疾病处疑为「疮」或「痬」；论大运处疑为「麋」（麋鹿，与上句「众鸟成群」对文）。**引用时保留【？】并注明原缺，不要臆补。**

### 3.「【X】」形式的校正字（十余处）

底本用【】标注「编者认为应改之字」，例如：

| 位置 | 原文 |
|---|---|
| 卷十三 | 更兼恶杀来临着，父母如何得不忧。又歌云：……十二同三定五【关】 |
| 卷卅 论形貌性情 | 手足【纤】腻 |
| 卷卅一 论疾病 | 少年主多【？】疖之患 |
| 卷十七 论官神 | 会不知其五行克纳音者为真官（无【】，但同段有「【变鬼为官杂格】」标题） |

**这类【】与书中小节标题的【】形式相同，须靠上下文区分**：小节标题【】内是名词性短语（如【十干例】【天乙贵神】），校正字【】内是单个字。

## 四、正文中的「衍字、脱字、错简」

### 1. 明显脱字

- 卷十九 论进神：（壶中子）「遇(疑此处丢退字)则智识暗昧之人也」——底本自己标出「疑此处丢退字」，可从。
- 卷廿五 论三刑：「刑有四种」而下文只详述无礼刑、无恩刑、恃势刑三种，第四「自刑」另在段末补叙（「辰、午、酉、亥、各自刑」），非脱文，是编排如此。

### 2. 明显衍字

- 卷廿四 论亡神：「亡神官符与劫杀对冲是也」——「官符」前疑衍「亡神」二字（下文即云「亡身杀者……亦名官杀符」）。
- 卷三 论干神一：「甲乙木丙丁火戊己土庚辛金壬癸水」——此行为【十干例】的正文，非衍文，但无标点易被误认为标题。

### 3. 错简

- 卷二《释六十甲子吉凶例》表中，「庚申」条下缺「性质」三字（仅存「庚申」二字，直入神煞），与全表体例不合，疑脱。
- 卷二表中「庚辰」条作「榴花」，而庚辰纳音为白腊金，与上下文皆言金者不合，疑为「榴花」当属他柱而错入。

### 4. 引文内嵌注

本书大量出现「某某云：……（注云：……）」的嵌套，以及「（并某书）」的括注体例。**「并」＝「以上数条并出此书」**，不是人名：

> ……（并广信集）＝以上诸条都出自《广信集》

这一点在切分时要留意：一个「（并某书）」往往管前面好几段。

## 五、标点与断句

底本已有标点，但存在两类系统性问题：

### 1. 句中逗号断在词中间

由于原文本按固定宽度硬折行，折行处常插入逗号或直接断开：

> 天元变化书云：天干合，阳得阴合福慢，因得阳合福紧，故甲得己合为财，己得甲合为官
> ，十干倣此。

上例第二行开头的「，」是折行残留。本 skill 已按行合并，但**未强行重排标点**（避免二次致误），因此阅读时须留意行首以逗号、句号开头的情形。

### 2. 顿号与逗号混用

底本录入者对不同标点的使用并不严格，尤其列举干支时：

> 甲食丙、（这里的顿号都应该是逗号）乙食丁、丙食戊……

此处底本留有编者批注，已列入上文。

## 六、使用建议

1. **先查表再读原文**：用 `02_纳音六十甲子表.csv`、`03_神煞起例表.csv` 定位，避免在 18 万字里盲搜。
2. **检索时多字形并用**：己／已、戌／戍、克／剋／尅、玉霄／玉宵／玉箫，全部试一遍。
3. **引用必标卷次与篇目**：本书同名篇目多（如「论财」在卷十九，「论库墓」亦在卷十九），只标篇名不足以定位。
4. **遇到（ps：…）、【？】、单字【X】即为底本批注或占位，引用时剔除或注明原缺**。
5. **本书是辑录体**：同一问题在不同卷可能给出不同答案（因来源不同）。不要强行统一，先辨明所引何家。
