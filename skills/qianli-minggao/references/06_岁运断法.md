# 06 岁运断法

> 对应原书：**运限篇**（PDF 45—49）、**流年篇**（49—50）、**月建篇**（50）
> 底本：`references/vol_yunxian.md`、`vol_liunian.md`、`vol_yuejian.md`
> 本文是八步评断法**第⑤步「查岁运」**的作业手册。

---

## 一、总原则只有一句

> **「利于用神者，为善运；不利于用神者，为恶运。」**

大运、流年、月建，三者用的是同一把尺子——**对用神有利还是不利**。区别只在层级与权重。

但原书立刻给这把尺子加了缓冲：

> 「利于用神之运，而被柱中他神克去或合住者，**善而不善，但亦不恶，平庸而已**。」
> 「不利于用神之运，而被柱中他神克去或合住者，**恶而不恶，但亦不善，平庸而已**。」

**这两句极为重要**：它把「善／恶」改成了三档——**善、平庸、恶**。所以断语不能是「这年大好／大坏」二选一，绝大多数年份其实是「平庸」。这直接决定了断语的可信度。

### 三级尺度对照

| 层级 | 主管 | 时间跨度 | 判准 | 原文出处 |
|---|---|---|---|---|
| **大运** | 十年之趋势 | 10 年 | 运干支利于用神 | 运限篇 |
| **流年** | 一年之吉凶 | 1 年 | 年干支利于用神 | 流年篇 |
| **月建** | 一月之动静 | 1 月 | 月干支利于用神，**月干重于月支** | 月建篇 |

## 二、行运七三折衷法（韦千里的核心创见）

这是千里命稿在技术上最有辨识度的一条，必须讲清。

### 争的是什么

> 「古法以一干及一支为一运，一运管十年。今人以一干一支各为一运，一运管五年。此立法之不同，而休咎有异矣。盖古法一运之吉凶，须干支并看；今人则走天干运即以该干论吉凶，走地支运即以该支论吉凶。」

两派：

| 派 | 法 | 病 |
|---|---|---|
| **古法** | 一干一支合为一运，管十年 | 前五年后五年无别，吉凶一刀切 |
| **今法** | 干管五年、支管五年，各论各 | 割裂干支，与实际脱节 |

### 韦千里的折衷

> 「管见谓**折衷办法，最为精当**。何谓折衷办法？即如甲午运，**前五年注重甲字，兼看午字，甲占七分，午占三分；后五年注重午字，兼看甲字，午居七分，甲居三分。**」

```
甲午运（十年）
├── 前五年：甲 70%  +  午 30%
└── 后五年：午 70%  +  甲 30%
```

### 原书自己的例证（必须看懂）

> 命：**甲子 丁丑 辛亥 乙未**
> 「辛逢甲乙，又逢亥子丑，财多身弱为患。运逢**甲戌**，忌甲之辅财，喜戌之帮身。
> **前五年七分甲而三分戌，凶多于吉；后五年七分戌而三分甲，吉多于凶。**」

拆解：

1. 辛金日主，天干甲乙木（财）、地支亥子丑水 → **财多身弱**。
2. 行甲戌运：甲木是财（忌），戌土是印（喜，帮身）。
3. 前五年以甲为主（七分）→ 忌神当令 → **凶多于吉**；
4. 后五年以戌为主（七分）→ 喜神当令 → **吉多于凶**。

**这条方法的价值**：它能解释为什么同一个十年大运，前五年与后五年的人生境遇可以完全不同。**断大运时必须把十年切成两段来说，不能笼统。**

### 使用注意

- 七三之比是韦千里给的经验值，**不是精确推导**，不必追问为何是七三不是八二。
- 折算的重点不是数字，而是**「前后五年各有重心，但都不完全排斥另一方」**这个结构。
- 断流年时，**流年叠在哪个半运上，力量不同**——前五年遇大运天干相同之字，力量加倍。

## 三、大运：四类八种基本态势

原书「行运之能力」用**八字善恶 × 运之善恶**做了一张 2×2×2 的态势表：

| 八字 | 运 | 结果 |
|---|---|---|
| **纯善**（并无恶神破坏） | 行**扶善**运 | 善者益善，功名富贵无可限量 |
| | 行**破坏**运 | 虽不为害，而必略见抑塞，稍不如志 |
| **虽善**（有恶神破坏） | 行**去恶**运 | 八字中所有之好处立至 |
| | 再见**已破坏之善神**，及**所制之恶神** | 坏处亦立见 |
| **纯恶**（并无善神制伏） | 再行**激恶**运 | 恶者愈恶，贫贱灾祸惨不忍闻 |
| | 行**制伏**运 | 虽不能为福，「**小草春风，亦可片时得志**」 |
| **虽恶**（却有善神制伏） | 行**去善**运 | 八字中所有之坏处立见 |
| | 再见**所制之善神** | 好处亦立见 |

### 这张表的三个反直觉结论

1. **命好不怕坏运**：「纯善」之命行破坏运，只是「略见抑塞」，不会翻盘。反过来，「虽恶」之命行去善运，**坏处立见**。命本身的底子决定运能造成多大波动。
2. **坏命也有春风**：「纯恶」之命行制伏运，仍能「片时得志」。所以见极差之命不能断言一生全无起色。
3. **「再去见」比「不见」更凶**：已破坏的善神重现、所制的恶神重现，都在第二档与第四档出现。断运时要查**这个字是不是局中曾经出过、曾经被制过的字**。

## 四、善运恶运：按格查表

原书按格列了完整的「善运／恶运」对照（PDF 46—47），覆盖八格、五大局、从格、化气格、建禄格、月刃格。**逐格查表，不要凭感觉得出。**

### 八格（摘录格式，完整表见 `vol_yunxian.md`）

格式一律是：**「日干＋某格＋局中之病 → 取某为用 → 逢某某之运为善，逢某某之运为恶」**。

| 格 | 日干 | 局中之病 | 用神 | 善运 | 恶运 |
|---|---|---|---|---|---|
| 正官 | 弱 | 财星重 | 比劫（无则用印） | 印比 | 财官 |
| 正官 | 弱 | 食伤多 | 印 | 官印 | 伤财 |
| 正官 | 弱 | 官杀重 | 印 | 印比 | 财官七杀 |
| 正官 | 强 | 劫比多 | 官 | 财官 | 印比 |
| 正官 | 强 | 印多 | 财 | 财食 | 印比 |
| 正官 | 强 | 多见伤食 | 财 | 财官 | 比劫 |
| 财 | 弱 | 伤食多 | 印 | 印比 | 伤财 |
| 财 | 弱 | 财重 | 比劫 | 比劫 | 伤食财乡 |
| 财 | 弱 | 官杀多见 | 印 | 印比 | 财官七杀 |
| 财 | 强 | 劫比重重 | 伤食或官杀 | 伤食官杀 | 印比 |
| 财 | 强 | 印多见 | 财 | 伤食财 | 印比官杀 |
| 印 | 弱 | 多官杀 | 印 | 印比 | 财官 |
| 印 | 弱 | 多伤食 | 印 | 印比 | 伤食财乡 |
| … | | | | | |

**读表规律（自己推也推得出来）**：

> **善运 = 用神之五行 + 生用神之五行；恶运 = 克用神之五行 + 用神所克之五行（泄用神者）。**

验证：正官格日弱财重 → 用比劫 → 善运「印比」（比劫为用神，印生比劫）；恶运「财官」（财克印耗比，官克比劫）。完全吻合。

**这条规律的价值**：表可以不必背，用「用神及其生我者＝善；克我者及我生者＝恶」直接推。但当表与推导不一时，**以表为准**——原书的表来自大量实例，其中若干处不合机械推导。

### 五大局

| 格 | 善运 | 恶运 |
|---|---|---|
| 曲直（木） | 水、木、火 | 金 |
| 炎上（火） | 木、火、土 | 水 |
| 稼穑（土） | 火、土、金 | 木 |
| 从革（金） | 土、金、水 | 木※ |
| 润下（水） | 金、水、木 | 土 |

> ※ 原文「从革格，逢土金水运为善，**木运为恶**」——此处疑为「**火运**为恶」之讹（金格忌火克，木为金所克，不构成恶运；且曲直格忌金、炎上格忌水、稼穑格忌木、润下格忌土，皆忌克我之行，则从革格当忌火）。**引用时请核原书，并优先采用「火运为恶」的通行说法。**

### 从格与化气格

| 格 | 善运 | 恶运 |
|---|---|---|
| 从财 | 伤食、官杀 | 印比 |
| 从杀 | 财、杀 | 印比 |
| 从儿 | 伤食、财 | 官杀、印绶 |
| 从旺 | 印绶、比劫 | 财官、伤食 |
| 化土 | 火、土、金 | 木 |
| 化金 | 土、金、水 | 火 |
| 化水 | 金、水、木 | 土 |
| 化木 | 水、木、火 | 金 |
| 化火 | 水、火、土 | 水※ |

> ※ 原文「化火格，逢水火土运为善，水运为恶」，自相矛盾（水既善又恶）。疑「水火土」为「**木火土**」之讹（火格喜木生、火助、土泄，忌水克）。**引用时请核原书。**

⚠️ **从格与化气格的恶运一律是「克我之行」或「印比」**，逻辑极干净：既已成从／化，最怕回到本气。这条比任何口诀都可靠。

| 建禄，比劫多 | 官杀 | 财官 | 印比 |

## 五、行运杂缀：按十神分组的断运细则

原书「行运杂缀」是最实用的一节，六十余条，按十神分组。**这是断运时真正要查的东西**——比前面的表格更细。

### 5.1 用官

| 条 | 断 |
|---|---|
| 官星纯正（身强），行运复得官旺之乡、官星成局之运、财旺生官之地 | 皆是作福之处 |
| 正官为用，**大忌行运至伤官之地，更忌刑冲破害之运** | 大忌 |
| 正官而用财印，身稍轻 | 喜助身运 |
| 正官而用财印，官稍轻 | 喜助官运 |
| 正官用财 | 运喜印绶身旺之地，切忌食伤；**然若身旺而财轻官弱，仍喜财官运** |
| 正官带伤食而用印制 | 运喜官旺印旺之乡 |
| 正官带杀，命中用**比**合杀 | 财运可行、伤食可行，**只不可复露七杀** |
| 正官带杀，命中用**伤官**合杀 | 伤食与财俱可行，**而不宜逢印** |
| **正官格行杀运** | 即是**杀来混官** |
| **正官格行墓运** | 即是**官星入墓** |
| 正官如月时重犯、天干多透，再行官旺乡 | **变官为鬼，旺处必倾，多致灾夭** |

> 最后一条极重：「旺处必倾」——正官本身已重，再走官旺之运，不是更好而是崩。**这是「太过」在运程上的表现。**

### 5.2 用杀

| 条 | 断 |
|---|---|
| 四柱杀旺运纯（独行制杀运），身旺 | 为官清贵 |
| 时上偏官无制伏 | 行制运亦可发福 |
| 柱中七杀坐禄乘旺，发自坐长生临官帝旺，又带比劫，财能化鬼为官 | **运入印乡必发** |
| **制杀太过** | 为贫儒；**但行财运醒杀，亦发威权** |
| 七杀乘旺，身又逢刃 | 贵不可言；只忌财旺生杀。**岁运加之，身旺且多灾，身弱则尤甚** |
| 杀强身弱有印 | **最忌财运** |
| 杀旺身弱，行身弱运 | 祸不旋踵 |
| 身强杀浅 | 杀运无妨 |
| 身杀俱旺无制伏，又行杀旺运 | 虽贵不久 |
| **杀重宜制，如行官杀运** | 不死必贫 |
| 七杀行官杀混杂之运，或制伏太过之运 | 多去官退职，甚至凶死 |
| 杀用食制，杀重食轻 | 喜**助食**之运 |
| 杀用食制，杀轻食重 | 喜**助杀**之运 |
| 杀食平均而日主根轻 | 喜**助身**之运 |
| 带杀正官（不论去留） | 身轻则喜助身，食轻则喜助食 |
| 日干衰弱但不能从杀，杀有制有化 | **岁运逢财旺杀旺地，必成灾祸** |
| 同上，更无制无化 | 岁运逢财逢杀旺地，**无不危亡** |
| **身杀两等** | **行运宁可扶身** |
| **原有制伏，杀出为福**（指身弱） | 行杀运有制则福 |
| **原无制伏，杀出为祸** | 行杀运无制则祸 |

> **「身杀两等，行运宁可扶身」** 是一条宝贵的取舍原则：两种方向都说得通时，**优先扶身**。因为身是本，杀是客。

### 5.3 用伤官

| 条 | 断 |
|---|---|
| 用官而见伤官 | 妙入**财印**之运 |
| 用伤官而**多**者 | 宜**印**运 |
| 用伤官而**少**者 | **忌印**运 |
| 用伤官而见官者，运入官旺乡 | **祸不堪言**；虽有吉神解救，亦必生恶疾，甚至残躯，或遭官事 |
| 伤官原有官星 | 行**去官**运发福 |
| 伤官带印 | **不宜再行财运** |
| 伤官用印 | 运行**官杀为宜**，印运亦吉，伤食不碍，**财运则凶** |
| 伤官多印比而财浅 | 喜行财运或伤官运 |
| 伤官用财 | 行财得地运发福；**逢败财运必死** |
| 伤官用财 | **不宜比劫运** |
| 伤官用财 | 行财旺身轻运则吉 |
| 伤官而有杀印 | **印运最利**，伤食亦亨，杂印非吉，**逢财即危** |
| 身旺而四柱伤尽官星 | 行财运则当发福 |

> **「败财」指财被克破之运**（非「破财」）——见原书「逢败财运必死」，语气极重，用时须谨慎。

### 5.4 用食神

| 条 | 断 |
|---|---|
| **食神多者** | 宜行**印**运 |
| **食神少者** | **忌**行印运 |
| 食神 | 喜行身旺地，**遇枭逢比总成空** |

> **「食神多宜印、少忌印」与「伤官多宜印、少忌印」完全同构。** 这是「多则制之、少则忌制」的通则：印是食伤的控制器，只在食伤过多时才是药。
> **「遇枭逢比总成空」**——食神运里遇枭（夺食）或遇比（分财），都落空。

### 5.5 用印

| 条 | 断 |
|---|---|
| 身旺印多 | **财运无妨** |
| 身弱有印 | **杀运何妨** |
| **印有比肩** | 喜行财运 |
| **印无比肩** | **畏**行财运 |
| **贪财坏印** | 喜行**比劫**之乡 |
| 印绶太过 | 不喜再行**身旺**地 |
| 印太轻 | 宜**官杀**运生之 |
| 印太多 | 须**财**运制之 |

> 「印有比肩喜财运、印无比肩畏财运」——差别在于**有没有人替印挡财**。有比肩则财去克比，印得保全；无则财直坏印。

### 5.6 用财

| 条 | 断 |
|---|---|
| 财有比肩 | 喜行比劫之乡 |
| **财多身弱** | **畏入财乡** |
| 财多身弱 | **身旺运以为荣** |
| 身旺财衰 | **财旺乡而发福** |
| 柱中无财，若行财运 | 虽美，**有名无实** |
| 财多身弱，又行官乡或财旺之运 | **祸患百出** |
| 财多身弱 | 要印扶身 |
| 身旺财衰 | **怕劫分夺** |
| 刃助官 | 运喜助官；若命中官根深，则**印绶比劫之方反为美运** |
| 刃用杀，杀不甚旺 | 运喜助杀；**杀若太重，则运喜身旺** |
| **小盈大亏** | 恐是**劫财**之地 |
| 财多身弱，遇劫为福 | |
| 财弱身旺，见劫为祸 | |
| **多劫又遇劫运** | 守穷途而凄惶 |

> **「柱中无财，若行财运，虽美有名无实」** ——这条很反直觉但极准：局中本来无财，运里来财，财无所依托，是「虚财」。断财运别见财就断发。

## 六、流年：三层叠加

### 6.1 流年本身

| 条 | 断 |
|---|---|
| 流年干支利于用神 | 善 |
| 流年干支不利于用神 | 恶 |
| 利于用神**但为局中他神克去或合住** | 善而不善，然亦不恶，**平庸** |
| 不利于用神**但为局中他神克去或合住** | 恶而不恶，然亦不善，**平庸** |

### 6.2 流年与运：十二则

| # | 组 | 断 |
|---|---|---|
| 1 | 流年善，运亦善 | **更妙** |
| 2 | 流年善，运恶 | 善恶互见 |
| 3 | 流年恶，运亦恶 | **更恶** |
| 4 | 流年恶，运善 | 善恶互见 |
| 5 | 流年善而被局中克合，**运来制住克合之神** | 仍佳妙 |
| 6 | 流年恶而被局中克合，**运来制住克合之神** | 仍蹇劣 |
| 7 | 流年善而被克合，**运来生畏克合之神** | 凶多吉少 |
| 8 | 流年恶而被克合，**运来生辅克合之神** | 吉多凶少 |
| 9 | 流年善，运若生助之 | 更善 |
| 10 | 流年恶，运若生助之 | 更恶 |
| 11 | 流年善，运若克挫之 | 善力减轻 |
| 12 | 流年恶，运若克挫之 | 恶力减轻 |

**核心机制**：**大运是「操作流年的手」**。同一个被克合的流年，运来解开克合则复其本性，运来助长克合则加倍压制。**所以断流年必须先看运怎么对待那个「克合流年之神」。**

### 6.3 流年之干支：十二则

原书先破两说：

> 「有谓流年重天干；亦有以天干为上半年、地支为下半年——**皆非的论**。当以**干支并看**，最较精确。」

| # | 情形 | 断 |
|---|---|---|
| 1 | 干支皆利于用神 | **大吉** |
| 2 | 干支皆不利于用神 | **大凶** |
| 3 | 干利、支不利 | 吉凶参半 |
| 4 | 干不利、支益助用神 | 吉凶互见 |
| 5 | 干利，支再辅之 | 大吉 |
| 6 | 干不利，支再辅之 | 大凶 |
| 7 | 支利，干再辅之 | 大吉 |
| 8 | 支不利，干再辅之 | 大凶 |
| 9 | 干利，支克挫之 | 吉力减轻 |
| 10 | 干不利，支克挫之 | 凶力减轻 |
| 11 | 支利，干克挫之 | 吉力减轻 |
| 12 | 支不利，干克挫之 | 凶力减轻 |

> ⚠️ **第 5、6 行的「再辅助之」与第 9、10 行的「克挫之」是两套机制**：辅助＝同向叠加，克挫＝反向削减。第 6 行「干不利而支再辅之，大凶」——注意此处的「辅」指的是**支加强干的不利**，不是支来救。
>
> **原书此表第 1—8 行与第 9—12 行的逻辑略有重叠（「益助」与「再辅」如何区分未明说），引用时以「干支同向则加倍、反向则相减」这一条总原则为准。**

### 6.4 流年断语的三档写法

综合上面三层，一个流年的结论应写成：

```
【干支】甲辰年（干支各有宜忌）
【与运】叠在某运前/后五年（主七分某，兼三分某）
【局中反应】用神 X 得生／被克合，有无解救
【结论】（大吉／吉／平庸／凶／大凶）+ 具体事象方向
```

## 七、月建：最细一层

### 7.1 月建与流年的关系（十二则）

与流年—运的关系**完全同构**，只是层级下移：

| # | 断 |
|---|---|
| 1 | 月建善，流年亦善 → 更妙 |
| 2 | 月建善，流年恶 → 善中有恶 |
| 3 | 月建恶，流年亦恶 → 更恶 |
| 4 | 月建恶，流年善 → 恶中有善 |
| 5 | 月建善而被克合，流年制住克合之神 → 仍佳妙 |
| 6 | 月建恶而被克合，流年制住克合之神 → 仍蹇劣 |
| 7 | 月建善而被克合，流年生辅克合之神 → 凶多吉少 |
| 8 | 月建恶而被克合，流年生辅克合之神 → 吉多凶少 |
| 9 | 月建善，流年再生助之 → 更善 |
| 10 | 月建恶，流年再生助之 → 更恶 |
| 11 | 月建善，流年克挫之 → 善力减轻 |
| 12 | 月建恶，流年克挫之 → 恶力减轻 |

### 7.2 月干重于月支

> 「月建看法，**月干重于月支**，因**干流动而支固定**。」

原书同时否掉两种流行说法：

- 「以干为上半月、支为下半月」——**不甚可信**；
- 「以月支所藏人元，分何者当旺几天，而定几天吉凶」——**更不足信**。「盖完全偏重于月支……看命中强弱且不能以建中人元旺几天而标定，况流年中之流动月建耶。」

**这是千里命稿对「人元司令分日用事」派的正面否定。** 与本技能 `04_补充篇精要.md` 第二节「以本气为主」互证。

### 7.3 月建与时令

月支固定（正月必寅），故不如月干重要。但**时令与月建相关**：

| 时令 | 月干组合 | 效果 |

| **春（木旺）** | 甲寅、乙卯、甲辰 | 木更盛 |

| | 戊寅、己卯、戊辰 | 土被木克而不健 |

| **夏（火旺）** | 丁巳、丙午、丁未 | 火更盛 |
| | 己巳、戊午、己未 | 土得火生而亦强 |

## 九、断语纪律（务必遵守）

### 1. 三档而非二档

「善、平庸、恶」三档。**绝大多数年份应判「平庸」**。原书明说：「善而不善……平庸而已」。把平庸判成吉凶，是最常见的过度断。

### 2. 不跨级

流年吉凶不能脱离大运单独断（第六节 6.2）。大运吉凶不能脱离原局单独断（第三节四类八种）。

### 3. 不断具体事件，只断方向

原书虽偶有「不死必贫」「必成灾祸」「祸不堪言」这类重话，但那些都是**极端配置下的极值表述**（如「杀旺身弱，行身弱运，祸不旋踵」）。**本技能的纪律：只断「此年压力大、阻力多、宜守不宜进」这类方向，不预断疾病、死亡、官非、离散。**

### 4. 大运必分前后五年

若不提「前五年／后五年」而笼统断十年，等于没用七三折衷法。

### 5. 遇原书矛盾条文，标注「原书两说并存」

本文件已标出数处（从革格恶运、化火格恶运）。遇到别的，同样如实标注，不擅自裁决。

### 6. 不用神煞作主断

驿马、贵人、天月德、旬空，都只作**加减**（见 `04_补充篇精要.md` 第十节）。

### 7. 神煞与刑冲的减力规则要说清

- 旬空：吉凶皆「虚而不实」
- 驿马逢冲：加鞭（吉愈吉，凶愈凶）；逢合：系足（迟发）
- 天月德：命吉增吉、命凶减凶；但**本身遭克不以吉论**
