# 断婚姻诀

十一断婚姻诀

判断婚姻看日支，日坐财星为喜用

爱人必是有钱人，日坐将星为喜用

贤慧敦厚慈悲心，日坐偏印为喜用

精明强干聪明人，日坐正官为喜用

端庄矜持威严人，日坐七杀为喜用

刚直伶俐身健康，日坐伤官为喜用

诚信有德爽朗人，日坐食神为喜用

快乐无忧体胖人，如果婚姻不顺心

喜用变作了忌神，依此便可做反断

仔仔细细说的真，如果日支是喜用

却被他支伤害了，必是配偶有疾病

或者对象不满意，如果日支是忌神

却被他支伤害了，感情虽然不太好

但是却是有本事，倘若财官入日支

只要被人伤害了，就是病灾和死亡

倘若财官在他支，克日不吉生日吉

男命混杂了财星，伤官食神无

七杀桃花入日支，必是有了婚外情

女命混杂了官星，财多无制有隐情

禄星入命合他神，必是有了婚外情

女命要看几次婚，几个官杀几次婚

几个伤官几次婚，男命要看几次婚

几个财星几次婚，几个比劫几次婚

看时定要看日支，河洛图中数分明

女命痛苦离了婚，只因财星被关门

宫中十神换得杂，重婚重配是一定

年月出现配偶星，早早结婚不由你

月时出现配偶星，一定会是晚婚命
