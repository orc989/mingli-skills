# 自在道人实战命例五十五坐下忌神杨女士

阴历一九四七年十月二十戌时阳历1947年12月1日
坤造：丁亥辛亥乙卯丙戌（子丑）
[pic]

一、断旺衰
日干乙木生在亥水月旺51%.时干丙火有力.身旺不从.时干丙火是用神.月干辛金无力反断
为忌神.年干丁火为用神。
二命局疾病分析
日干乙木身旺，座下卯木为忌神，卯木为病，代表的内容.肩肘.颈椎.肝胆.腰关节.股骨
头.膝关节.躁关节.究竟是什么病，全方位分析一下，l凡是两边粗中间细的关节连接处
都称之谓卯。
1.女命时支为正六亲时.代表前面.上面.左面.戌土制卯木起了好作用.上面没有病.右面
没有病。
不能是肝胆首断不是肝病。
2.女命月支为偏六亲时.代表右侧.后侧.下侧.月支亥水生卯木是病.月支亥水为后侧，后
侧使卯木不健康.应为腰椎部分.月支亥水生卯木也是病.腿部也不健康.但是日支卯木制
月令亥水。
亥水之病也没有卯木病重。
3日支卯木代表腹部.腰部中间部分排除了上面的病.排除了下面的病，排除了左右的病.
卯木在前侧腹部.没有疾病对应部位.只能是腰部后部中间之病.腰椎间盘突出症之病。
