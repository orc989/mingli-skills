## 三、OCR 干支误识清单（60 条实测）

OCR（tesseract chi_sim）对干支字的误识高度稳定，形成固定映射。以下为实测清单，**已全部在清洗阶段修复**，但仍有漏网之鱼，故列出供人工复核。

### 天干

| 误识 | 正字 | 例 |
|---|---|---|
| 全 | 癸 | 全水 → 癸水 |
| 王 / 于 / 手 / 亡 / 张 | 壬 | 王水 → 壬水 |
| 两 | 丙 | 两火 → 丙火 |
| 成 | 戊 | 成土 → 戊土 |
| 已 | 己 | 已土 → 己土 |
| 本 | 丁 | 本火 → 丁火 |
| 庚 / 辛 / 甲 / 乙 | 偶有颠倒 | 需按四柱行整体校验 |

### 地支

| 误识 | 正字 | 例 |
|---|---|---|
| 卵 | 卯 | 丁卵 → 丁卯 |
| 成 | 戌 | 庚成 → 庚戌 |
| 于 | 子 | 于午 → 子午 |
| 雍 | 丑 | — |
| 实 | 寅 | 实土 → 寅土 |
| 展 | 辰 | — |
| 袖 | 巳 | 丙袖 → 丙巳 |
| 本 | 未 | 本三合 → 未三合 |
| 西 | 酉 | 西金 → 酉金 |
| 交 / 玄 | 亥 | 交金 → 亥金 |

### 高频组合误识（18 条）

`王辰→壬辰`、`王寅→壬寅`、`王申→壬申`、`王戌→壬戌`、`王子→壬子`、`王午→壬午`、
`庚成→庚戌`、`甲成→甲戌`、`丙成→丙戌`、`戊成→戊戌`、`壬成→壬戌`、`成成→戌戌`、`成运→戌运`、
`已西→己酉`、`癸西→癸酉`、`乙西→乙酉`、`辛西→辛酉`、`丁西→丁酉`

### 尚未完全解决的

1. **`戌`/`戊` 混淆**：二字在高密度命例段落中仍偶有互换（`戊` 为天干、`戌` 为地支，需按位判）。
2. **`己`/`巳`/`已` 三字混淆**：`已` 大量出现，多数应为 `己`（天干）或 `巳`（地支），只能按位判。
3. **`未`/`末`**：`末` 一律应为 `未`。
4. **`巽` 字在 02 册几乎全失**：被误识为「哄」「虹」「典」「吕」「蜀」「嗣」等多个字，无法统一还原，故 02 册八卦只有七卦。

## 六、可复现步骤

```bash
# 1) 文字层抽取
pdftotext -layout 04.pdf txt/04上册.txt

# 2) 扫描件渲染（裁掉左侧竖排书名边栏）
pdftoppm -r 300 -x 312 -y 0 -W 2000 -H 2400 -png 01.pdf /tmp/jbm/p01

# 3) OCR（单线程 tesseract + 进程池并行）
OMP_THREAD_LIMIT=1 tesseract p01-001.png out -l chi_sim --psm 6

# 4) 清洗 + 干支修复（build.py 的 PHRASE 表）
python3 build.py

# 5) 切章（空白放宽为 \s*，逐段推进 base）
python3 split.py && python3 split2.py
```

**切章的两个坑（已踩过）**：

1. **不能用 `find` 精确匹配带空格的标题**——OCR 会在标题字间插入换行。必须把锚点转为 `\s*` 连接的正则：`re.compile(r'\s*'.join(re.escape(c) for c in anc if not c.isspace()))`。
2. **日期锚点必须带标题后缀**——如 `2021.4.2` 会同时命中 `2021.4.20`、`2021.4.22`，必须写成 `2021.4.2 源流`。

## 七、引用规范

在本 skill 内引用原文时，请遵守：

1. **四柱八字一律标注来源篇号**，如「例（`K04_06`）：癸 癸 辛 己 / 亥 亥 亥 丑」。若干支有可疑，加「（原文作…，疑为…）」。
2. **口诀类引用注明册号**（`M08` / `M09`），并说明「口诀需配合讲法，有使用条件」。
3. **08 册的卦名按修复后读法**（竞→兑、民→艮、巽用「哄/虹/典/吕」）。
4. **不得把 OCR 错字当作原文术语**。例如「枭印」在 OCR 中大量写作「氮印」「桌印」「抽印」「抠印」——**正字是「枭印」**，不可当作新概念。
5. **遇到讲不通的句子，先怀疑 OCR，不怀疑理论**。
