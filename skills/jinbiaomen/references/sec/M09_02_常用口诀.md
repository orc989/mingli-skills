# 常用口诀

二常用口诀

五行生的全，富贵万万年。

一卯二卯，富贵到老。

男子带文昌，提笔写，女子带文昌，贴花进绣房。

男子带，出门有酒喝，女子带，房门都挤破。

聪明不过食神，伶俐不过伤官。

男子带进神，打马进朝庭。

年上七杀一把刀，克夫暂子命不挠。

伤官挂了角，不瘤腿就裸脚。

行运早，多烦恼，行运迟，往后好。

己运己运，哭哭盈盈，

子运子运，走的不好就是死运。

伤官伤官，波杂多端。

伤官伤官，日夜不安。

人人有个三十六，喜一喜来忧一忧。

暮库暮库，挺挺库库。

少年暮库吓得哭，老来暮库要死不活。

天罗地死臣，不自己别人，退财可以免灾兴，不退钱财死蓄生。

年轻七杀人，老来七杀助精神。

不怕你发恨，就怕命不行。

官怕交印，人怕交运。
