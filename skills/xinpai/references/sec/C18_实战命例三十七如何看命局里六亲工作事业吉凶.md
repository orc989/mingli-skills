# 实战命例三十七如何看命局里六亲工作事业吉凶

阴历：一九八一年四月二十九阳历
坤造：辛酉癸巳庚戌壬午(寅卯)
[pic]
一看丈夫的工作事业吉凶情况。
1.先找丈夫的那个字.丁火.在命局里没有出现.在月干癸水对应.日干庚金从弱.丈夫丁火
是用神。
2.丈夫丁火的正官在命局时干出现.丁火为用神.时干壬水制丁火为忌神.丈夫正官的壬水
为忌神.弱时丈夫的正官吉。
3.丈夫正官的工作环境.女命正六亲正官的工作环境.在代表正官这个字的右侧天干看.如
果在时干透出.月干作用日干对时干起的作用.就是这个正六亲正官的工作环境。
月干癸水泄日干庚金.庚金弱不生时干壬水.丈夫有一份轻松的工作一生有贵人帮助。
