# 知命

知 命

要与人间开侮材，顺逆之机须理会。

京南道人: 今人学命，有见化官生印而为官者，有见食神生财为技术者，有合官
而为官者，合财而为富者，有冲库必发者，有相穿为害者，有和夺食贫苦者，有劫财破
财者，荒唐取用，定人终身，是犹医者知参芪之能生人，而不知参芪之能害人也，知
础巡之能杀人，而不知磁巡之能救人也。又如财支透官，日主合官，号曰财戴官帽，
必为官者，何不取印戴财帽，动戴印帽者乎? 又午支透庚，竟论午带庚象，夫五行火
金两克，不待辩而知其廖也，以是为非，论以传这，遂使学命者，如伦虎者多矣。又
有书房专论旺则抑之，衰则补之，不知顺道之理，竟以伤官见官为祸百端，不知无用
之官尽可伤，竟以比劫见财必破财，不知不用之财尽可动，财重印轻官星不现，用比
劫者富矣。造化之机必有一用字，理会之，方可以言命也。
