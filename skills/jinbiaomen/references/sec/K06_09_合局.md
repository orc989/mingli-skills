# 合局

合 局

      合有宜不宜，合多不为奇
      合有合化，有合去，合化后助用神就好，合化后助忌神就凶，用神被合去就凶，
忌神被合去就吉。
      喜用神得合而助之者
      比如乙庚合，庚是喜用神，遇到乙合，如果合化金了就吉。
      比如戊癸合，癸是忌神，或者闲神，遇到戊合，如果合化成火是命局的用神就吉，
不能合化就是合去了，也就是合掉了癸水。
      比如壬是闲神，丁是忌神，这两个都不是我所用的，但是丁壬合化成木了，木是
喜神或者用神就是吉。
      还有冲解合的，合解冲的。
      比如子午冲，午火是喜用神，有丑合住子解冲就言。寅申冲，喜用神是寅，有寅
亥合解冲就吉。这个就是得其大意变通之。
      忌神得合而助之者
      比如己土是忌神，遇到甲合，甲己合化成土，助起忌神就凶。
      比如乙木为喜用神，辛是闲神，遇到丙辛合化水了，水生木助起用神，就不凶了。
      比如壬为忌神或者闲神，丁也是忌神或者闲神，丁壬合化木了，但是木是凶神或
者忌神就是凶了。
      比如卯酉冲，喜用神是卯木，遇到辰土来合酉金，合化金克木，就是凶。
      所以合要看能不能合化，看合的五行和合化后事是喜神是忌神，总之对命局起好
作用就吉，起坏作用就凶。
